# 阶段③ · 一致性自检清单（人工）

> **触发时机**：每章写完跑 `check_text.py` 出机器观察值后，人工逐项过一遍。
> **强度**：观察级——机器只给提示，以下由人判断并记录结论。
> **底线**：金额、位置、时间这三类硬事实，正文必须与 `真相/facts.md` 台账一致。

## 1. 时间锚点自洽

- [ ] 相邻时序副词能否顺序对上？（先后 / 接着 / 然后 / 后来）
- [ ] 没有互相矛盾的时间表述（如"白天成交"与"当晚发现"）？
- [ ] 与前后章的接续时间点一致（读 `真相/timeline.md` 校准）？

> 机器依据：`check_text.py --consist` 导出的时间线顺序清单。

## 2. 负向句 × 逆转的真实性

- [ ] 出现"没做梦""不是/没有 XX"时，句子的**真伪**是否被后续文本坐实或推翻？
- [ ] 是否有"先说没有、后又说有"的隐性矛盾？（如"没做梦"却"床单湿了"）

## 3. 数据前后一致

- [ ] 金额/数字在本文内多次出现时，数值统一吗？
- [ ] 数字与 `真相/facts.md` 台账值一致吗？（工资/余额/成交价/时间等）

> 机器依据：`check_text.py --digits` 导出的全数字清单 + `--facts` 台账比对。

## 4. 位置/场景连续

- [ ] 场景切换有过渡路径吗？（卧室→地铁→公司…链得住）
- [ ] 前后章同一地点的物理特征不冲突？（道观"前后两进"每次描述一致）

## 5. 开篇质量复核（仅首章 / 每卷首章）

- [ ] 首 300 字是否收录**人物/事件/冲突/悬念**至少 2 项？（见 self-review 一票否决）
- [ ] 开篇不是纯回顾式写法？（若被 `--hook` 标记，确认是否刻意为之）

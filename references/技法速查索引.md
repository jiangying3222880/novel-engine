# 技法速查索引（Technique Quick Index）

> 来源：v1.0.0 `06-knowledge-pack.md`（8 大分类速查库）重建 · 对齐当前 124 个技法文件（T-001~T-118 + 方法论）
> 原则：**按需加载**。写什么阶段/场景，只查对应分区；不要一次全读。

## 0. 怎么用

**两个入口，按你当前卡在哪一步选：**

| 你现在的处境 | 查哪节 |
|-------------|--------|
| 写某一章时卡住了，不知道该用什么手法 | → **§1 按场景查**（规划/开头/正文/高潮/对白/收尾） |
| 想写某种文梗（打脸/复仇/觉醒/系统…），要现成配方 | → **§2 按文梗查**（T 卡分组） |
| 写短篇，要选兑现方式 | → **§3 短篇速查**（六引擎 + 单元讲法） |

> 每个分区只列"最相关"的 2-5 个，完整清单见 `library/techniques/_README.md`。

## 4. 维护规则

- **新增技法卡**：写入 `library/techniques/`，并按机制归入 §2 对应分组；没有合适分组的，新建分组并更新本索引。
- **删除技法卡**：同步从 §2 分组移除，避免死链。
- **本索引定位**：导读层，不重复技法卡正文；每个条目一句话说明即可，详细内容点链接看原文。

# 10. 外包写作分支（Chat-Outsource）

> **一句话**：技能负责规划与治理，写作外包给任意网页 chat（豆包网页 / Claude 网页 / 其他），写完后拿回继续"自检 → 去AI味 → 落库"。
> **定位**：这是五阶段 SOP 的**流程分支**（流程层），不是内容层规则——它改变"谁写正文"，不改变"怎么去AI味、怎么落库"。

---

## 1. 何时用 / 何时不用

**用**（符合任一即激活）：
- 用户说"这章外包""用网页chat写""给我提示词我拿去写""外部写手"
- 用户想借助某个 chat 的强写作/强风格能力（如特定模型的文风）
- 初始化时就说"整本书走外包模式"（每章都出提示词，用户贴回）

**不用**：
- 用户没有明确要求（默认技能自己写阶段②）
- 单章仅需"润色"而非"重写"（走 04/06 即可）

---

## 2. 激活方式（自然语言，随时）

| 时机 | 用户可说 |
|------|---------|
| 初始化 | "开新书，走外包模式""这本书用网页chat写" |
| 中途（整本书持续） | "从这章开始都外包" |
| 中途（仅本章） | "这章外包""这章我拿去chat写" |
| 回接 | "写好了，贴回来""这是我的稿子" |

激活后本分支接管：**阶段①照跑，但产出变成一份自包含的最终提示词**；**阶段②由外部 chat 承担**；**阶段③④⑤由技能接续**。

---

## 3. 核心产出：最终提示词（必须自包含）

外部 chat **读不到本地状态文件**，所以最终提示词必须**打包全部必要上下文**，一份贴进去就能写。打包清单：

```
【任务】写第X章正文，约N字，题材基准<书/作者>
【当前状态】（来自 story/truth/ 6 文件的精简摘要）
  - 时间/地点：...
  - 在场角色与状态：...
  - 关键道具：...
  - 未回收伏笔（仅本章相关，防剧透不泄未来）：...
【本章目标】来自规划清单（主角行动目标 / 事件 / 钩子）
【声线样本】1-3 段 target 风格示范（来自 pools/author_dna + 设定/角色声线）
【写作要求】
  - 用动作/结果呈现，避免解释设定（冰山）
  - 对话有节奏与个性，声线区分
  - 每500字左右一个小钩子或情绪转折，章末留悬念不圆满收束
  - 只写正文，不写元数据/YAML，不要标题以外的小结
【字数】约 N 字
【输出格式】纯正文，分段落，对话独立成行
```

> 最终提示词由技能自动编译（读 6 状态文件 + 规划清单 + 声线样本 → 拼装）。用户**不需要自己组织**，技能给出一份可直接复制的提示词。

---

## 4. 交接与回接流程

```
阶段① 规划 ──► 编译最终提示词 ──► 用户复制 → 贴入网页 chat
                                      │  chat 输出正文
                                      ▼
用户把正文贴回 ──► 阶段③ 自检（03，4问行为验证）
                ──► 阶段④ 去AI味（04/06/09，跑满：外部chat几乎必带AI味）
                ──► 阶段⑤ 落库（Change Report + 更新6状态文件 + meta）
```

**回接校验清单**（正文贴回后先做，再做③）：
- [ ] 正文是否包含全部规划目标（缺失的段节点要补）
- [ ] 是否有 YAML/元数据残留（要清掉）
- [ ] 是否有"解释设定/对称排比/总结式"等 AI 味痕迹（④重点跑）
- [ ] 声线是否偏离基线（对照 voice-profile）
- [ ] 与上一章衔接（读 story/meta/上一章 核对）

---

## 5. 注意事项

1. **④ 必须跑满**：外部 chat 没有 novel-engine 的去AI味治理，正文回来基本带 AI 味，阶段④按 04/06/09 全流程执行，不跳过。
2. **提示词必须自包含**：上下文打包不全 → 外部 chat 瞎编。宁可多打包 1KB，不要缺。
3. **防剧透**：只给本章相关的伏笔/状态，未来情节不泄（与 08-retrieval 的 cutoff 同原则）。
4. **流程层分支**：外包是"谁写正文"的流程选择，不改变"内容只引导不禁止"的理念——去AI味照旧是引导式，不是给外部 chat 禁词黑名单。
5. **回接格式**：外部 chat 可能输出 markdown 标题/列表，③校验时清成干净正文。
6. **失败兜底**：回接正文严重不达标（声线崩塌/缺节点/超字数），允许再补一轮提示词让外部重写，或降级为技能自己重写阶段②（最多 3 轮，与修正循环一致）。

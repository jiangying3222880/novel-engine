# 阶段①：项目启动与本章规划 SOP

## 1. 状态装载流程

在回答用户前，按顺序读取且仅读取以下文件：

1. `novel-config.json` — 项目档案（书名/题材/字数/基调，开书时建立）
2. `hooks.md` — 当前生效的伏笔与未解悬念
3. `设定/角色声线.md` — 已登场角色的基线档案（语言基线/硬边界/情绪光谱）
4. 最新已完成章节的 Frontmatter — 上一章的 causal_links / hooks / emotion_arc

**首次启动判断**：如果项目目录中没有 `novel-config.json`，说明项目未初始化，跳转至 `references/00-project-setup.md` 执行阶段⓪。

**禁止全量加载设定集。** 大纲文件只读当前章对应段落。

## 2. 新角色检查

判断本章是否有首次出场的说话角色：
- **有新角色** → 按 `templates/voice-profile-template.md` 建立基线档案，写入 `设定/角色声线.md`
- **无新角色** → 直接使用已有基线

## 3. 章态注入

为本章每个出场角色生成 3-4 行声线章态：

```
角色名｜当前情绪状态｜语言节奏变化（vs基线）｜口癖/习惯变化｜动作泄露
```

**章态必须落在基线的情绪光谱内。** 超出光谱 = OOC。

## 4. 规划判断逻辑

读取完成后，内部判断（不输出）：
- 上一章 emotion_arc 的终点是什么？本章应从什么情绪开始？
- hooks.md 中有哪些 `[active]` 钩子到了该回收的时机？
- 本章调阅 8 大技巧库中的哪一类？

## 5. 阶段① 输出模板

```markdown
### 【第 X 章 规划清单】

1. 核心目标与情绪弧
   - 本章核心事件：[一句话]
   - 目标情绪弧：[起点] → [终点]

2. 伏笔与钩子计划
   - 拟回收旧钩：[Hook ID + 回收方式]
   - 拟埋下新钩：[Hook ID + 悬念内容]

3. 本章声线章态
   - 角色A｜[情绪]｜[语言变化]｜[口癖变化]｜[动作泄露]
   - 角色B｜[情绪]｜[语言变化]｜[口癖变化]｜[动作泄露]

4. 技巧调阅
   - 本章调阅：[8 大分类中 1-2 个]

5. 预估字数：[X000 字]
```

## 6. 规划质量自检

- 至少 1 个钩子被回收或推进？
- 情绪弧是否和上一章终点衔接？
- 章态是否落在角色基线光谱内？
- 核心事件能一句话说清？

## 7. 首次启动特例

第1章（无上一章）：
- 跳过"读取上一章 Frontmatter"
- 额外读 `references/06-knowledge-pack.md` 的【黄金开头】分类
- 规划清单增加"第一句话设计"
- 所有出场角色都按新角色处理

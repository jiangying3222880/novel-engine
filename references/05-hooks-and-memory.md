# 阶段⑤：状态落库与 Change Report

## 1. 核心原则

- **状态集中在 `story/truth/`**：4个文件（characters / world / hooks / relationships）是唯一真相中心
- **Change Report 驱动更新**：先出报告，再改状态文件，确保所有变更可追溯
- **池子只放对标书内容**：素材池是高质量对标书的拆解产物，不存自己的稿件

---

## 2. story/truth/ 四层状态体系

| 文件 | 内容 | 更新频率 | 对应旧记忆级别 |
|------|------|----------|---------------|
| `characters.md` | 基线摘要 + 当前状态（位置/情绪/知识/物品） | 每章 | L1 角色记忆 |
| `world.md` | 核心规则 + 当前状态（时间/地点/环境/大事记） | 每章 | L1+L2 世界记忆 |
| `hooks.md` | 伏笔追踪（active / resolved / abandoned） | 每章 | 伏笔管理 |
| `relationships.md` | 关系矩阵 + 关键关系备注 | 每章 | 关系记忆 |

> **完整设定档案**（`设定/角色声线.md`、`设定/世界观.md`）是深度参考，不在强制加载范围内。只有当声线存疑或需要深挖设定时才读取。

---

## 3. hooks 语法规范

伏笔状态仅允许三种：

| 状态 | 含义 |
|------|------|
| `active` | 已埋下，尚未回收，读者心中有悬念 |
| `resolved` | 已回收，悬念已解答 |
| `abandoned` | 已废弃（因剧情调整不再需要回收，需在备注说明原因） |

```markdown
| ID | 类型 | 内容 | 埋设章 | 计划回收章 | 实际回收章 | 状态 |
|----|------|------|--------|------------|------------|------|
| h_001 | mystery | 主角腰间的黑色令牌到底来自哪个门派？ | 1 | 5 | - | active |
```

### 伏笔债务管理

- `active` 超过 10 章未推进的钩子标记为"伏笔债务"
- 每次落库时检查是否有债务，在报告末尾提示用户
- 如果 `active` 超过 20 章未推进，强制在下一章规划中安排推进或废弃

---

## 4. Change Report 生成与落库流程

正文确认后，按以下步骤执行：

### Step 1：生成 Change Report

参照 `references/change_report_spec.md`，生成本章变更报告，包含：

1. **角色变化**：哪些角色的位置/情绪/已知信息/携带物品变了
2. **新伏笔**：本章埋了哪些新伏笔
3. **伏笔回收**：本章回收了哪些旧伏笔
4. **时间线**：故事时间推进了多少
5. **世界规则变化**：有没有新设定确立
6. **关系变化**：哪些角色关系变了

### Step 2：更新 story/truth/ 状态文件

根据 Change Report 内容，逐个更新4个状态文件：

- `characters.md` → 更新「当前状态」表格，「基线摘要」极少变动
- `world.md` → 更新「当前状态」+「时间线大事记」，「核心规则」极少变动
- `hooks.md` → 新伏笔追加行，回收的伏笔改状态 + 填实际回收章
- `relationships.md` → 更新关系矩阵强度 + 追加变化备注

### Step 3：写入章节 Frontmatter

将以下字段写入章节文件顶部：
- `causal_links`（因果链）
- `hooks_planted` / `hooks_resolved`（伏笔埋收）
- `emotion_arc`（情绪弧）
- `change_summary`（本章核心变化摘要，下一章快速读取）

### Step 4：输出落库报告

按下方模板输出。

---

## 5. 落库报告输出模板

```
### 落库报告：第 X 章

## 状态更新
  ✓ characters.md：[变化简述，如：林深位置→上传舱，情绪→紧张]
  ✓ world.md：[变化简述，如：时间推进32分钟，新增"意识上传"规则]
  ✓ hooks.md：新增 X 个，回收 X 个
    - 新增：h_00X（内容简述）
    - 回收：h_00X
  ✓ relationships.md：[变化简述，如：林深↔方若华 从6→7]

## 伏笔债务
  - h_002 已 active 12 章，建议下章推进
  - 无新增债务

## Change Report 摘要
  [一句话总结本章核心变化]

## 入池状态
  - 池子为静态（对标书拆解内容），不随写作增长
```

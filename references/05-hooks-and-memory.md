# 阶段⑤：伏笔追踪与记忆落库

## 1. hooks.md 语法规范

伏笔状态仅允许三种：

| 状态 | 含义 |
|------|------|
| `[active]` | 已埋下，尚未回收，读者心中有悬念 |
| `[closed]` | 已回收，悬念已解答 |
| `[abandoned]` | 已废弃（因剧情调整不再需要回收，需在备注说明原因） |

```markdown
# 伏笔追踪库 (Hooks)

* [active] [HK002] [章003埋入] 主角腰间的黑色令牌到底来自哪个门派？
* [closed] [HK001] [章001埋入 → 章005回收] 二叔突然病危的真正原因（系中毒）
* [abandoned] [HK004] [章002埋入] 邻居王婶的身份疑点（剧情调整，该支线删除）
```

## 2. 伏笔债务管理

- `[active]` 超过 10 章未推进的钩子标记为"伏笔债务"
- 每次落库时检查是否有债务，在报告末尾提示用户
- 如果 `[active]` 超过 20 章未推进，强制在下一章规划中安排推进或废弃

## 3. 4 级记忆系统

记忆按时效分为 4 级，存储方式不同：

| 级别 | 内容 | 存储位置 | 读取频率 |
|------|------|---------|---------|
| L1 全局记忆 | 故事弧线、主角成长线、核心世界观 | `memory-l1.txt` | 每章规划时读 |
| L2 世界规则 | 已建立的设定铁律、对读者的承诺 | `memory-l2.txt` | 每章规划时读 |
| L3 近章上下文 | 上一章的因果链、情绪弧、未解悬念 | 章节 Frontmatter | 上一章的读 |
| L4 历史归档 | 5 章以前的已完成章节 | 正文文件 | 仅跨章检查时读 |

### L1 全局记忆文件格式

```markdown
# 全局记忆 (L1)

## 主角成长线
- 章001-005：被动求生 → 章006-010：主动反击 → 章011+：承担使命

## 核心剧情节点
- [章003] 主角发现令牌秘密
- [章007] 师父真实身份揭露
- [章012] 第一次独力击杀强敌

## 世界观铁律
- 修炼体系：炼气→筑基→金丹→元婴
- 地理：东荒→中州→北冥
```

### L2 世界规则文件格式

```markdown
# 世界规则 (L2)

## 已建立的设定
- 令牌只能在新月夜激活（章003确立）
- 筑基期无法飞行（章006确立）

## 对读者的承诺
- "那个地方"——主角说要回去，读者在等（章004承诺）
- 师父的酒壶——暗示有故事，尚未揭示（章008暗示）
```

## 4. 落库操作流程

正文确认后，按以下步骤更新：

1. **更新 hooks.md**：本章回收的 Hook 改为 `[closed]` + 补充 `[章X回收]`；本章新增的 Hook 追加为 `[active]`
2. **更新 L1 全局记忆**：如有重大剧情节点，追加到 `memory-l1.txt`
3. **更新 L2 世界规则**：如本章确立了新设定/新规则，追加到 `memory-l2.txt`
4. **写入 Frontmatter**：将 causal_links / hooks_planted / hooks_resolved / emotion_arc 写入章节文件顶部
5. **提示用户**：报告本章落库了哪些变更

## 5. 落库输出模板

```
### 落库报告：第 X 章

Hooks 更新：
  - [closed] HK001（本章回收）
  - [active] HK006（本章埋入：……）

L1 记忆更新：
  - 追加：[章X] 主角首次……

L2 规则更新：
  - 新规则：……（章X确立）

伏笔债务：
  - HK002 已 active 12 章，建议下章推进
  - 无新增债务
```

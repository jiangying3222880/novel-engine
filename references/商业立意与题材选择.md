# 商业立意与题材选择

> 来源：起点编辑视角商业写作指南（job-0031）
> 定位：L3 Strategy 层 · 题材决策参考
> 上游：C-001（变化的驱动力）/ P-001（价值翻转）

---

## 核心原则

> **"题材风格匹配 > 个人喜好。"**

作者随着写作有自己的风格。而这种风格，又会因为作品的选题对作品的人气产生相当大的影响。

题材选择不是"我喜欢什么"，而是"我的风格适合什么"。

---

## 题材选择三禁区（新人慎入）

> 起点编辑认证：以下三类题材，除非有十足经验，新人第一部书不要碰。

### 1. 武侠
- **原因**：读者从武侠书长大，珠玉在前，套路和角色塑造读者了如指掌
- **例外**：对武侠进行包装（如《诛仙》= 武侠言情包装成仙侠；《终极地狱》= 网游包装武侠）
- **同人捷径**：写知名作品同人，角色已有读者印象，不需重新描写角色

### 2. 科幻
- **原因**：硬核设定门槛高，读者专业度高期待严格
- **例外**：有专业背景或大量阅读积累的作者

### 3. 推理
- **原因**：逻辑严密性要求极高，漏洞容易被专业读者发现
- **例外**：有推理阅读积累或专业训练的作者

> **本质**：不是写不好，而是读者期待高（参照物是经典）。新人作品难以满足参照系 → 数据差 → 打击信心。

---

## 包装策略（降维打击）

当内心有某个题材梦想但感觉难度高时：

```
内心梦想题材 → 包装成 → 另一个题材
     ↓
降低读者参照系门槛
     ↓
更容易获得正向数据反馈
```

**成功案例**：
- 《诛仙》：武侠言情内核 → 仙侠包装 → 大爆
- 《终极地狱》：武侠内核 → 网游包装 → 大爆

---

## 风格即商业价值

不同的作者风格，适合不同的题材：

| 作者风格 | 适合题材 | 案例 |
|---------|---------|------|
| 文字优美、翻译体 | 欧洲中世纪历史 | 蓝晶《魔盗》 |
| 痞气放肆、快节奏 | 神魔/玄幻/都市 | 血红《邪风曲》 |
| 细腻情感、慢节奏 | 都市言情、历史古言 | 传统言情作者 |

> **风险提示**：风格强烈的作者写不熟悉的题材，主角容易"千人一面"——血红写任何题材主角都是痞气感觉。

---

## 题材适配自检表

在确定写哪个题材前，问自己：

1. 我最熟悉哪种叙事节奏？（快攻 / 慢热 / 张弛交替）
2. 我擅长写什么类型的人物？（痞气男主 / 隐忍型 / 成长型）
3. 我的读者画像是谁？（学生 / 白领 / 网文老读者）
4. 这个题材的读者期待是什么？（爽 / 虐 / 烧脑 / 甜）
5. 我的风格能覆盖这个期待吗？

> 答案不匹配 → 考虑包装策略，或换一个更匹配的题材。

## 起点读者画像（job-0034 · 运营实战补充）

> 来源：起点商业写作分析；是代入感设计的基准

### 读者是谁

> "起点的主流读者是十几岁到二十几岁的男性。"

代入感设计必须以这个画像为基准：
- 主角最好是：**年轻男性**（现代/都市/校园背景）
- 避免：女性/中年/非人类主角（除非变身/有依托）
- 如果必须写非人类主角：**变身成男性** 或 **以人类视角展开**

### "一人高"万金油法则

> 问：主角身高多少合适？答："一人高"。

- 任何具体的差异化设定（身高/年龄/外貌）都会让一部分读者无法代入
- "一人高"是个万金油——读者自己脑补代入感最强
- **同样适用于**：主角外貌描写要模糊化处理，不要写太详细

### 读者想实现什么

> "读者想实现：奇遇、升级、寻宝、泡妞、发财、欺人、助人。"

| 愿望类型 | 爽点设计 |
|---------|---------|
| 奇遇 | 金手指/特殊机缘 |
| 升级 | 实力跃升/境界突破 |
| 寻宝 | 捡漏/打脸夺宝 |
| 泡妞 | 美女倒贴/暧昧推进 |
| 发财 | 捡漏变现/逆袭 |
| 欺人 | 打脸/碾压 |
| 助人 | 收小弟/护短 |

### 商业禁忌

1. **主角不能是窝囊废**——读者来放松不是找罪受
2. **绿帽/贞操情节是大雷**——读者会反弹跑掉
3. **传统武侠代入感差**——古代思维与现代人脱节（支撑题材选择三禁区）

> **核心**：代入感是YY的前提。先让读者把自己代入主角，YY的快感才能传递。

## 与skill的整合

- **C-001 变化驱动力**：立意阶段就要确定主角"缺什么"——缺口越大，成长空间越大
- **P-001 价值翻转**：立意阶段要预设核心翻转点——读者期待什么场景下的主角翻盘
- **T-001 剧情收获推演**：立意阶段就要规划好"读者多久爽一次"的节奏密度

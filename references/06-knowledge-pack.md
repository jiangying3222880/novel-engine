# 写作技巧索引库（8 大核心分类）

写作时按需调阅，每章选 1-2 个分类参考。不是规则，是工具箱。

> 如果某个技巧在写作时落地困难，可在项目目录下创建 `knowledge/` 目录，为该技巧补充完整示范段落。格式见 `README.md` 的"可选：knowledge/ 自定义技巧库"章节。

---

## 1. 情绪高潮与爽点

核心逻辑：压抑→隐忍→反击→反转，爽感来自落差的瞬间释放。

| 技巧 | 说明 | 示例 |
|------|------|------|
| 三步递进 | 羞辱→隐忍→爆发，不跳步 | 被当众羞辱→咬牙不说话→三招内翻盘 |
| 延迟满足 | 读者越想要什么，越不立刻给 | 主角明明能反击，偏要等对方说完再动手 |
| 希望毁灭循环 | 给一点甜头→立刻打回去→更狠 | 刚拿到解药→发现是假的→但药引在仇人手里 |
| 沉默爆发 | 最强的反击是最短的 | 全场嘲讽，主角只说了一个字："来。" |
| 地位倒错 | 捕食者变猎物 | 考官发现考生是自己的恩师 |

## 2. 人物关系与感情戏

核心逻辑：嘴硬心软，身体背叛语言，利益纠葛制造羁绊。

| 技巧 | 说明 | 示例 |
|------|------|------|
| 空间压缩 | 把两人关在小空间里 | 暴雨、破庙、只剩一件干衣服 |
| 行动背叛 | 嘴上说不在乎，手先动了 | "别管我"——但她已经把伞递过去了 |
| 说反话暗示 | 用反话传递真实情感 | "你死了和我有什么关系"——但她一整夜没睡 |
| 敌意螺旋 | 从敌对到和解的弧线 | 刺杀目标→被迫合作→发现对方被冤枉 |
| 四类差异化 | 冰山型/烈火型/大地型/骄傲型 | 冰山型的关心是默默做事不说；烈火型是直接吵 |

## 3. 节奏控制与悬念拉满

核心逻辑：信息差是悬念的燃料，延迟揭示是悬念的拉力。

| 技巧 | 说明 | 示例 |
|------|------|------|
| 倒计时 | 给场景一个硬性时间压力 | 天亮前必须离开，否则…… |
| 波浪节奏 | 紧张-松一口气-更紧张 | 打完一波→刚喘口气→发现这只是前哨 |
| 冰山式悬念 | 只露 10%，藏 90% | 角色提到"那件事"但不说是什么事 |
| 悖论炸弹 | 用矛盾信息逼读者追问 | 死人寄来的信 |
| 洋葱揭示 | 层层剥开，每层都推翻上层 | 父亲是凶手→父亲是替罪羊→父亲是卧底 |
| 断崖章末 | 章末抛出最大悬念 | 门推开——站着本该死去的人 |

## 4. 日常推进

核心逻辑：日常不是废话，是侧面展现世界和角色的窗口。

| 技巧 | 说明 | 示例 |
|------|------|------|
| 小摩擦展世界 | 通过日常冲突展示设定 | 买东西纠纷暴露货币体系 |
| 短句为王 | 日常段落用极简短句 | 他进屋。倒水。坐下。没说话。 |
| 动作伴随对话 | 边做事边说话，不干聊 | "你确定？"她头也不抬，继续磨刀。 |
| 内心独白驱动 | 用角色的碎碎念推进 | （不是大段心理描写，是几个字的念头） |

## 5. 世界观构建

核心逻辑：侧面描摹，拒绝说明文，设定通过角色体验传达。

| 技巧 | 说明 | 示例 |
|------|------|------|
| 蚁穴视角 | 从小人物的日常展现大世界 | 通过一个佣兵的吐槽带出军队编制 |
| 感官锚定 | 用具体感官细节锚定世界观 | 空气中的灵气浓度——呼吸时肺里有冰碴子感 |
| 双向信息差 | 角色和读者对世界认知不同步 | 角色觉得正常的事，读者觉得诡异 |
| 技术细节 | 用伪科学细节增加真实感 | 不写"很厉害的法术"，写法力的运行路径 |

## 6. 反转揭秘

核心逻辑：意料之外，情理之中。70% 铺垫 + 30% 揭示。

| 技巧 | 说明 | 示例 |
|------|------|------|
| 认知颠覆 | 推翻读者已建立的认知 | 一直以为是盟友的人，其实从第一天就是棋子 |
| 70-30 法则 | 70% 线索提前铺设，30% 揭示时串联 | 前五章的"无关细节"在揭示时全部串联 |
| 伪反转 | 先给一个假答案，再翻真答案 | 以为是师父叛变→其实师父在保护→保护对象是自己 |
| 铺垫回收 | 揭示时必须让读者回想起前文 | 揭示时点明：还记得第三章那杯茶吗？ |

## 7. 黄金开头

核心逻辑：第一句话建立冲突，快速引入核心动机。

| 开局类型 | 说明 | 第一句话示例 |
|---------|------|------------|
| 倒叙穿越 | 从未来视角切入 | "三年后我才知道，那天她递的不是解药，是毒。" |
| 日常异常 | 日常中突然出现不对劲 | "早饭时，爹的手少了一根指头。" |
| 身份落差 | 开局就是身份巨变 | "圣旨到了。我不是进士，我是驸马。" |
| 危机开局 | 直接在危机中 | 刀架在脖子上的时候，他在想晚饭。 |
| 弱者开局 | 从最弱者视角开始 | 修炼者满天飞的世道，他连灵根都没有。 |

## 8. 反派塑造

核心逻辑：反派有自己的逻辑，不是为主角服务的工具人。

| 技巧 | 说明 | 示例 |
|------|------|------|
| 独立动机 | 反派有自己的目标，不是为了衬托主角 | 反派要的不是主角的命，是主角手里的地图 |
| 镜像对照 | 反派是主角的另一种可能 | 如果主角当初选了另一条路，就会变成他 |
| 合理手段 | 反派的手段符合其资源和身份 | 皇帝用政治手段，不用亲自下场打架 |
| 不可代替性 | 删掉这个反派，故事塌掉 | 他的存在推动了主角成长的每一个关键节点 |

## 调阅指南

- 打脸/逆袭/爆发场景 → 调阅分类 1
- 对手戏/感情线/试探 → 调阅分类 2
- 战斗/悬疑/章末钩子 → 调阅分类 3
- 过渡章/日常章 → 调阅分类 4
- 新场景/新设定出场 → 调阅分类 5
- 真相揭示/大反转 → 调阅分类 6
- 第1章/新书开头 → 调阅分类 7
- 反派登场/反派对决 → 调阅分类 8

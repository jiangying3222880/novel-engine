# 短篇文梗引擎库（Short Story Engines）

> **定位**：short-story.md 管"怎么憋怎么爆"（节奏层），本文件管"憋什么、怎么兑现"（引擎层）。两个文件互补，不重叠。
> **来源**：2026 上半年 2600 篇付费爆款分类语料精读（10 类代表全文/开头），全部为市场验证过的结构。

---

## 0. 元配方：情绪债务 × 兑现

**所有爆款短篇 = 同一个公式的变体：**

> **制造情绪债务 → 累积债务 → 一次性兑现**
> （情绪债务 = 读者替主角感到的委屈/愤怒/不甘；兑现 = 打脸/揭穿/反转/后悔）

每个"文梗标签"不是题材，而是**"如何制造债务 + 如何兑现"的配方组合**：

| 债务制造方式（免费区·前70%） | 兑现方式（付费区·后30%） | 对应标签 |
|------------------------------|-------------------------|---------|
| 以"为你好/避嫌/大义"之名牺牲主角核心利益 | 主角当众觉醒→离开/断亲/反打 | 避嫌文学、偏心、亲情虐 |
| 主角被骗/被绿，忍住不发作（暗中取证） | 掌握证据→当众揭穿（PPT/录音/质问） | 反套路女主、出轨流 |
| 主角/读者知道对方不知道的事（信息差） | 主角利用信息差反杀 | 弹幕流、心声流、偷听、错认、论坛体 |
| 主角死/假死/消失，施害者失去后才懂 | 施害者悔疯/赎罪 | 死人文学、假死 |
| 主角被系统/他人掠夺（成绩/资源/身份） | 重生→反杀掠夺者 | 转移系统、互换选择 |
| 开头抛反常识现象（房子消失/倒计时） | 追查→真相揭晓 | 卖关子、倒计时、微悬疑 |

**付费心理（为什么读者愿意付费）**：
- 免费区猛堆债务 → 在"最想看到兑现"处截停 → 读者为兑现付费
- 章末钩子 = 债务 +1（新证据/更深羞辱），**不是**爽点 +1
- 标题 = 承诺兑现类型（"悔疯了/杀疯了/慌了"），读者为承诺付费

## 1. 引擎卡模板（每条入池必填，缺一不可）

```markdown
### 引擎：〈引擎名〉
- **债务制造**：〈免费区怎么让读者憋，2-4 条具体动作〉
- **兑现方式**：〈付费区怎么释放，2-4 条具体动作〉
- **适配题材**：〈题材/文梗标签清单〉
- **硬约束**：〈3-5 条，违反即崩，如"弹幕必须给主角可用信息，不能纯装饰"〉
- **结构骨架**：
  - 开篇钩子：〈第一句怎么进冲突〉
  - 中段：〈债务怎么累积，按什么节奏〉
  - 付费点：〈在哪个位置截停，读者为什么付〉
  - 兑现：〈结尾怎么释放、释放后停在哪〉
- **代表样例**：〈已精读爆款：标题 + 一句话验证结论，不复制原文〉
- **组合提示**：〈可与哪些引擎/技法组合，例：+公开处刑=打脸文〉
```

## 2. 入池判断标准（不达标不入池）

| # | 判断项 | 通过条件 |
|---|--------|---------|
| 1 | 债务制造独特 | 制造方式与已有引擎不重复（不换皮） |
| 2 | 兑现明确 | 有清晰释放动作，不悬空（"她走了"≠兑现） |
| 3 | 可迁移 | 去掉具体人物/背景后，抽象结构可套用其他故事 |
| 4 | 市场验证 | 有已精读的爆款样例佐证（标题+结构结论） |
| 5 | 与节奏层不冲突 | 不破坏憋压三段式（不引入中段微爽/小反转） |

> ≥4 条通过 → 入池。自问：**写短篇时这张卡真的能指导我选引擎、写债务、写兑现吗？** 不能 = 卡不对。

## 4. 六引擎（初始版，按 §1 模板逐条精读后扩充）

### 引擎：信息差引擎
- **债务制造**：主角/读者知道对方不知道的事，眼睁睁看主角吃亏（弹幕剧透、心声暴露、错认身份）
- **兑现方式**：主角利用已知信息反杀（识破阴谋/抢先布局/当众点破）
- **适配题材**：弹幕流、心声流、偷听梗、错认梗、论坛体、知乎风
- **硬约束**：① 信息必须给主角**可用**反杀点，不能纯装饰；② 对方视角保持"不知道"（不泄底）；③ 信息获取方式要能自洽（重生/系统/弹幕，选一个锚定）
- **结构骨架**：开篇抛"主角突然知道 X"→ 中段主角借 X 暗中布局 + 对方继续作恶（债务累积）→ 付费点：布局将成/对方将踩坑前一刻 → 兑现：反杀 + 对方后知后觉
- **代表样例**：《弹幕说闺蜜要撬我男朋友》（弹幕剧透→主角反杀→全文 15 节全是"我知道你不知道"）
- **组合提示**：+公开处刑 = 信息差打脸文；+牺牲觉醒 = 重生避嫌文

### 引擎：牺牲觉醒引擎
- **债务制造**：主角被以"为你好/避嫌/大义"之名牺牲核心利益（生命/名额/工作/婚姻），还被道德绑架不许发作
- **兑现方式**：主角当众觉醒→拒绝/离开/断亲/反打；施害者后悔（情绪惩罚>物理惩罚）
- **适配题材**：避嫌文学、偏心、亲情虐、第二个家、白眼狼、学乖流
- **硬约束**：① 牺牲必须"合理包装"（避嫌/为你好），不能纯恶；② 觉醒要"当众"（有人看见才爽）；③ 兑现后主角不回头/留白，不复合不总结
- **结构骨架**：开篇一句进牺牲现场 → 中段累积牺牲次数/深度（每次"为你好"都更重）→ 付费点：觉醒前一瞬 → 兑现：当众觉醒 + 施害者崩溃/后悔
- **代表样例**：《为了避嫌，心脏被妈妈让给贫困生》（牺牲→当众觉醒→直播崛起→父母崩溃，结尾留白"原谅在下一个冬天"）
- **组合提示**：+死亡后悔 = 死遁文；+公开处刑 = 觉醒打脸文

### 引擎：死亡后悔引擎
- **债务制造**：主角死/假死/消失（或被判定死亡），施害者失去后才意识到主角的价值
- **兑现方式**：施害者悔疯/赎罪/崩溃；主角（若重生/系统视角）见证后悔
- **适配题材**：死人文学、假死、注销身份、替身文学
- **硬约束**：① 死亡要有"催化剂"（不公累积到阈值），不能无故死；② 后悔要具体（谁后悔、后悔什么、怎么表现），不能泛泛"全家哭"；③ 视角要能"看见后悔"（重生/系统/魂魄）
- **结构骨架**：开篇抛死亡/死亡倒计时 → 中段展示不公累积（每次"该让"都更过分）→ 付费点：死亡执行/死讯传开前一刻 → 兑现：死后全家后悔细节展开
- **代表样例**：《保送名额让给姐姐，我死后全家悔疯了》（系统死亡程序+不公计数→脑死亡→全家后悔）
- **组合提示**：+牺牲觉醒 = 亲人偏心死遁文；+信息差 = 死后真相揭开

### 引擎：掠夺反杀引擎
- **债务制造**：主角被系统/他人掠夺（成绩/资源/身份/命运），且掠夺被"合理化"（对方有靠山/规则允许）
- **兑现方式**：重生/换位后反杀掠夺者（让掠夺者自食其果）
- **适配题材**：转移系统、交换系统、互换选择、重生修正
- **硬约束**：① 掠夺机制要具体（什么被抢、怎么抢、代价是什么）；② 反杀要"利用机制本身"（不是单纯变强）；③ 重生锚点要早（在首次被掠夺前）
- **结构骨架**：开篇抛"主角重生/发现被掠夺" → 中段主角借机制反制 + 掠夺者继续得逞（债务累积）→ 付费点：反杀将成前一刻 → 兑现：掠夺者自食其果
- **代表样例**：《学渣同桌对全市第一的我使用了成绩掠夺系统》（毒糖融进粥让全校共享→掠夺者自食其果）
- **组合提示**：+信息差 = 弹幕+掠夺复合；+牺牲觉醒 = 重生避嫌文

### 引擎：反常识钩子引擎
- **债务制造**：开头抛反常识现象（房子消失/楼层变少/倒计时），主角是唯一执念者，被当疯子
- **兑现方式**：追查→真相揭晓（悬疑兑现，不是情绪兑现）
- **适配题材**：卖关子、倒计时、微悬疑、时空错位
- **硬约束**：① 反常识现象必须"可查证"（有线索链），不能纯故弄玄虚；② 主角执念要有代价（被孤立/被当疯子）；③ 真相要配得上钩子（不能烂尾）
- **结构骨架**：开篇抛反常识现象（第一句）→ 中段主角追查 + 阻力加深（债务累积=迷雾加深）→ 付费点：真相前一步 → 兑现：真相揭晓（不解释多余）
- **代表样例**：《刚交50万首付，我的房子长腿跑了》（18层消失→被当疯子→重生查真相）
- **组合提示**：+信息差 = 弹幕悬疑；+死亡后悔 = 死后真相文

### 引擎：公开处刑引擎
- **债务制造**：主角被欺骗/出轨/背叛，忍住不发作（暗中取证，表面若无其事）
- **兑现方式**：掌握完整证据→当众揭穿（PPT/录音/质问），施害者社交性死亡
- **适配题材**：反套路女主、出轨流、摊牌梗、装穷梗
- **硬约束**：① 取证要"可展示"（截图/录音/实物），不能只靠直觉；② 处刑要"当众"（有观众才爽）；③ 处刑后主角离开/放下，不回头
- **结构骨架**：开篇抛"主角发现证据" → 中段主角继续装无事 + 对方变本加厉（债务累积）→ 付费点：处刑现场前一刻 → 兑现：当众揭穿 + 主角转身离开
- **代表样例**：《前男友的出轨日记，在订婚宴上循环播放》（截图取证→订婚宴 PPT→转身离开→米兰珠宝展成功）
- **组合提示**：+信息差 = 取证流；+牺牲觉醒 = 觉醒打脸文

## 5. 与现有模式的关系（防冲突）

| 现有资产 | 关系 |
|---------|------|
| `references/short-story.md`（憋压三段式） | 节奏层：本文件是引擎层。所有引擎的债务段都走"憋压"节奏，兑现段走"大坝决堤" |
| `references/short-story-rhythm-origin.md` | 原理层：单情绪弧憋压是底层节奏，引擎选择不改变它 |
| `library/techniques/身份逆转反转法.md` | 组合实例：= 信息差引擎 + 公开处刑引擎的递进版（四层反转） |
| `library/techniques/` 其他通用技巧 | 通用方法论：引擎是短篇专用，技巧跨体裁可用 |

**写作时调用顺序**：触发词选引擎 → 按引擎结构骨架定章节节奏 → 中段债务走憋压 → 兑现走大坝决堤 → short-story.md 的硬约束/自检兜底。

## 6. 版权纪律（与拆书规范一致）

- 只学"结构编排手法"，不复制原文（引擎卡、结构骨架均为抽象，样例仅记标题+验证结论）
- 拆解产物是项目内部素材，不对外传播（语料自带"仅用做推文工作，请勿传播"标注）
- 入池片段（如需）≤ 原文 1%，且必须附"可借鉴点 + 迁移提醒"

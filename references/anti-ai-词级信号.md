## 6. 词级 AI 味信号（诊断 → 真人引导，不是禁止）

> **定位**：本技能理念是**正向引导**——真人怎么写，我们照着学底层逻辑（见 §2 对照式真人示范 + 本书 `素材池/author_dna/` 真人样本）。本节词级清单**不是"禁词表"**，而是**诊断信号**：检出这些词 = "这里可能词假了"，处理方式是**回到真人范例，看同类场景真人怎么写，借鉴其底层逻辑**。禁止≠目标，引导=目标。
> **来源**：信号清单吸收自《AI 写作禁令》（网传技能），但弃用其"机械禁用"路线——实测证明它误伤合理描写（如"铁片**黑沉沉**"是正常质感、对话里"不是/没有"极常见）。

### A 级 · 破墙/提纲味连接词（正文硬纪律）

- **破墙词**：`男主` `女主` `主角`（正文里称呼人物直接用名字/身份，破墙=退出叙事）
- **提纲味连接词**：`说白了` `换句话说` `简单来说` `不难发现` `总而言之` `综上所述`
- **定性**：这是"正文必须像正文"的正确性纪律，不是风格偏好——出现即破墙/提纲，必须改写。

### B 级 · 高频 AI 味描写词（信号 → 回真人范例借鉴）

**检出即信号**：说明此处描写落入了 AI 常见词库，词是"贴标签"而非"落到具体行为"。
**处理（引导，不是替换）**：回到 §2 真人示范（或本书 author_dna 真人样本），找**同类情绪/场景真人怎么写** → 借鉴其底层逻辑改写。

| 信号词（词假倾向） | 真人怎么写的底层逻辑（引导方向） |
|------|------|
| 指节泛白 · 指尖发白 · 洗得发白 · 咬着下唇 · 脚钉在地上 · 眉头紧皱 · 瞳孔缩紧 | 紧张/用力 → 真人写法是"连续的具体动作链 + 身体局部特写"，不是堆情绪标签。例：`攥着铁片，指尖发白，膝盖一软` → 看真人示范里"手背青筋鼓起来""喉咙挤出闷声"这类**动作+声响**组合 |
| 目光平淡 · 神色平淡 · 沉沉 · 压抑 | 情绪/氛围 → 真人写法是"落在环境与旁人反应上"，不直接给心理形容词。例：`气氛压抑` → 真人会写"没人说话，只剩远处一声钟响"（§2 示范B 硬科幻就是这逻辑） |
| 仿佛 · 仿佛要 | 比喻出口 → 真人少用"仿佛"直给，多用具体意象或直接陈述 |
| 不容置疑 · 不容忽视 · 狠狠的 · 狠狠地 · 彻底 · 瞬间 · 顿了顿 · 缓缓 · 机械地 | 程度副词堆砌 → 真人用**具体动作/后果**表达强度，不靠副词强调。例：`彻底失败` → `连爬都没爬起来` |
| 清晰的认知 · 认知 · 献祭 · 仪式 · 极度的 · 到了极限 · 生命力 · 前所未有的 · 难以言喻的 · 难以名状的 · 每一步 · 每一次 · 极致 · 到极点 | 抽象程度词 → 真人写极端用**身体/感官/场景具体化**：极致愤怒 → `青筋从颈侧鼓起来`，前所未有的恐惧 → `腿软到站不住` |
| 语气平静得像 · 语气平静的就像 · 语气平淡得像 · 再说今天的天气 · 声音不大却异常清晰 · 带着...特有的... | 声音状态模板 → 人物状态改用**动作、呼吸、伤势、器物、站姿、旁人反应**来写，不套声音公式 |

> **引导步骤**（检出信号后必走）：
> 1. 在 §2 四类真人示范 / 本书 author_dna 真人样本里，找**同情绪同场景**的段落；
> 2. 提炼其底层逻辑（动作链？环境烘托？感官细节？留白？）；
> 3. 按该逻辑重写该处，不照搬原句、不机械换同义词。

### C 级 · 标点密度（参考真人标点习惯）

- `——` `……` `。。。` 密度 ≥3 处/千字 → 对照真人文本：真人多用短句、换行、具体停顿描写，破折号/省略号克制（对话里表迟疑的"……"可保留 1-2 处）。
- 判定按"密度"不按"存在"——避免误伤正常对话停顿。

### D 级 · 禁句式（诊断 → 回真人改写）

**检出即改**：这些解释腔/导演腔结构在正文中反复出现，说明作者在"讲"故事而不是"演"故事。

| 禁句式 | 诊断含义 | 改写方向 |
|--------|---------|---------|
| `那不是...是...` `这不是...这是...` `不是...而是...` `并非...而是...` `不再是...而是...` `与其说...不如说...` `如同是...` | 解释腔，判断句直接下结论 | 删除解释句，直接写行为/后果；或改成疑问让角色来回答 |
| 连续写 `他意识到` `他忽然发现` `他这才明白` | 全知视角复盘，主角像旁观者 | 改用有限认知：主角只能观察到表面，具体含义留给读者 |
| `当...的时候` `在...之后` `这使得他` `他对此感到` | 导演腔推进，时间跳动用动作/事件而非说明词 | 改用具体事件和动作：不说"然后他开始修炼"，写他翻开书、盘腿坐下 |
| 三个以上同开头、同句式、同语法结构连续出现（严格排比） | 机械结构，节奏失衡 | 打散句式，用问题/递进/场景变化/人物反应来重组 |
| 禁导演腔：先是 / 再是 / 最后 / 紧接着 / 然后 / 再然后 / 只见 / 又见 / 顿了顿 / 缓缓 | 镜头调度词，牵着读者走 | 改成直接动作、冲突、反应和后果 |

1. A 级=正文正确性硬纪律（破墙/提纲必须改）；B/C 级=诊断信号，**处理一律回到真人范例引导，禁止机械替换**。
2. 词级信号**叠加**在三大模式之上（§1）与真人对照（§2）之上：模式级解决"结构假"，词级解决"用词假"，真人引导解决"怎么改"。
3. 信号清单是"起点"非"穷尽"：每章落库若发现新的高频 AI 味词，登记入清单并补一条"真人怎么写的底层逻辑"。
4. **引导优于禁止**：任何"禁词"如果连真人文本都会正常使用，就不该出现在清单里（如否定词、黑沉沉这类质感词）。

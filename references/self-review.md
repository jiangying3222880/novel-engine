# 阶段③：行为验证自检协议

## 0.0 硬冷切换（进入自检前强制）

> 同一个 Agent 刚写完正文，最容易带"作者思维"进自检（自卖自夸）。进入读者通道前，先停一版、做一次认知切换，再读正文。以下两类问答在"读者先读"和"编辑再审"前各做一次，回答后再往下。

**A. 进入"读者通道"前（先答，再读正文）**
1. 我手里现在**只有本章正文**吗？（若还握着细纲/真相/伏笔表 → 先放回）
2. 只从正文看，这是什么类型的书？
3. 开篇后我的**第一直觉感受**是什么？（不引用任何作者意图）
4. 我读到哪**想往下翻**？哪**想跳**？（读者只报体验，不给解法）

**B. 进入"编辑通道"前（读完正文后、审阅前）**
1. 我的判断基于**正文 + 元数据**，有没有把"读者感觉"误当"留存依据"？
2. 主角五项 / 前100字 / 连载风险里，哪些是**文本证据**支持、哪些只是"我写的所以我以为好"？
3. 我给的是**修改方向**（编辑管"改不改、往哪改"），不是直接动笔（动笔交阶段④作者身份）。

## 0. 身份双通道自检（功能六 + 功能二 融合）

> 功能二身份路由 + 豆包 editor-perspective 融合。自检从单一"行为验证"升级为**读者(体验) × 编辑(留存) 双通道**，并加成因层诊断 + 准出评分 + 一票否决。

### 0.1 双通道（顺序固定：读者先读，编辑再审）

1. **读者通道（体验）**：以读者身份第一遍直觉读正文，报告：弃书点 / 卡顿 / 出戏 / 代入感。读者只报体验，不给解法。
2. **编辑通道（留存）**：以编辑身份审阅：前100字硬指标 / 主角五项（目标/困境/主动/人格/制造剧情）/ 前500字与第一章 / 核心设定能否反复制造冲突 / 前三章小闭环 / 差异点 / 连载风险 6 项。

### 0.2 准出评分（编辑通道量化）

每个维度 1-5 分，合计得 AI 味指数参考值 + 留存分：

| 维度 | 1-5分 |
|------|-------|
| 前100字留存 | （人物/事件/冲突/悬念 ≥2项） |
| 主角主动 | （有目标/困境/行动） |
| 冲突升级 | （是否比上章多一层代价） |
| 情绪回报匹配 | （爽/甜/虐/燃/悬念是否匹配铺垫） |
| 连载风险 | （风险越少分越高） |

### 0.3 一票否决（任一命中直接打回重写，不进评分）

- 卖点未落地：简介承诺的爽点/类型正文没兑现
- 主角连续 2 章零台词（B 回填：台词配额检查）
- 真死角色在当下时间线以活人身份出场（功能七校验）
- 前 100 字无任何"人物/事件/冲突/悬念"

### 0.4 与成因层联动

自检检出 AI 味问题时，用 
references/anti-ai.md 第 0 节的**成因层表**定位"哪层假"，再决定改法；用 AI 味指数五档决定改写强度。

## 核心原则

**自检不是"自夸"，是"行为检测"。**

不要问自己"我写得好不好"，要检测：**正文中是否存在某种可观察的行为模式。**

每一问的验证逻辑：
1. 先检测"有没有问题行为"
2. 如果有 → 引用原文片段作为证据
3. 如果没有 → 引用一段"体现了相反好行为"的原文片段作为反证

无证据引用的"通过"一律判定无效。

---

## 证据格式

`source: [角色名/场景名/段落位置] excerpt: [原文片段]`

示例：
```
evidence_ids:
  - source: 方若华 excerpt: 她的手指一直在透明板上滑，红光印在她眼镜镜片上
  - source: 章末 excerpt: 门推开——站着本该死去的人
```

## 自检 4 问

### Q1：章节出口（自然未完状态检测 · v1.4.1）

**检测行为**：读者翻页时，当前叙事是否处在一个**自然的未完状态**？允许平静出口，不硬造悬念。

- 验证步骤：
  1. 找到章末最后 3 段
  2. 问：这一刻故事**停在哪里**了？是"动作未完 / 信息刚揭开 / 决定刚做出 / 新问题出现 / 场景切断 / 后果尚未显现"中的哪一种？
  3. 若处于自然的未完状态 → 通过，引用那段原文
  4. 若只是把事件讲完、或收束情绪 → **不一定未通过**，问：停在这里是"顺其自然的停"，还是"为制造悬念硬停"？顺其自然 → 通过；硬造悬念 → 未通过

- **不通过信号**：
  - 章末是情绪总结（"他心里久久不能平静"）
  - 为了"必须留钩子"而硬加一个与本章无关的悬念（流水线式章尾）
  - 只有当章节类型本身要求悬念（卷末/大冲突切口）时才强制要钩子

> 落点类型（开/合/转）去重检查由 check_text.py 相邻3章校验承担，本章只管"停得自然"。

---

### Q2：OOC 检验（声线行为检测）

**检测行为**：本章角色的关键对话和决策，是否落在 `故事/真相/characters.md` 的基线摘要范围内？

- 验证步骤：
  1. 提取本章每个主要角色的 2-3 句关键对话/关键动作
  2. 对照基线摘要的"硬边界"：有没有做了基线说"不会做"的事？
  3. 对照基线摘要的"情绪光谱"：本章状态是否在光谱范围内？
  4. 如果声线存疑 → 去读 `设定/角色声线.md` 完整档案深抠
  5. 全部在范围内 → 通过，引用关键对话/动作作为证据
  6. 有超出 → 未通过，指出哪句话/哪个动作越界了

- **Q2a 补充：声线区分度盲读（v1.4.1）**——验证"角色已形成自己的行为指纹"，而不只是"没越界"。
  - 遮住对话前的角色名 + 人物标签 + 明确身份说明，只保留动作 / 台词 / 反应 / 叙述。
  - 问三个问题：
    1. 刚说这句话的人是谁？
    2. 刚做这个动作的人是谁？
    3. 如果删掉名字，两个角色会不会互换？
  - 判定：能分辨 ≥2 个主要角色 → 区分度成立；遮名后分不清是谁 → 声线撞衫，需打散（用词/句式/节奏任一层拆开）
  - 证据格式照旧：`source: 遮名盲读 excerpt: 原文台词片段 -> 断定是 [角色X]`
  - 与 Q2 的区别：Q2 查"是否违背设定"（消极防错），盲读查"是否已有辨识度"（积极防瘫）。两者互补，不合并为总分。

- **不通过信号**：角色说出了与基线矛盾的话（如基线"极短句+不说教"但本章角色说了一段大道理）；或遮名后无法分辨两角色的话谁是谁（撞衫）

---

### Q3：质感检验（三大模式行为检测）

**检测行为**：逐段扫描，三大 AI 味模式各命中了几处？

参照 `anti-ai.md` 的检测标准：

| 模式 | 检测行为 | 命中标准 |
|------|---------|---------|
| 乒乓球短句 | 数连续对话轮次 | 连续 ≥4 轮，每轮 ≤5 字，无动作穿插 |
| 段末升华 | 找段尾总结句 | 段尾有"这一刻/终于/他知道/仿佛/就像"等句式 |
| 解释腔 | 找解释性连接词 | 有"因为……所以……""也就是说""其实"等，或角色在科普设定 |

- 验证步骤：
  1. 逐段扫，每类模式分别计数
  2. 命中 0 处 → 通过
  3. 命中 1-2 处 → 有瑕疵但可放行，标注位置
  4. 命中 ≥3 处 → 未通过，必须修改

- **注意**：不是所有"解释"都算命中。**读者自己能推断出来、且删了不影响理解**的解释才算。必要的信息交代不算解释腔。

---

### Q4：因果与情绪落地（感官行为检测）

**检测行为**：
1. 本章开头是否有与上一章衔接的具体句子？（不是"上一章发生了X"，而是通过动作/对话自然带出）
2. 本章高潮段落是否有感官细节（触觉/听觉/视觉/味觉/嗅觉），而不是纯情绪词？

- 验证步骤：
  1. 找本章前 5 段：有没有与上一章因果衔接的具体句子？
  2. 找本章高潮段：有没有感官细节？还是只有"他很愤怒/恐惧/激动"？
  3. 两项都有 → 通过
  4. 缺任意一项 → 未通过

- **不通过信号**：
  - 开篇是纯回顾/总结，没有通过场景自然衔接
  - 高潮段满是情绪词（"心中掀起惊涛骇浪"）但没有具体的感官描写

## 修正循环规则（最多 3 轮）

### 规则

1. 第一轮自检 → 未通过 → 修正 → 第二轮自检
2. 第二轮仍未通过 → 再修正 → 第三轮自检
3. 第三轮仍未全部通过 → **停止修正，输出当前最佳版本**

### 为什么要停

继续无限修正可能出现**越改越差**：
- 为了通过 Q3（质感）把情绪全删了，人物变成木头
- 为了通过 Q1（翻页欲）硬加一个悬念，破坏了本章节奏
- 来回修改导致整体风格碎片化

### Best Version 保留机制

每一轮自检后，给当前版本打一个**粗略的综合分**（1-10分，凭整体感觉，不需要精确）。修正过程中始终记录：

```
第1轮：[分数] ← 当前最佳
第2轮：[分数]
第3轮：[分数]
```

3轮结束后，**输出分数最高的那一轮版本作为最终正文**，不一定是第3轮。

> 例：第2轮得分最高（8分），第3轮反而降到7分 → 输出第2轮版本

### 最终状态标记

3轮后如果仍有未通过项，在 Frontmatter 的 `review_status` 字段标注：
- `full_pass` — 4/4 全部通过
- `partial_pass` — 3/4 通过，剩余 1 项有瑕疵但可放行
- `needs_human_review` — ≤2/4 通过，需要作者重点审稿

> 注意：这个标记是给作者的提醒，不是"不合格打回"。作者最终审稿决定用不用。

## 跨章一致性检查（每 5 章一次）

每写完第 5、10、15 章…额外执行：
- 翻阅最近 5 章 Frontmatter 的 `change_summary` 和 `emotion_arc`，检查情绪是否断裂
- 检查 `故事/真相/hooks.md` 中 active 超过 10 章未推进的钩子（标记"伏笔债务"）
- 对照 `故事/真相/characters.md` 基线摘要，检查角色声线是否跨章漂移

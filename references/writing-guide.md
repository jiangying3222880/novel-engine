# 阶段②：正文写作指南

## 手法规则注入（生成前 · Author DNA 驱动）

> 写作前先注入 `素材池/author_dna/{书名}_dna.md` 的手法规则（10 类），**先定"怎么写"再动笔**——不是写完再改。

- 注入对象：手法规则 10 类（让步转折 / 原因后置 / 钩子预告 / 具体锚点 / 心理外化 / 口语混入 / 短段 / 收束方式 / 对话夹叙 / 助词习惯）
- 注入方式：读 author_dna 的手法规则节，写作时逐类对齐；**学"怎么写"，不抄任何句子**
- 强度对齐：按规则标注的频率（高/中/低）控制使用强度，**不要每条规则都拉满**——过度执行会产生新的漂移
- 收束铁律：章末/段末落到具体物件或朴素判断，**禁止"要变个样了"式空泛升华**
- 无 author_dna 时：跳过本节，用下方"写作质感示范"兜底

> 与 `references/human-signal-zh.md`「手法规则注入」模板配套使用。

## 1. 冰山法则（留白原则）

默认读者看过同类型作品，具备全部背景常识。

- 避免通过对话或旁白解释设定（引导：倾向用行为/结果呈现设定，让读者自己体会）。角色不会对同行科普"量子烙印是什么"。
- 遇到复杂概念，只写物理结果，不写科学原理。
- 读者不需要知道服务器怎么炸的，只需要知道"屏幕红了，数字在掉"。

**对比：**
- 解释腔：周蔓说"因为反上传分子炸毁了B3层服务器，E-2208的数据正在丢失，如果不处理她会崩解。"
- 冰山法则：周蔓的手指在虚屏上快得拉出残影，眼睛死死咬着红色错误代码。"不是单点故障，B3节点整片都在爆，算力池出了个天坑。"

## 2. 章态构建（每章必做）

为本章出场的每个角色生成 3-4 行声线章态，写在阶段①规划清单中：

```
角色名｜当前情绪状态｜语言节奏变化（vs基线）｜口癖/习惯变化｜动作泄露
```

**章态必须落在角色基线的情绪光谱内。** 超出光谱 = OOC = 打回重写。

基线档案存在 `设定/角色声线.md`，新角色首次登场时建立。

## 3. 对话不对称三原则

**原则一：答非所问**
人在极度焦虑、专注或有心事时，很少顺着对方的话茬回答。
- 韩铮问数据，周蔓回答技术细节——因为她此刻的优先项是系统，不是他的焦虑
- 韩铮拍控制台说"我问的是小安"——他不接技术话题，强行拉回自己的优先项

**原则二：动作打断语言**
台词必须穿插物理世界动作，不是空对空朗诵。
- 周蔓说话时手指不停 → 停手 → 摘眼镜 → 揉眼眶 → 才开口说关键信息
- 动作节奏控制对话节奏：急速动作配急速台词，停顿动作配沉重台词

**原则三：声线不对称**
避免让不同角色的用词习惯与句式节奏对齐（引导：声线靠用词/句式/节奏区分）。如果两个角色说话像同一个人，说明声线没分开。
- 科学家：术语密集 + 俗俚混杂 + 复句（"算力池出了个天坑"）
- 军人：动词多 + 极短 + 指令化（"我问的是小安"）
- 儿童：具象追问 + 跳切话题（"苹果为什么没味道"）

## 4. 嘴心 5 问（重点对话戏隐式思考）

当编写角色对峙、试探或高密度对话时，先在内部解答：
1. **表象**：嘴上在说什么？
2. **真意**：内心真实意图是什么？
3. **谎言**：他在试图对自己掩盖什么？
4. **回避**：双方极力避免提及的真相是什么？
5. **叛变**：身体哪个小动作暴露了真意？

台词只写"表象"，用动作暗示"叛变"，用节奏控制暗示"回避"。"真意"和"谎言"永远不直接写出。

## 5. 写作质感示范（Few-shot 样本）

以下是目标质感，写作时以此为标杆：

**示范A：科幻危机对话**
> 周蔓的手指在虚拟屏上快得拉出残影，眼睛死死咬着那一列狂跳的红色错误代码，连头都没回："不是单点故障，B3节点整片都在爆，算力池出了个天坑。"
> 韩铮往前跨了一步，手掌拍在控制台边缘："我问的是小安。"
> 周蔓这才停了手。她把眼镜摘下来，揉了揉眼眶，声音沙哑："E-2208在倒流。照这个速度，半小时后她传上去的那大半截就全白费了——韩铮，她会变成一张空皮。"

关键点：答非所问（韩铮不接技术话题）、动作打断（手指→停手→摘眼镜→才说关键句）、声线不对称（周蔓术语+俗俚 vs 韩铮极短指令）、段末落在具象比喻（"空皮"）而非抽象总结。

**示范B：日常情感**
> 小安把苹果举到他面前："爸爸，苹果为什么没味道？"
> 韩铮接过来咬了一口。没味道。他嚼了两下，咽下去，说："甜的。"
> 小安看着他的脸，没说话。

关键点：不解释"上传后味觉退化"的设定（冰山法则）、动作暗示真意（"没味道"三个字独立成句=真实感受）、儿童声线（追问非核心细节）、段末落在沉默上，不升华。

## 6. 正文元数据（v1.4 索引驱动 · 正文无 YAML）

## 7. 节奏控制

- 每章按 config 字数目标
- 每 500 字左右一个小钩子或情绪转折
- 章末留悬念或情绪未完感，禁止圆满收束
- 对话段与叙事段交替，避免大段纯对话或纯描写

## 8. 人物深度与叙事技法（story-guide 并入 · 规划功能六）

> 写正文时逐条对照。每条是"检查项"不是"必选项"——按场景取用，避免机械套用。

| # | 维度 | 要求 | 反例 → 正例 |
|---|------|------|------------|
| 1 | 人物有成长背景，非身份标签 | 角色是"有来路的活人"，不是"剑修/皇女/神医"的标签集合 | "她是神医（标签）" → "她父亲死在时疫里，从那以后她见不得人白受罪（背景）" |
| 2 | 对白有潜台词·延宕 | 对话不直给答案；答非所问、停顿、转移话题都是信息 | "我不去。（直给）" → 沉默三息："你非让我说难听的？"（延宕） |
| 3 | 叙事有详略 | 关键帧详写，过渡段一句带过；不平均用力 | 全程平铺 → 打斗只写"刀锋贴着他咽喉停住"三帧，赶路一句带过 |
| 4 | 动作有关键帧，非连续慢动作 | 动作只写转折帧，不写"抬手→挥下→击中"全程 | 慢动作流水账 → 只写"出手前那一瞬的眼神"（关键帧） |
| 5 | 叙述者认知匹配年龄·人设 | 儿童不写权谋内心、粗人不写文绉比喻；知识边界即人设边界 | 村童分析朝堂博弈 → 村童只看得见"那人笑得假" |
| 6 | 句子疏密有功能 | 短句提速/施压，长句铺陈/舒缓；疏密服务情绪 | 全篇均匀 → 紧张处三字一顿，松弛处长句舒展 |
| 7 | 环境·闲笔服务情绪关系节奏 | 天气/陈设/闲笔都指向当下情绪或关系张力，不写空景 | 为写景而写景 → "窗纸被雨打得发白，屋里两个人都没点灯" |
| 8 | 结尾避免意象金句 | 章末落"具体的动作/声响/画面"，不升华成金句 | "那一刻，他知道自己再也回不去了。（金句）" → 段末落物（见 anti-ai 原则四） |

## 字数硬校验（阶段② 验收线 · v1.4 修正）

- 每章正文必须落在 `novel-config.json` 的 `target_word_count` **±15%** 区间内（例：target=7000 → 5950 ~ 8050 字）
- 不足区间下限 → 扩写后重检（补场景细节/对话延展/支线），不达标不进阶段③
- 超出上限 → 精简冗余，不注水
- `check_text.py` 可观测字数；写作前先按目标字数 × 节拍密度系数做字数分配（见细纲模板）
- 这是"字数未确认就开写、产出不符合设定篇幅"的根因修复
- **验收标准由 target_word_count 动态计算（±15%），config 不存区间；用户给区间（如6000-8000）→ target 取中点（7000）**

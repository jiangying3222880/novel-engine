# 模块注册表（Module Registry · Agent 调度版 · v1.8）

> 定位：L3 模块调度卡。**只给 Agent 读**（调度决策用）；用户决策信息见 `module-说明书.md`（初始化提问/用户询问时才读，常驻不读）。
> 上游：SKILL.md 模块路由表（挂载铁律）· `references/project-setup.md` Step 5.6（初始化确认）
> 下游：阶段②写作（按卡决定加载什么）· 阶段⑤落库（按卡决定跑什么）

## 0. 模块卡七字段（缺一不可，不填卡不挂载）

| # | 字段 | 谁读 | 内容 |
|---|------|------|------|
| 1 | 触发类型 | Agent | 显式（用户点名）/ 状态（项目状态命中）/ 周期（流程锚点）/ 默认关（可显式开启） |
| 2 | 具体条件 | Agent | 触发该模块的精确条件（触发词/状态/锚点） |
| 3 | 适用范围 | Agent | 仅长篇 / 仅短篇 / 两者（Obsidian/ZVEC/拆书 = 仅长篇，短篇自动跳过并说明） |
| 4 | 运行依赖+降级 | Agent | 依赖什么（软件/SDK/工具）；缺失时怎么降级（不静默、明示提醒） |
| 5 | 副作用 | Agent | 执行后改了哪些文件/状态（防 Agent 不知副作用乱触发） |
| 6 | tokens 消耗 | Agent+用户 | 高 / 中 / 低（只标档位，不标精确数值——用户只需有个底） |
| 7 | 作用说明+使用依赖+推荐档位 | 用户 | 白话作用、需要装什么才能用、建议启用场景（详见说明书） |

## 1. 触发分类

| 分类 | 含义 | 例子 |
|------|------|------|
| 显式 | 用户明确点名才触发 | "写个短故事""外包写" |
| 状态 | 项目状态命中自动触发 | config.modules 开启 Obsidian → 每5章全量对齐 |
| 周期 | 流程固定锚点触发 | 初始化时拆解对标书 |
| 默认关 | 默认不加载，用户显式开启 | Obsidian 总览 / ZVEC |

## 2. 已挂载模块卡

### M-001 短故事模式
- 触发类型：显式
- 具体条件：用户说"写个短故事/短篇/单篇完结/抖音推文风/这个故事短一点/几十分钟听完那种"
- 适用范围：仅短篇
- 运行依赖+降级：无依赖
- 副作用：不建项目/不初始化 truth/不拆书/不维护章节索引（走 short-story.md 轻量分支）
- tokens 消耗：低
- 作用说明+使用依赖+推荐档位：见说明书 §M-001

### M-002 外包写作（Chat-Outsource）
- 触发类型：显式
- 具体条件：用户说"外包写作/这章用网页chat写/给我提示词我拿去写/外部写手"
- 适用范围：长篇（短篇一般不需要）
- 运行依赖+降级：无依赖（外部 chat 由用户提供）
- 副作用：阶段①照跑→编译自包含提示词→外部写→贴回走③④⑤；④必须跑满
- tokens 消耗：低
- 作用说明+使用依赖+推荐档位：见说明书 §M-002

### M-003 对标书拆解（素材池）
- 触发类型：周期（初始化）+ 显式（中途补充对标书）
- 具体条件：初始化 Step 4 用户提供对标书（书名/文本文件）；或中途"再拆一本"
- 适用范围：仅长篇
- 运行依赖+降级：无依赖；池子由 Agent 自动拆解（快速预览→用户确认→深度拆解）
- 副作用：创建 `素材池/` 目录（planner/author_dna/reference/samples/techniques），影响阶段①推荐加载
- tokens 消耗：中（档位：轻量2-3KB / 标准4-6KB / 全量8-12KB 每章）
- 作用说明+使用依赖+推荐档位：见说明书 §M-003

### M-004 Obsidian 叙事总览
- 触发类型：默认关 + 周期
- 具体条件：config.modules.obsidian_overview = true；正文每章 → 增量更新 `叙事总览/`；每 5 章全量对齐一次；每卷结尾结构复核
- 适用范围：**仅长篇**（短篇不建总览，自动跳过并说明）
- 运行依赖+降级：**需用户本机安装 Obsidian 软件 + 手动把叙事总览目录加入知识库**，否则总览只是普通文件夹；未装时降级=总览仍生成但无双链视图，**明示提醒**"要完整体验需装 Obsidian 并加入知识库"
- 副作用：写/改 `叙事总览/` 下所有文件（角色卡/关系/地点/hooks/时间线）；每5章全量对齐会重写旧条目
- tokens 消耗：中
- 作用说明+使用依赖+推荐档位：见说明书 §M-004（含短篇不建议启用提醒）

### M-005 ZVEC 检索
- 触发类型：默认关
- 具体条件：config.modules.zvec = true；阶段⑤落库时 `python runtime/index.py build`
- 适用范围：**仅长篇**
- 运行依赖+降级：需安装 zvec SDK；**缺失时策略：不自动安装**——自动降级 BM25+FTS（必跑），日志明示"ZVEC 未安装，已降级 BM25；如需安装请告知，我给你安装命令"
- 副作用：构建/更新 ZVEC 索引文件
- tokens 消耗：低
- 作用说明+使用依赖+推荐档位：见说明书 §M-005

### M-006 拆书模块（拆解方法论/拆书规范）
- 触发类型：显式
- 具体条件：用户要求拆书、分析某本书、按拆书模板输出
- 适用范围：仅长篇（短篇拆书走 short-story-engines 的引擎精读，不建池）
- 运行依赖+降级：无依赖；执行 `templates/pools/拆解方法论.md`（拆书前必读）+ `拆书规范.md`（判断标准）
- 副作用：产出拆书报告；若入库则写 `素材池/`（与 M-003 共用）
- tokens 消耗：中
- 作用说明+使用依赖+推荐档位：见说明书 §M-006

### M-007 多窗口执行
- 触发类型：默认开（auto）
- 具体条件：宿主有子 Agent/spawn 能力时启用；无则按 `execution-modes.md` 降级 single（显式声明）
- 适用范围：两者
- 运行依赖+降级：宿主能力；降级机制见 `references/execution-modes.md`
- 副作用：各阶段产物落盘交接（规划_第000X章.md / 自检_第000X章.md）；truth 写入集中在阶段⑤
- tokens 消耗：—（这是执行架构，不按模块计）
- 作用说明+使用依赖+推荐档位：见说明书 §M-007

## 3. 挂载门禁（新增模块流程）

1. 填满七字段卡（字段缺失 = 不挂载）
2. 触发条件必须**可判定**（Agent 执行时能明确判断命中/未命中，不能"大概"）
3. 有副作用必须写清副作用（防乱触发）
4. 适用范围必须标（仅长篇/仅短篇/两者）
5. 有运行依赖必须写降级路径（不静默、明示提醒）
6. 挂载后回填 SKILL.md 模块路由表 + 本文件 §2 + 说明书对应节

> 新增模块未走此流程 = 不是正式模块，Agent 不得自动加载（C-007：流程层才允许硬规则，模块挂载属流程层）。

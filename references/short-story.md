# 短故事创作模式（Short Story）

> 底层节奏 = 单情绪弧憋压爆发。不建项目、不初始化 truth、不拆书建池、不维护章节索引。

## 0. 底层节奏原理

**单情绪弧：憋压积蓄 → 彻底爆发**

```
第一句 → 信息量爆炸 + 读者被钉住
    ↓
中段全程 → 压、压、压（委屈/困境持续叠加，不释放）
    ↓
中后段 → 压到临界点（微光/忍无可忍的前奏，不是爽）
    ↓
高潮爆发 → 全部情绪一次宣泄，读者跟着炸
```

**字数自适应**：8000字憋紧凑，30000字憋更深的层次，节奏本质不变。

## 1. 何时启用（触发词）

| 用户指令 | 判断 |
|---------|------|
| "写个短故事""短篇""单篇完结""抖音推文风""这个故事短一点" | → 进入本模式 |
| "写下一章""继续写""规划第X章"（已有项目） | → 走五阶段 SOP，不进本模式 |

## 2. 三段式生成流程

### 段一：高压注水开场（前 300-500 字）

**第一句 = 直接进憋屈状态，禁止铺垫背景/天气/心情。**

❌ 平淡："我叫王磊，今天是丈母娘的生日。"
✅ 爆发："从那天起，我再也没抬起过头。"

第一句把读者直接按进情绪里，让他想问"然后呢"。

### 段二：憋压蓄力（中段，按字数自适应）

**核心原则：只压，不释放。**

- 每段都是憋——困境加深、委屈加大、尊严继续被践踏
- **禁止中段设置微爽/小反转**——快感留到结尾一次给
- 允许：忍无可忍的前奏（蓄力，不是释放）
- 字数长就憋更深的层次，不靠反转给糖

### 段三：大坝决堤爆发（结尾 1000-2000 字）

**全部情绪一次性宣泄。**

- 爆发可以是：身份揭露/行为反击/真相公开/情绪宣泄
- 爆发后不停，留白/断在情绪最高点
- **禁止爆发后加总结/感慨/反思**（情绪断了就不值钱）

## 3. 硬约束（铁律，写前必读）

- **事实锚点**：关键数字/物品/关系不得串（例：金额/身份设定）
- **声线边界**：每个角色的说话风格不漂（例：丈母娘=刻薄嘲讽，老婆=冷漠嫌弃，主角=内心吐槽役）
- **红线**：擦边只写反应不写器官；不暴露主角知道的事
- **禁止**：中段有任何微爽/小释放；结尾停在感慨/总结里

## 4. 自检（写完检查）

**2问行为验证（每问附 evidence_ids）：**

1. **情绪憋到位了吗？** — 标注正文中"最憋的一段"，引用原文片段
2. **爆发有力吗？** — 标注正文中"爆发那一句/动作"，引用原文片段

**4大转换去AI味（写后检查）：**
- 心理描写 → 动作/表情
- 解释说明 → 结果/呈现
- 对称排比 → 不对称长短句
- 总结升华 → 停在行为/台词里

**断章自检：**
- [ ] 最后一句是否停在情绪最高点，而不是感慨里

## 5. 旁白语感（音频/推文适配）

- 第一人称"我"，口语化，像朋友倒苦水
- 极短句：每段 ≤50 字，多停顿
- 情绪可标注：（颤抖）（冷笑）（歇斯底里）
- 对话占 50%+，心理描写极简

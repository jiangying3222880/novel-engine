# 短故事创作模式（Short Story）

> 底层节奏 = 单情绪弧憋压爆发。不建项目、不初始化 truth、不拆书建池、不维护章节索引。

## 0. 底层节奏原理

**单情绪弧：憋压积蓄 → 彻底爆发**

```
第一句 → 信息量爆炸 + 读者被钉住
    ↓
中段全程 → 压、压、压（委屈/困境持续叠加，不释放）
    ↓
中后段 → 压到临界点（微光/忍无可忍的前奏，不是爽）
    ↓
高潮爆发 → 全部情绪一次宣泄，读者跟着炸
```

**字数自适应**：8000字憋紧凑，30000字憋更深的层次，节奏本质不变。

## 1. 何时启用（触发词）

| 用户指令 | 判断 |
|---------|------|
| "写个短故事""短篇""单篇完结""抖音推文风""这个故事短一点" | → 进入本模式 |
| "写下一章""继续写""规划第X章"（已有项目） | → 走 S1-S4 流水线，不进本模式 |

## 1.3 短篇细纲门（v1.9 新增 · S1 编剧必产）

> 短篇不走完整长篇细纲，但**必须走细纲门**（用户拍板："短篇不走细纲那怎么写？"）。S1 编剧按 `templates/short-story-template.md` 产短篇细纲（憋压三段式四维骨架），过细纲门后再进入写作：

**短篇细纲门（硬软两层）**：
- 硬性结构检查：冲突链四节点（想要/阻拦/弄砸/代价）有内容、憋压层次 ≥3 层且逐层加深、声线要求标注来源、任务字数已按 §2.0 预检分配
- 软性删节推理：删掉任一层憋压，爆发还有力吗？有=注水需加层；无=力度够
- 打回 ≤2 轮（节级：只打回力度不够的那层憋压，不整篇重写）

**短篇声线/知识边界透传**（同长篇机制）：从角色卡提取声线（标注来源）、压缩角色知识边界（"知道什么/不知道什么"）——S2 讲述者不读原始状态，靠细纲透传。

## 1.5 驱动标注（写前必填 · 编译自炼丹炉 ReaderLoop 驱动参数表）

> 机制：**期待 → 回报 → 新期待**。短篇所有技法（憋压/信息差/引擎）都必须服务"读者为什么翻到最后一页"。
> 引擎选择：`references/short-story-engines.md`（六引擎：如何制造情绪债务 + 如何兑现）。

**写前必填 4 字段**（缺一项 = 驱动不完整，禁止动笔）：

```
驱动标注：
- 制造什么期待（读者在等什么）：_____________
- 第几段/字引爆（情绪张力起点）：_____________
- 憋压到什么程度给（信息释放时机）：_____________
- 读者翻页动力（为什么不停下来）：_____________
```

**示例（憋压型短篇）**：
- 制造什么期待：读者想知道"他什么时候爆发"
- 第几段引爆：段三（结尾 1000-2000 字）
- 憋压到什么程度给：憋到"再忍就不是人了"的临界点
- 读者翻页动力：愤怒累积 + 等一次性宣泄

> 与长篇同机制、不同参数：短篇 30 字钩 / 单弧憋全场 / 第 1 段情绪张力 / 结尾一次性兑现；长篇 前3章目标 / 多弧并行 / 章末卷末切口 / 多峰递进。详见 `references/narrative-kernel.md` §5。

## 2. 三段式生成流程

> **分段生成（强制）**：按 2000-2500 字/节分节生成，禁止一次成篇。一次成篇实测字数仅达标约 47%，且易结构失控（爆发点前移/中段泄压）。流程：段一（1 节）→ 段二（**节数按 §2.0 写前预检反推，不再写死 2-3 节**）→ 段三（1 节），每节写完追加到正文文件，再写下一节。

### 2.0 写前预检（动笔前必做 · v1.8 新增）

> **背景（算术冲突修复）**：旧流程段二固定 2-3 节（2000-2500/节）→ 全篇实算仅约 5300-10000 字，永远达不到默认 target 15000 的验收下限 12750。根因=节数是拍脑袋定的，没和 target 联动。v1.8 改为**由 target 反推节数**。

**由 target 反推节数，再开工：**

1. 确认 target（默认 15000；验收区间 = target±15%，如 15000 → 12750-17250；用户指定以用户为准）
2. 段一固定 1 节（300-500 字）、段三固定 1 节（1000-2000 字）——这两段是节奏定死的高压区/爆发区，**不参与 ≥2000 门禁**（见 §2.1）
3. **段二节数 = 反推**：
   - 段二需覆盖字数 ≈ target − 400（段一中值）− 1500（段三中值）
   - 节数 = 向上取整（段二需覆盖字数 ÷ 2200（每节中值））
   - target=15000 → 段二 ≈ 13100 字 → **6 节**（容量 12000-15000 ✓）
4. 校验：段二节数 < 3 时（target ≤ 约 10000）→ 提示用户按紧凑憋压写（每节 2000 下限硬保）或调低 target 预期；**禁止节数不够硬凑**。

> 例：target=10000 → 段二需 8100 → 4 节；target=20000 → 段二需 18100 → 9 节。节数随 target 动，不再写死。

### 2.1 每节字数校验（强制门禁 · v1.7.1 方案B短篇版）

> **背景（基线实测）**：v1.4.3 / v1.7.0 两轮基线（T1 都市/T2 仙侠/T3 悬疑）字数全未达标（8083→5478/6953/7166，目标 12750+），根因=**分节字数无强制校验**：Agent 高密度写完即收（每节约 900-1000 字，规格要求 2000-2500/节）。方案 C（保持 15000 重跑）实测无效，方案 B 编译为硬门禁。

**每节写完 → 先统计字数 → 再决定是否进入下一节：**

```
每节字数统计（去空白）：
  [节X 实际字数]：____ 字
  [门禁判定]：≥2000 字 → 通过，写下一节
              <2000 字 → 打回本节，用下方"中段加厚清单"补足后重写本节
```

- **统计口径**：正文去空白字符数（含对话，不含标题/元数据）
- **判定时机**：每节写完**立即**统计，不达标**不得**写下一节（Agent 不能"先写完再补"，补也是重写本节）
- **门禁适用范围（v1.8 明确）**：≥2000 字门禁**只对段二生效**。段一（300-500 字高压开场）、段三（1000-2000 字爆发收尾）是节奏定死的区段，**豁免门禁**，但须落在各自区间内。
- **允许单节超 2500（v1.8）**：2500 是目标值**不是上限**；门禁只保下限。单节写到 2800-3000 属正常，无需拆节——只要节数按 §2.0 预检走，总字数达标即可。
- **全篇验收**：全部写完后统计总字数，对照 target±15%（默认 target 15000 → 12750-17250；用户指定 target 以用户为准；节数按 §2.0 预检反推，禁止用不足的节数硬凑）
- **达标判断**：憋压型短篇的中段（段二）是主要加厚区——字数不足优先回中段加层/加厚，不是去硬凑爆发段

### 2.2 中段加厚清单（字数不足时的加厚手段 · 配合驱动标注"憋到什么程度给"扩层）

> 中段"压不住"= 每层只有一句概括、没有落成场景。以下 8 手段按需选用，**每层憋压至少落成 1 个完整场景**（时间/地点/在场人/对话/动作），禁止概括化（"又被羞辱了"=不合格）。

| # | 加厚手段 | 说明 | 示例（憋压层） |
|---|---------|------|---------------|
| 1 | 场景化而非概括 | 憋压必须落成具体场景，不是一句总结 | 不是"又被羞辱了"，而是"家宴上，丈母娘把剩菜推到我面前，桌上所有人都在笑" |
| 2 | 加对话回合 | 羞辱场景 ≥2-3 个对话回合（对方说→主角忍→对方再压） | 她："你弟弟要结婚了，你工资卡先借我用用。"我："妈，那是给我爸看病的……"她："看什么病？拖两天死不了。" |
| 3 | 加身体细节 | 憋屈时的身体反应（动作/表情，不是心理独白） | 我攥着筷子，指节发白，又慢慢松开，夹了一筷子菜 |
| 4 | 加旁观者反应 | 在场其他人的反应（嘲讽/同情/冷漠）放大屈辱 | 表姐端着酒杯嗤笑一声："姐夫可真会过日子。"满桌人低头，没人接话 |
| 5 | 加环境压迫 | 天气/陈设/时间指向当下的憋 | 窗纸被雨打得发白，屋里没点灯，我坐在冷饭前等她下班 |
| 6 | 加对比闪回 | 与之前的美好形成对比（只对比，不释放） | 三年前她跟我挤出租屋，说"穷不怕，有你就不怕"——现在她嫌我端汤的样子丢人 |
| 7 | 加代价显化 | 每次憋压让主角付出可感知代价（钱/尊严/时间/机会） | 这一退，我连这个月房租都凑不齐了，还得笑着跟房东说月底前一定给 |
| 8 | 加二次确认 | 对方踩完再补一句"为你好/别不知好歹"式道德绑架，加深憋 | 她扔下卡："不是妈说你，男人要有出息，别整天病秧子似的拖累人。" |

**加厚优先级**：先加层（新憋压场景，层次不足 5 层先补层）→ 再厚化（对已憋场景用手段 1-8 落成完整场景）→ 仍不足则检查是否提前泄压（中段出现微爽/小反转会压缩字数空间）。

### 段一：高压注水开场（前 300-500 字）

**第一句 = 直接进憋屈状态，禁止铺垫背景/天气/心情。**

❌ 平淡："我叫王磊，今天是丈母娘的生日。"
✅ 爆发："从那天起，我再也没抬起过头。"

第一句把读者直接按进情绪里，让他想问"然后呢"。

### 段二：憋压蓄力（中段，按字数自适应）

**核心原则：只压，不释放。**

- 每段都是憋——困境加深、委屈加大、尊严继续被践踏
- **憋压层次 ≥5 层（硬指标）**：每层是一个独立的具体场景/事件，逐层加深（如：强索→病中无人问→剥削史→抢房→拒之门外）。5 层以下爆发力不足，两次实测均 5-6 层才够力
- **每层 ≥500 字**（配合 §2.1 每节门禁：一节约 2000-2500 字，约含 3-4 层憋压场景；不足按 §2.2 清单加厚）
- **禁止中段设置微爽/小反转**——快感留到结尾一次给
- **微光边界（判定标准）**：允许"忍无可忍的前奏"（蓄力），禁止"微爽/小反转"。前奏必须不改变主角处境、不解决任何问题、不带来任何收益——只是心理上的决意（如"我要见掌门""我不想忍了"）；一旦出现"他拿到证据/他占了上风/对方破绽被抓"等实际进展，即越界为微爽，必须删除
- 允许：忍无可忍的前奏（蓄力，不是释放）
- 字数长就憋更深的层次，不靠反转给糖

### 段三：大坝决堤爆发（结尾 1000-2000 字）

**全部情绪一次性宣泄。**

- 爆发可以是：身份揭露/行为反击/真相公开/情绪宣泄
- 爆发后不停，留白/断在情绪最高点
- **禁止爆发后加总结/感慨/反思**（情绪断了就不值钱）
- 结尾余韵只写"行为/画面"（收拾东西、跨门槛、不回头），不写"他终于解脱了"式总结

#### 段三断章三法则（诊断参考 · 编译自炼丹炉 job-0046，样本=爽文500章统计）

> 性质：**诊断问题，非硬指标**（C-007 引导原则）。数据源为装逼打脸流 500 章章尾统计，短篇/其他题材按类型调整权重。写段三结尾时用这三问自检：

1. **信息不对称了吗？**（断章第一法则）——结尾处读者是否知道某些角色不知道的事（或角色知道读者不知道的事）？停在信息差位置，是驱动翻页的最强动力
2. **情绪最高点急停了吗？**（断章第二法则）——爆发写到情绪最高点的瞬间切断，不给落地机会；禁止"爆发后继续解释/平复"
3. **最后一句够短吗？**（断章第三法则）——末句越短越有力；样本中 47.8% 的章尾 <15 字收尾（"死了。"2 字即经典）。**越重要的信息用越短的句子说**

**参考数据（爽文样本，非普适标准）**：章尾标点分布——省略号 40.6%（留白/"未尽之言"，让读者自己补全"然后呢"）、对话引号 27.8%（台词制造悬念）、感叹号 18.8%（情绪高点急停）；句式偏好——短句炸弹（<15 字占 47.8%）；章尾节奏——"三拍子"：倒 3 段叙述铺垫（82%）→ 倒 2 段动作/对话递进 → 倒 1 段最短最有力。章尾→章首衔接：97.6% 采用"直接延续"式（下节/下章首紧接本节尾同一场景同一时刻，不给读者冷静机会）——短篇分节生成时同样适用。

> **统计口径（v1.8 补充 · 可复查）**：
> - **样本**：《最强反套路系统》（装逼打脸流）前 500 章章尾（来源：炼丹炉 job-0046 语料精读）
> - **单位**：标点/短句统计以**每章最后一句**为单位；"三拍子"节奏以**每章最后 3 段**为单位；"直接延续"判定=章尾最后一句与下章首句是否同一场景同一时刻
> - **类别定义**：省略号=章尾含"……"；对话引号=末句以引号开头；感叹号=末句含"！"；短句=去空白 ≤15 字。**多标签可同时命中**（如"……他死了！"同时计省略号+感叹号）
> - **复核**：job-0046 人工抽样 50 章核对，与全量统计结论一致
> - **性质**：装逼打脸流单书统计，短篇/其他题材按类型调整权重；**启发式建议，非普适硬指标**（C-007）

## 3. 硬约束（铁律，写前必读）

- **事实锚点**：关键数字/物品/关系不得串（例：金额/身份设定）
- **声线边界**：每个角色的说话风格不漂（例：丈母娘=刻薄嘲讽，老婆=冷漠嫌弃，主角=内心吐槽役）
- **红线**：擦边只写反应不写器官；不暴露主角知道的事
- **禁止**：中段有任何微爽/小释放；结尾停在感慨/总结里

## 4. 检验（S3 · 写完检查）

> v1.9：短篇检验 = 憋压/爆发/断章双视角（读者+编辑），证据 excerpt 强制。

**2问行为验证（每问附 evidence_ids）：**

1. **情绪憋到位了吗？** — 标注正文中"最憋的一段"，引用原文片段
2. **爆发有力吗？** — 标注正文中"爆发那一句/动作"，引用原文片段

**4大转换去AI味（写后检查）：**
- 心理描写 → 动作/表情
- 解释说明 → 结果/呈现
- 对称排比 → 不对称长短句
- 总结升华 → 停在行为/台词里

**双视角（读者 + 编辑）：**
- 【读者】憋到想翻页吗？爆发时跟着炸了吗？断在还想看的位置吗？
- 【编辑】节奏快慢分配对吗？中段有没有泄压/微爽？结尾停在最高点还是感慨里？

**断章自检：**
- [ ] 憋压层次 ≥5 层（数一下独立憋压场景，不足 5 个补层）
- [ ] 中段无微爽/小反转（对照微光边界：前奏只蓄力不改变处境）
- [ ] 段二每节字数 ≥2000 字（对照 §2.1 门禁记录，不足=该节未过门禁；段一/段三豁免，但须落在 300-500 / 1000-2000 区间）
- [ ] 全篇节数 = §2.0 预检反推节数（写前已确认，防节数不足硬凑）
- [ ] 总字数达标（对照 target±15%；不足按 §2.2 加厚清单回中段加层/加厚）
- [ ] 断章三问（§2 段三诊断参考）：停在信息不对称处？情绪高点急停？末句够短？
- [ ] 最后一句是否停在情绪最高点/行为，而不是感慨里

## 5. 旁白语感（音频/推文适配）

- 第一人称"我"，口语化，像朋友倒苦水
- 极短句：每段 ≤50 字，多停顿
- 情绪可标注：（颤抖）（冷笑）（歇斯底里）
- 对话占 50%+，心理描写极简

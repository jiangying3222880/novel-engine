> 本文件是 novel-engine 的**深度方法库**。速查版在 `anti-ai.md`，本文件给完整模板、完整模式库与准出流程。

## 一、上游防御模板（生成前就把 AI 味压下去 · 对应 06 / 阶段①②）

**首次生成模板**（阶段②写作前注入，先定标准再写，不是写一版再补救）：

```text
请直接生成一版可用的【第X章】正文。

主需求：＿＿（本章要发生什么）
使用场景：＿＿（正文落 故事/正文/，元数据写 故事/元数据/）
作者画像：＿＿（本书作者声音/目标读者，见 配置/身份/）
最终读者：＿＿（他们在意什么、讨厌什么）
必须保留/使用的事实：＿＿（故事/真相/ 当前状态 + 细纲承诺）
不能写的内容：＿＿（边界：不破墙/不越世界观硬规则/不性暗示）
手法规则：＿＿（素材池/author_dna/ 提炼的手法规则 10 类，只学怎么写、不抄句子）

请先在内部判断：
1. 本章场景真人会怎么写（对照 04 §2 真人示范的底层逻辑）。
2. 这个场景 AI 味通常表现为哪种（04 §1 四模式 + 09 模式库）。
3. 人感应体现在：动作链 / 对白潜台词 / 环境烘托 / 细节观察方式（叙述者视角）。

输出要求：
- 直接给正文，不解释。
- 事实不足保守写，不编造状态（故事/真相 没有的设定不硬造）。
- 不为了自然破坏网文体裁规范（爽点节奏/章末钩子要留）。
```

**素材清单**（生成前向用户/状态文件要的素材，越具体越不容易 AI）：

- 一个真实场景：何时、何地、谁在场、发生了什么
- 一个具体动作：角色做了什么、没做什么、卡在哪里
- 一个真实判断：角色赞成/反对/保留什么（有取舍，不端水）
- 一个读者痛点：读者为什么在意这一段
- 一个边界：什么不能写、不能越界（世界观硬规则）
- 一个不完美处：犹豫、代价、冲突、失败（让角色有瑕疵）

**手法规则注入**（有 author_dna 手法规则时，阶段②生成前）：

```text
以下是对标书/作者稿提炼的"手法规则"（10 类），只学"怎么写"，不抄任何句子。写作时逐类对照执行：

【粘贴 素材池/author_dna/{书名}_dna.md 的手法规则 10 类】

逐类对齐：① 让步转折 ② 原因后置 ③ 钩子预告 ④ 具体锚点 ⑤ 心理外化 ⑥ 口语混入 ⑦ 短段 ⑧ 收束落到具体 ⑨ 对话夹叙 ⑩ 助词习惯。
保持类似语气和节奏；不要突然变得更华丽、更网感或更官方；避免样本不用的词和句式。
收束铁律：章末/段末落到具体物件或朴素判断，不用空泛升华。
```

## 二、改写模板（对应 04 · 阶段④）

```text
请把下面文本改得更真实自然，但保留原意和所有已建立事实。

改写强度：【轻度/中度/重度】
必须保留：＿＿（已建立的设定/状态/因果，见 故事/真相/）
不能改变：＿＿（角色立场/世界观硬规则/伏笔承诺）
禁用/少用：＿＿（用户不喜欢的词/句式，见 04 §6 信号清单）

原文：【粘贴】

要求：
- 只改"怎么说"，不改"说什么"（保真第一：不丢信息、不弱化事实）。
- 如果原文已经自然，直接说不建议大改（低误报）。
- 找到主要病灶（04 §1 四模式 + 09 模式库）再改，不做表面口语化。
- 不编造原文没有的具体经历、数据、物品、对话。
- 改完对照 04 §5 纪律：不为去味注水（产物取胜）、不制造新问题（反向校准）。
```

**改写强度选择**：

| 强度 | 处理 | 适用 |
|------|------|------|
| 不改 | 原文已自然/风格成立 | 低误报，直接说明不需要大改 |
| 轻度 | 保留结构，只降套话/连接词/抽象词/机械节奏 | 偶发 AI 味词 |
| 中度 | 重排表达，补动作/场景/读者视角 | 多处模式命中 |
| 重度 | 重构切入点/节奏/人设口吻 | 整段像模板腔 |

---

**改写前追问 / 澄清判断（Humanizer-zh allowed-tools 机制）**：
改写或润色前，若以下信息缺失，先向用户追问澄清，不瞎猜；无法追问时保守处理并标注：

- 手法规则缺失（有 author_dna / 用户代表作才做"匹配手法"，否则用默认人味规则）
- 改写强度不明（轻度/中度/重度，默认轻度，用户可调）
- 事实/设定缺失（故事/真相 没有的状态，不编造，标注待补）
- 目标读者/平台语体不明（网络小说 vs 出版语体，影响分寸）

追问只问"会改变改写结果"的关键项，不问无关项（低打扰）。


## 四、六层成因诊断（完整版 · 04 §0 细化）

用户说"假、空、AI"只是症状，先定位成因层再决定改法：

| 成因层 | 表现 | 改法 |
|--------|------|------|
| 观点层 | 中立无取舍、无效辩证、正确废话 | 补判断与取舍（角色有立场） |
| 结构层 | 三段式、均匀段落、机械列点、起承转合太完整 | 打散结构，留真实冗余 |
| 表达层 | 连接词过密、大词堆叠、句式整齐、强行概括 | 删连接词、抽象词落到动作/对象/结果 |
| 素材层 | 缺具体事实、假例子、泛化、缺动作和结果 | 用已有素材，缺则保守写不编造 |
| 叙事层 | 因果太顺、第一人称全知、每句都服务主线 | 加入真实阻力/误判/后知后觉，限叙述者认知 |
| 情感层 | 情绪恒温、强行升华、结尾金句、苦难叙事 | 克制主观感受，收在动作/事实/朴素判断 |
| 语境错配层 | 平台/受众/体裁语体不对（小说：像论文/像社论） | 回到题材与平台分寸 |

## 五、高频 AI 味模式库（完整版 · 04 §1 四模式的扩充）

> 标注【小说】= 对网文正文直接适用；【观点文】= 主要适用社论/科普/自媒体，小说里偶见。

### A. 结构/叙事类
1. **连接词过密**【小说/观点文】：首先/其次/此外/值得注意的是/归根结底。千字 >8 且分布均匀易像 AI；每段靠连接词推进=结构替代思考。→ 用事实顺序/动作/因果自然连接。
2. **叙事过度顺滑**【小说】：每个细节都刚好服务后文（像提前排好的材料）。→ 加入真实冗余、误判、后知后觉（04 §1 模式四）。
3. **第一人称全知**【小说】：叙述者知道不该知道的事、替别人分析内心。→ 限叙述者认知（02 §8 第5条）。
4. **结构过度工整**【观点文/小说】：每段/每章均匀，起承转合太完整。→ 留不对称、留悬念。

### B. 表达/用词类
5. **抽象大词堆叠**【观点文】：赋能/闭环/底层逻辑/时代命题。→ 落到动作/对象/结果（小说里少用社论式概念）。
6. **数据堆砌建可信度**【观点文】：非专业观点文高频甩数据。→ 只留能改变判断的 1-2 个。（小说里"装真实数字"另见 04 模式四）
7. **虚假高层概括**【观点文】：从本质上说/这背后反映的是/不仅是X更是Y/不是A而是B。→ 直接写现象和判断。
8. **句式像尺子量过**【观点文】：排比、对仗、字数工整。→ 打散句长（小说里"句子疏密"见 02 §8 第6条）。
9. **解释符号过量**【观点文/小说】：用破折号/括号/引号疯狂解释。→ 删多余解释，留白。
10. **AI 式设问**【观点文】："那么问题来了""我们不禁要问"。→ 删除设问，直接给判断。

### C. 细节/素材类
11. **教科书式举例**【观点文】：小明/某用户/部分企业撑内容。→ 用真实具体例子。
12. **装真实的数字细节**【小说】：精确到秒/次数/比例（除非人设爱计数）。→ 改印象式体感（04 模式四）。
13. **细节的观察方式**【小说】：细节不只看真假，还看叙述者会不会这样注意（孩子视角写成年人判断=假；紧张时看清所有动作=假）。→ 问：人物当下会注意到这个吗？
14. **无功能闲笔**【小说】：细节是作者为"有文学感"加的，人物不会注意。→ 只留人物会注意的细节（02 §8 第7条）。
15. **体裁必需件被误删**【小说】：为"干净"删掉网文必需的爽点/钩子/信息节奏。→ 体裁规范优先（不牺牲平台范式）。

### D. 情感/收尾类
16. **段尾强行升华**【小说】：段落/章节末尾感慨总结。→ 段末落物（04 原则四）。
17. **结尾金句化**【小说】：收在金句。→ 收在动作/事实/朴素判断。
18. **讨好式反套路**【观点文】：刻意反转/抖机灵。→ 自然表达。
19. **信息效率过高**【小说】：信息密度爆炸、每句都推进。→ 留呼吸感（对应"叙述者认知"与详略）。
20. **情绪恒温**【小说】：全程一个温度。→ 情绪有起伏、有压有放。
21. **评论/对话过于工整**【小说】：对话礼貌完整信息清楚、评论面面俱到。→ 对白有潜台词/延宕/未说出口（02 §8 第2条）。

---

### E. GitHub humanizer 系补充（blader/humanizer 35模式 + Humanizer-zh 中文24模式，2026-08-30 融合）

22. **同义词循环 / 刻意换词**【小说/观点文】：同一角色反复换称呼（主角/少年/那人/他），同一概念换词回避重复。→ 用最自然的一个称呼，不刻意换词。
23. **三段式排比过度**【小说/观点文】：强制三连（"愤怒、不甘与仇恨"）。→ 用意义需要数量的词，不为节奏凑三。
24. **过度限定词**【小说/观点文】：可能/或许/似乎/大概 堆叠（"他似乎可能大概知道"）。→ 保留一个必要的，删多余犹豫。
25. **假坦诚开头**【小说/观点文】："说实话""老实说""讲真"开头制造人味。→ 直接陈述，不靠口头禅装真诚。
26. **空泛积极收尾强化**【小说】：结尾落在"未来可期/一切都值得/这就是命运"等空泛展望。→ 收在具体动作/事实/朴素判断。
27. **回答没人提出的异议**【观点文】：替读者脑补反驳再自我辩解（"也许有人会问…"）。→ 删除未提出的防御，保留真实观点。

此外、至关重要、深入探讨、强调、持久的、增强、培养、获得、突出、相互作用、复杂/复杂性、格局（抽象）、关键性的、展示、织锦（抽象）、证明、宝贵的、充满活力的、不仅…更是…、值得注意的是。

## 六、生成后自检 7 问（对应 03）

输出/交付前自查：

1. 这篇还像目标题材/平台吗？（网文？爽点/钩子还在？）
2. 有没有事实被改、被弱化、被模糊？（故事/真相 状态没被破坏？）
3. 有没有编造状态文件里没有的设定、经历、具体细节？
4. 有没有一眼 AI 的句式：不是 A 而是 B / 好的一面坏的一面 / 每段观点解释例子总结？
5. 有没有靠大词、数据墙或段尾金句假装深刻？
6. 像这个角色（年龄/性格/身份）会说的话吗？（对照 voice-profile 基线）
7. 如果原文已经自然，是否应该不大改？（低误报）

## 七、准出流程（对应 03/04 · 一票否决 → 评分 → 回退）

```
1. 一票否决：触发任一硬伤 → 不交付，回到对应层重写。
   （小说硬伤示例：卖点未落地 / 主角连续2章零台词 / 真死角色以活人出场 / 破坏世界观硬规则 / 前100字无钩子）
2. 按维度评分：信息保真 / 可直接使用 / 产物效率 / 成因层诊断 / 题材平台适配。
3. 未过线回退：
   - 信息保真不足 → 回到 故事/真相 和原文，恢复事实/状态/限定条件
   - 成因层不足 → 重新定位观点/结构/表达/素材/叙事/情感/语境错配
   - 平台适配不足 → 回到题材与平台分寸重判
4. 默认不展示内部评分；用户要诊断/评测时才展示摘要。
```

## 八、核心原则（贯穿 04/06/09）

1. **保真第一**：只改"怎么说"，不改"说什么"；不编造、不丢信息、不弱化已建立事实。
2. **低误报**：原文自然/风格成立时，允许说"不需要大改"。
3. **产物取胜**：人感是手段不是目的；不为去味注水（碎碎念/重复/装细节）。
4. **引导优于禁止**：判断标准是"真人会怎么写"，不是"避开所有 AI 常见词"；真人文本正常使用的词不进禁单。
5. **作者手法优先**：有手法规则时学其处理方式/节奏/分寸，不套通用人味。
6. **边界不破**：不为"人感"牺牲事实、合规、题材平台范式与用户原声。
7. **内容引导 × 流程规则分层**：文本/表达层只引导不禁止（无禁词黑名单，判断标准"真人会怎么写"）；写作、修改的**流程执行层**允许禁止规则（写前必读 / 正文无 YAML / 修改保真不丢设定 / 自检不通过不交付 / 修正 ≤3 轮）。两层不混用。

## 九、人感注入（正面定义人味 · Humanizer-zh "个性与灵魂"）

去 AI 味不止是删痕迹；**技术干净但没灵魂 = 另一种假**。删完负面模式后，按下面注入正面人味：

### 缺乏灵魂的迹象（即使技术"干净"）
- 每句长度结构相同；无观点只有中立叙述；不承认不确定/复杂感受
- 不用第一人称（该用"我"时）；无幽默、无锋芒、无个性
- 读起来像资料或新闻稿

### 如何注入人味（小说/观点文通用）
| 手段 | 说明 | 示例对比 |
|------|------|---------|
| 有观点 | 不只报事实，对事有反应 | "这令人印象深刻但也有点不安" 优于 "这令人印象深刻" |
| 变化节奏 | 短句长句交替，两项优于三项 | 段落结尾多样化 |
| 承认复杂性 | 真实的人感受复杂 | 角色爱恨交织，不是单一情绪 |
| 适当用"我" | 第一人称是诚实不是不专业 | 内心戏用"我一直在想…" |
| 允许混乱 | 跑题/题外话/半成型想法是人味 | 不要每句都推进主线 |
| 对感受具体 | 不写"这令人担忧"，写具体场景 | "凌晨三点没人看着的时候还在运转" 优于 "这令人担忧" |

### 注入边界
- 人味服务于角色/叙述者，不改变已建立设定与剧情（保真优先）。
- 网络小说平台范式（爽点/钩子）不能为"人味"牺牲（呼应 09 §五 E 26）。
- 判断标准仍是"真人会怎么写"，注入不是加花哨（产物取胜）。

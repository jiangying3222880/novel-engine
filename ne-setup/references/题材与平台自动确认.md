# 题材与平台自动确认

**本文件要解决的问题**：题材和平台不该让用户从下拉框里挑。
作家的自然输入是"我的世界观长这样、我的大纲是这样的"，题材和平台应该**从这些材料里反推出来**，
再拿去跟用户确认一次。

**本文件只做两件事**：
1. 从世界观 + 大纲反推题材标签与平台风格匹配度（Agent 的分析活，不是用户的活）
2. 用最少的问题让用户确认或推翻（一次，不是十次）

---

## 两条铁律

1. **平台维度取"风格口味"，不取"审核规约"。**
   见 `../../ne-library/library/platforms/_README.md` §风格 != 规约。
   匹配的是"这书写成什么味道最像这个平台的东西"，不是"这个平台要求多少字"。
2. **反推结果必须过一遍用户的嘴。**
   Agent 可以给推荐，但必须让用户确认。用户的一句话先验 > 全表打分。

## 触发时机

| 场景 | 走哪条路 | 时机 |
|---|---|---|
| 世界观 + 卷纲 + 前 3 章细纲已成型 | **路线一：材料反推** | 立项 Step 4.5 |

## 路线一：材料反推

### Step A · 特征提取

读 `设定/世界观.md` + `大纲/卷纲.md` + 前三章细纲，抽取 11 个特征。**每个特征必须给出依据句**（从材料里摘一句原话），不允许凭感觉填。

| # | 特征 | 取值 | 从哪里看 |
|---|---|---|---|
| F1 | 设定信息密度 | 低 / 中 / 高 | 读者要先理解多少东西才读得懂第一章 |
| F2 | 力量/规则形态 | 无 / 单一外挂 / 完整升级体系 / 世界规则型 | 世界观里的力量体系段落 |
| F3 | 世界规模 | 日常一隅 / 一城一国 / 多界多重 | 地理设定 |
| F4 | 时间跨度 | 几天 / 数月数年 / 几代 | 时间线设定 |
| F5 | 核心冲突 | 人际 / 社会结构 / 生存 / 自我 / 超自然 | 卷纲主线 |
| F6 | 主角成长形状 | 线性升级 / 身份揭晓 / 关系变化 / 认知转变 / 无成长 | 卷纲弧线 |
| F7 | 情感线权重 | 无 / 副线 / 主线 | 卷纲里情感线占多少篇幅 |
| F8 | 反转密度 | 低 / 中 / 高（章级） | 细纲里每章有几个转折 |
| F9 | 主角主动性 | 主动出击 / 被动卷入 | 前三章主角在干什么 |
| F10 | 篇幅量级 | 短篇<5万 / 中长20-80万 / 超长>100万 | 总章数 × 目标字数 |
| F11 | 真实感要求 | 必须可信 / 容许幻想 / 必须奇幻 | 世界观与现实的偏离度 |

### Step B · 题材反推

题材由**世界观关键词**直接决定，权重最高的是 F2 + F3 + F5。打 1 个主标签 + 0-2 个修饰标签。

| 世界观里出现 | 主标签 |
|---|---|
| 境界/宗门/灵气/修炼/丹药 | 玄幻·修仙 |
| 现代都市 + 豪门/职场/娱乐圈/校园 | 都市 |
| 神明/异能/都市传说/收容物 | 都市异能 |
| 真实朝代 + 历史事件 | 历史 |
| 副本/数据化/职业/装备 | 游戏·无限流 |
| 丧尸/灾变/废土/物资 | 末世 |
| 案件/刑侦/法医/法庭 | 悬疑·刑侦 |
| 情感为主线（F7=主线）+ 古代背景 | 古言 |
| 情感为主线 + 现代背景 | 现言 |

| 世界观里出现 | 修饰标签（可叠加） |
|---|---|
| 系统/面板/签到/任务 | 系统流 |
| 重生/穿越/魂穿 | 重生穿越 |
| 聊天群/直播/弹幕 | 直播流 |
| 多 POV 群像 | 群像 |
| 反派视角/猎梦者式暗线 | 双线暗线 |

> 题材**不是**平台选择的输入之一，它只决定"适配气质"那一行是否对得上。
> 同一个都市题材，可以写成番茄爽文，也可以写成知乎盐选悬疑——看路线一 Step C。

### Step C · 平台风格匹配

不做 88 格的加权矩阵（维护不动，也说不清）。用**命中条件表**：每条命中 +1，每条排他 −2，排序取 Top 2。

| 平台 | 命中 ≥2 条即为候选 | 命中任一条即排除 |
|---|---|---|
| **番茄长篇** | F10=超长 · F9=主动 · F2=单一外挂/完整体系 · F1=低或中 · F8≥中 | F10=短篇 · 悲剧结局 · F1=高且前三章无兑现 · 群像主线 |
| **番茄短篇** | F10=短篇 · F8=高 · F7=主线 · F6=身份揭晓/认知转变 | F10=超长 · F3=多界多重 · F1=高 |
| **起点** | F1=高 · F2=完整升级体系/世界规则型 · F6=线性升级 · F10=超长 · F3=多界多重 | F9=被动且无外挂 · F8=高且 F1=低（那是短篇悬疑） |
| **晋江** | F7=主线 · F6=关系变化 · F5=人际/自我 · F1=低 | F2=完整升级体系且 F7=无 · F8=高且 F7=无 |
| **七猫** | F9=主动 · F6=身份揭晓 · F1=低 · F10=超长 · F5=人际 | F1=高 · F3=多界多重 · 苦情/悲剧 |
| **飞卢** | F2=单一外挂 · F8=高 · F1=低 · F10=超长 · F6=线性升级 | 慢热（前三章无爽点） · 悲剧 · F7=主线 |
| **知乎盐选** | F10=短篇 · F11=必须可信 · F8=高 · F5=人际/社会结构 · F9=被动卷入 | F2≠无（有超自然设定即出局） · F3=多界多重 · F10=超长 |
| **书旗** | 各项均为中间值 · F1=中 · F10=超长 · F5 任意 | F1=高（去起点） · F8=高且 F10=短篇（去番茄短篇/盐选） |

**并列处理**：同分时按题材的适配气质行（见各风格卡 §适配气质）再判一次；
仍并列 → **交给用户选**，不要自作主张。

### Step D · 确认提问（一次问完）

```
我读完你的世界观和卷纲，判断如下：

题材：都市异能（主） + 系统流（修饰）
  → 依据：世界观里有"猎梦者"层级设定（F2），主线是主角在梦境中的身份反差（F6=身份揭晓）

平台：番茄长篇（命中 3 条）
  → 依据 1：百万字量级（F10）
  → 依据 2：主角主动出击且手握外挂（F9+F2）
  → 依据 3：设定密度中低，前三章即有兑现（F1+F8）
  → 次选：飞卢（命中 2 条），理由是爽点更密、要求日更万字

风格取向（从《番茄长篇》卡抽取）：
  节奏：事件驱动，不留静场
  语言：短句·对话驱动
  情绪：高频小幅波动

这三行对吗？不对直接说改哪个。
```

> **禁止**把 11 个特征全念给用户听。只念**支撑结论的那 3 条依据**。

## 路线二：三问定位（材料不足时用）

还没有世界观/大纲时，用这三个问题即可把 8 个平台砍到 1-2 个。问完再回头做世界观。

1. **这本书打算写多长？**
   - 1-3 万字 → 只剩 番茄短篇 / 知乎盐选
   - 几十万字 → 晋江 / 书旗
   - 百万字以上 → 番茄长篇 / 起点 / 七猫 / 飞卢

2. **主角手里有没有"别人没有的东西"？**
   - 有（系统/外挂/隐藏身份） → 番茄长篇 / 七猫 / 飞卢
   - 没有，他只是比别人能打/能熬 → 起点 / 书旗
   - 没有，他是个普通人被卷进事里 → 知乎盐选 / 番茄短篇
   - 他最大的武器是**和某个人的关系** → 晋江

3. **读者看完第一章，你最希望他说哪句？**
   - "太爽了" → 番茄长篇 / 七猫 / 飞卢
   - "到底怎么回事" → 知乎盐选 / 番茄短篇
   - "他俩什么时候在一起" → 晋江
   - "这世界还有多少东西没讲" → 起点

> 三问给的是**方向**，写完世界观和卷纲后仍需用路线一复核一次（会出现"一开始想番茄，写完设定发现是起点"的情况）。

## 路线三：强先验

用户开口就指定了平台或题材时：
1. 原样记入 config，`platform_source` 记 `user`
2. 材料齐了以后**仍然跑一遍路线一**，但不覆盖用户选择
3. **只有当反推结果与用户指定严重冲突时才提示**，且只提示一次：

```
你指定的是晋江，但你的卷纲是"百万字 + 完整修炼体系 + 情感线为副线"，
这三条在晋江都属于不对味项（见《晋江》卡 §不对味）。
仍然按晋江写我照办，要不要考虑起点？
```

## 写入 novel-config.json

在 Step 1 生成的 config 上追加/更新以下字段（题材不再由 Step 1 手填，改由本步回填）：

```json
{
  "genre": "都市异能",
  "genre_tags": ["都市异能", "系统流"],
  "platform": "番茄长篇",
  "platform_source": "auto",
  "platform_runner_up": "飞卢",
  "style_card": "../../ne-library/library/platforms/番茄长篇.md",
  "style_fingerprint": {
    "pacing": "事件驱动，不留静场",
    "language": "短句·对话驱动",
    "emotion_curve": "高频小幅波动",
    "pov": "主角限知",
    "character_taste": "主动型 + 金手指"
  }
}
```

| 字段 | 说明 |
|---|---|
| `genre_tags` | 主标签 + 修饰标签，供 ne-library 检索题材包 |
| `platform` | 平台名，必须能在 `../../ne-library/library/platforms/` 找到同名卡 |
| `platform_source` | `auto`（反推）/ `user`（强先验）/ `auto+user-confirmed`（反推后用户确认） |
| `platform_runner_up` | 次选，供用户一键改 |
| `style_card` | 风格卡相对路径，S1/S2 直接读它，不用再翻目录 |
| `style_fingerprint` | 从风格卡摘的 5 行，**这才是进提示词的东西**（不是"你是资深作者"这种空话） |

### 与身份矩阵的关系（待建）

`style_fingerprint` 是身份矩阵的**平台维输出**。矩阵其余维度：
- Voice（作者/编剧/编辑/读者/档案员）—— 已有 5 份档案，见 `../../ne-write/references/identity-routing.md`
- 篇幅 —— 由 `target_word_count` + 总章数派生
- 题材 —— 即 `genre_tags`
- 资历 —— **建议砍掉**。"资深/大神"对输出无约束力，只制造幻觉

> 矩阵卡最终形态待定；在矩阵落地前，`style_fingerprint` 先独立生效，S2 执笔时直接注入。

## 常见坑

| 坑 | 表现 | 防法 |
|---|---|---|
| 把规约当风格 | 平台维写成"2000字/章、不能涉黄" | 见本文件 §两条铁律 1；字数放 config，红线放 `_README.md` |
| 凭感觉填特征 | Step A 的特征没有依据句 | 每个特征强制附材料原话，凑不出就标"待确认"去问用户 |
| 全表念给用户 | 确认环节念 11 个特征 | 只念支撑结论的 3 条 |
| 反推翻用户 | 用户说了写晋江，材料指向起点，Agent 擅自改 | 路线三：只在严重冲突时提示一次，最终以用户为准 |
| 一次定终身 | 写到第十卷题材变了 | 卷纲变更后重跑一次路线一，config 里记 `platform_source` 便于追溯 |

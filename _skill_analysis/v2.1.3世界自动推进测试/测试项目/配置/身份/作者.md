# 作者身份档案（项目级 · 测试用）

> 注：下面的「样本段」是门禁夹具用的示范文本，**不是任何真实作者的声音**。
> 真实项目必须换成作者本人 200-400 字成稿（或试笔段），否则 #29c 会报。

一句话卖点：梦里喊他主人的女上司，现实里冷得像不认识他。
目标读者：番茄都市异能读者，25-40 岁。
写作边界：不解释梦的机制；不提前揭示猎梦者身份。
叙述人称：第三人称限知，贴林枫。
句法倾向：短句为主，动词先行，心理写外部动作。
禁用清单：仿佛 / 似乎 / 不由得 / 说不清的 / 某种 / 小心翼翼。
样本段: |
  电梯到七楼，门开了又合上。他站着没动，指节抵在不锈钢壁上，凉。
  走廊尽头的灯管坏了两格，一明一灭，把她的影子拉到墙上又收回来。
  他想起早上出门时她说过的话，随即又把它按回去。想这些没用。
  办公室的门半掩着，里面有人在笑，笑声隔着一层石膏板，像从水底传上来。
  他把手从壁上挪开，往那边走。鞋跟敲地砖的声音规律得让他自己都觉得假。

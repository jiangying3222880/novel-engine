# 对照组 B · 有身份矩阵

**共用细纲**：与 `01_无矩阵.md` 完全一致（同一份四维骨架，一字未改）。

**S2 输入包（有矩阵）** = 细纲 + `target_word_count: 1500` + 下面三段。

### 平台风格指纹（来自 `番茄长篇.md`）

```
节奏：事件驱动，几乎不留静场；铺垫是成本，不是资产
语言：短句、动词先行、对话驱动；心理描写压缩成外部动作
情绪：高频小幅波动；压抑极短，兑现要快
视角：紧贴主角的第三人称限知
人物：主角主动出击；配角功能化
```

### 题材标签

```
都市异能（主） + 双线暗线（修饰）
```

### 讲述者声音档案（示例 · 占位）

> ⚠️ 这段是**我根据番茄风格临时编的占位样本**，不是主人的声音。
> 真正生效需要主人提供 200-400 字自己认可的成稿，替换这一节。
> 本节只用于演示“有定义”与“没定义”的差别。

```
句法：短句为主，每段 ≤4 行；动词先行，修饰语后置
禁用词：仿佛 / 似乎 / 不由得 / 像是……一样 / 说不清的 / 某种 / 小心翼翼
心理处理：不写“他想”，写他的手、他的脚、他做了什么
对话：口语，不解释，不补全潜台词
节奏：每 3-5 段必须有一个具体事件或一句对话推进
```

## 正文

林枫在电梯里看见了苏晚。

她按了十七楼。他也按了十七楼。

昨晚梦里，她跪在他脚边，仰着脸喊他主人。现在她站在他左边半米，看着跳动的楼层数字，头都没转。

“早。”

苏晚侧过脸，“你哪个组的？”

“三组。上周给你发过验收单。”

“哦。”

她转回去。

电梯上行。八楼停，进来两个运维的，说话声一下子大起来。十二楼停，出去一个。十六楼停，没人。

第三次开门的时候，林枫看见她的手。

右手小指，指甲缺了一小块。

昨晚她抓他手腕的时候，他记住的就是这只手。缺口的形状都一样。

他往前挪了半步，“苏总监。”

“嗯？”

“你以前是不是在——”

“十七楼。”电梯报站。

梦里她还说了一句。

她说，你会忘的。

他说不会。

她说，那你记住这个。

然后她抓了他的手腕。

门开了。她先出去，高跟鞋敲在地砖上，声音很脆。林枫跟在后面，一直跟到会议室门口。

大堂那边，老陈端着咖啡凑过来，“看见新总监没？”

“看见了。”

“总部下来的，”老陈压低声音，“听说带过两个项目，一个都没成。这趟是最后一次机会。”

林枫“嗯”了一声，没接。

九点半开会。苏晚站在投影前讲新一季排期，语速快，句子短，翻页不打草稿。会议室里没人说话。

林枫坐在最后一排，笔记本翻开，一个字没写。他一直在看她的手。

第三页，她停住，“三组。”

他抬头。

“上周那份验收单，”她说，“格式不对。”

有人笑了一声。会议室安静下来，所有人都看向最后一排。

林枫站起来。

“第三页那个数也不对。”

苏晚看着他。

“华东区，你写的四千二。”他说，“上月实际是三千八。差四百万。”

没人笑了。

老陈在旁边倒吸一口气。

苏晚低头翻手里的表格，翻了两页，停住。三秒。

“改。”她说。

"验收单我也改。"

她抬眼，"今天下班前。"

"行。"

老陈凑过来，压着嗓子，"四千二和三千八，你怎么记的？"

"上月周报我看过三遍。"

"你故意的。"

"她先点我。"

老陈摇头，"你完了。"

散会。人往外走。林枫堵在门口。

“昨晚——”

“我们不熟。”

她从他旁边过去，没停。

回工位，林枫把保温杯转了半圈。

杯壁上多了一道痕。指甲掐的，很浅，在右侧偏下。

他把手放上去。指尖刚好盖住。

昨晚她抓的就是这个位置。角度也一样。

老陈路过，“哟，谁掐的？”

“自己碰的。”

“你那杯子跟宝贝似的，”老陈笑，“碰能碰出指甲印？”

林枫没说话。

十一点，他去茶水间。

苏晚在里面，背对着门，手机贴在耳边。

“我知道。”她的声音很低，和会上不一样，“别催。”

林枫站在门口。

她转过身，看见他，把电话挂了。

“有事？”

“验收单的格式，”他说，“有模板吗？”

“共享盘。”

她从他身边过去。杯子没接水，空的。

回到工位，林枫打开内部系统，搜“苏晚”。

入职三个月。上一栏是总部战略部。中间有一段空白：六月到八月，状态显示休假。

两个月。

他盯着那行字。梦里她说她被关在一间白屋子里，关了很久。

多久她没说。

他合上页面，转头看自己的杯子。

杯子不在原位。

往左挪了两指宽。

刚才老陈来过，茶水间他也去过。工位上只有他自己。

对面是落地窗。窗外是对面楼的天台。

天台上站着一个人。灰夹克，看不清脸。

林枫看见他的时候，那人已经在看了。

七秒。

然后转身，走了。

林枫起身往消防通道跑。

推门。楼梯间空的，只有声控灯一层一层亮下去，又一层一层灭掉。

他跑到十六楼，扶着栏杆往下看。

没有人。

安全门在他背后合上，声音很闷。

他站在那儿数了十秒。

电梯的显示屏贴在墙上，数字从 3 跳到 2，跳到 1。

然后停在 B2。

口袋里手机亮了一下。陌生号码。

「别再想起她的脸。」

林枫握着杯子，看着那行字。

昨晚梦里最后一句，她说的是：别回头。

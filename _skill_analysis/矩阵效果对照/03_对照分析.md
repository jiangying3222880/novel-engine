# 对照分析 · 有矩阵 vs 无矩阵

**样本**：《梦里叫主人，醒来装路人》第 1 章（林枫 / 苏晚 / 猎梦者暗线）
**控制变量**：同一份四维细纲，一字未改；只改 S2 输入包。

---

## 一、可量化差异

| 指标 | A · 无矩阵 | B · 有矩阵 |
|---|---|---|
| 字数 | 1584 | 1418 |
| 段落数 | 34 | 95 |
| 段均字数 | 47 | **15** |
| 句均字数 | 18.9 | **8.1** |
| 对话句数 | 12 | **33** |
| 禁用词（仿佛/似乎/不由得/说不清/某种） | **4** | 0 |
| 冲突出现位置 | 第 12 段才进电梯相遇 | **第 1 段** |
| 章内小兑现 | 无 | **3 处**（当众纠错 / 指甲痕 / 短信） |
| 结尾 | 抒情留白（"说不清的预感"） | 具体钩子（短信 + 梦里那句"别回头"） |

**最硬的一条是句均字数：18.9 → 8.1。** 这正好落在番茄长篇卡的"短句、动词先行"上，
也正好避开番茄 2026 年 AI 治理点名的"句构单一、情感无波动"。
A 版的句构是**长句一统到底**（34 段里几乎没有短句），这才是被抓的那种形态，不是"写得差"。

## 二、结构差异（比文风更重要）

A 版把 1500 字花在了：雾气、地铁、耳机、玻璃幕墙、前台、杯子的磨砂质感。
这些是**氛围**，番茄读者在前三章就划走了。

B 版把同样的字数花在了：电梯相遇 → 指甲 → 会上被点名 → **当场顶回去**（小爽点）
→ 堵门被拒（压抑）→ 指甲痕兑现（不安）→ 茶水间反常电话（暗线）
→ 两个月空白履历（信息）→ 杯子被挪（恐惧）→ 灰夹克 → 短信。

**同一份细纲，B 版多出了 6 个事件位。** 这不是文笔更好，是风格卡强制了
"事件驱动、不留静场"，字数预算被自动分配到事件而不是氛围上。

## 三、三个必须说清楚的 caveat

### 1. B 版的"声音"是我编的占位样本

`02_有矩阵.md` 里的讲述者声音档案是我按番茄风格临时写的，**不是主人的声音**。
所以 B 版证明的是：**有定义 > 没定义**，不是**这是主人的声音**。
真正要拿到主人的味道，需要主人给 200-400 字自己认可的成稿，替换那一节。

这是整个技能目前最大的缺口——讲述者 §五 声音样本槽至今空着。

### 2. 矩阵不会让文字变好，只让它变"确定"

B 版在纯文学意义上未必比 A 版好（A 版有些句子其实更细腻）。
矩阵的收益是**一致性**：下一章、下一卷、换一个会话、换一个模型，
只要输入包还是这张卡，出来的还是这个味道。
A 版的问题不是"差"，是"每次都不一样"。

### 3. 用矩阵跑你这本书，结果和你的强先验冲突

按 `ne-setup/references/题材与平台自动确认.md` 的规则跑一遍《梦里叫主人，醒来装路人》：

| 特征 | 取值 | 依据 |
|---|---|---|
| F1 设定密度 | 中 | 梦境体系 + 猎梦者暗线，但不是硬核设定 |
| F2 力量形态 | 单一外挂 | 梦境能力 |
| F5 核心冲突 | 人际 + 超自然 | 她认不认得他 / 猎梦者 |
| F6 成长形状 | 关系变化 + 认知转变 | 不是升级流 |
| F7 情感线权重 | **主线** | 梦境十美 + 现实冷若路人 |
| F9 主角主动性 | 被动卷入 | 被梦缠上，不是主动出击 |
| F10 篇幅量级 | **中长（25 万）** | 100 章 × 2500 字，不是番茄的百万字 |

**命中结果：**

- **番茄长篇 3 条**（单一外挂 / 设定密度中 / 反转中）— 但 F10 篇幅、F9 主动性两条**都未命中**
- **晋江 3 条**（情感主线 / 关系变化 / 人际冲突）
- 书旗 2 条
- 飞卢 1 条且**被排除**（F7=情感主线是飞卢的排他项）

**结论：并列第一，规则要求交给用户选。** 这不是矩阵失灵——
它恰好把这本书真正的分歧点摆出来了：**你是想写成"都市异能爽文"（番茄），
还是"情感张力向"（晋江）？** 25 万字 + 情感主线这个组合，在番茄属于偏短、偏软。

按路线三处理：你已在番茄发 = 强先验，矩阵不覆盖，只在立项时提示一次这个冲突。

## 四、结论

| | A · 无矩阵 | B · 有矩阵 |
|---|---|---|
| 输出稳定性 | 每次不同 | 跨章节跨会话一致 |
| 平台适配 | 靠运气 | 由风格卡强制 |
| AI 味风险 | 高（长句一统 + 抒情留白） | 低（句长分化 + 事件密度） |
| **主人的声音** | 无 | **仍然没有**（缺样本） |

最后一行是关键：**矩阵能把"通用 AI 腔"变成"某个平台的稳定腔"，
但变不成"你的腔"。** 那一步只有声音样本能做到，而且只能你给。

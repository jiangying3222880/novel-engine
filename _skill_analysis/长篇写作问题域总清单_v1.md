## A 组：角色物理隔离架构（14 条）

| 编号 | 问题 | 级别 | 说明 |
|------|------|------|------|
| A-01 | 隔离的物理性依赖宿主子 Agent 能力 | 🔴 | 不支持的宿主只能降级为"自包含提示词"隔离，隔离强度打折 |
| A-02 | 细纲容量不足 → 讲述者用模型先验填充 → AI 味回归 | 🔴 | 细纲太薄时模型会朝统计默认值漂移（棕眼睛/高大男主），T1 初稿 7844 字节容量不足的根因可能在此 |
| A-03 | 长篇连续性由谁保证 | 🔴 | 讲述者只知细纲，剧本必须消化"上章结尾+active hooks+角色状态"进细纲，编剧是连续性负责人 |
| A-04 | 打回没有上限和定位 | 🟡 | 需 2 轮上限 + 区分"故事没吸引力→回编剧" vs "写得太差→回讲述者" |
| A-05 | 评估汇报不带证据 = 打回无法执行 | 🟡 | 评分必须 + 引用原文 + 修改方向（C-006 证据链铁律） |
| A-06 | 四份产物格式契约缺失 | 🟢 | 细纲/初稿/评估汇报/Change Report 需要最小 schema |
| A-07 | 落库非原子 | 🟢 | 6 状态文件改一半失败 = 半新半旧；需暂存→校验→提交→回滚 |
| A-08 | 成本翻倍需知情 | 🟢 | 每章 5 次 LLM 调用 vs 当前 1-2 次，需用户知情同意 |
| A-09 | 长篇/短篇流程参数化 | 🟢 | 同架构两种流程的参数切换 |
| A-10 | 细纲确认门 | 🟢 | 防"垃圾进垃圾出"，细纲不合格不进入写作 |
| A-11 | 声线卡必须进细纲 | 🟢 | 讲述者不知道角色怎么说话 → 同腔；遮名测试应进自检 |
| A-12 | 字数归属：写进细纲 | 🟢 | 由编剧按憋压层次算字数，不是另传 |
| A-13 | 编排层复核标准可检查 | 🟢 | 复核不能凭感觉，要有 checklist |
| A-14 | 复核不得回写 | 🟢 | 规则/修改意见不许流回执行角色上下文，只通过打回指令传递 |

## C 组：长篇写作本体问题（人类作者视角 · 外部调研）

### C-1 结构层（主线/大纲/骨架）

| 编号 | 问题 | 来源 |
|------|------|------|
| C-101 | 主线说不清/无主线 → 剧情凌乱碎片化 | 抖音（主线一句话说不清必跑题；主线在推进中不是完成中） |
| C-102 | 大纲没有终点 → 写着写着迷路 | 抖音（大纲要有终点，知道结局才不会迷路） |
| C-103 | 中期最容易崩（1/3 处热情耗尽） | 抖音（15 条结构心法） |
| C-104 | 分卷不换赌注 → 读者疲 | 抖音（每卷主角面对的东西要升级） |
| C-105 | 支线喧宾夺主 / 支线不回归主线 | 抖音（主线 50-60%，支线 30-40%，暗线 10-20%，删主线全书散架） |
| C-106 | 主角目标不具体（"变强"vs"拿到某物"） | 抖音（目标要具体才有具体剧情） |
| C-107 | 三线并行写乱 | 抖音（主线/支线/暗线关系不清，需伏笔清单+卷末收束） |
| C-108 | 战力/世界观规则摇摆（即用即抛、例外特权） | 中国作家网《龙族》案例（血统等级降级无标准、超规格归因"血脉特殊性"） |
| C-109 | 设定前后矛盾 → 靠改设定硬推 | 抖音（设定可以慢慢补，不能前后打架；圆不上剧情=读者信任崩） |
| C-110 | 世界观开篇全摊开 = 百科全书开头 | 抖音（设定藏进动作里，读者和主角建立情感连接前全是噪音） |
| C-111 | 冲突设计错误（只有吵架打斗才算冲突） | 抖音（冲突=想要的东西+阻拦+主动争取；内心纠结/情感对立/目标相悖都算） |
| C-112 | 假推进（活动增加但后果不增加） | Novelium（情节失控类型）+ 抖音（每章有事但主线没抬高） |
| C-113 | 支线四种失控 | Novelium（休眠/脱离/过早兑现/迟召回） |
| C-114 | 赌注不升级/金手指不升级 | 抖音（一开局就无敌后面拿什么往上走；能力要随剧情成长） |

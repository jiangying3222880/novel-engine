# v2.1.4 · 作者声音样本（#29c）实测报告

**日期**：2026-10-16
**触发**：主人提问「声音样本核实一下，是小说角色的声音还是作者的声音样本」

## 一、核实结论

仓库里并存**两套声线**，且此前没有任何一处写明它们是两回事——这是本次发现的真实缺陷。

| | 作者声线（§5.2 本区） | 角色声线（另一套） |
|---|---|---|
| 谁的嘴 | 作者的笔：叙述/描写/动作/心理转述 | 每个角色的嘴：说出来的话 |
| 落点 | `配置/身份/作者.md` §5.2 | `设定/角色声线.md`（模板 `ne-write/templates/voice-profile-template.md`） |
| 谁负责 | 作者·决策态（立项时定） | 编剧·S1（从 characters.md 透传进细纲 §5，须标来源） |
| 机器闸 | **原本没有**（v2.1.4 补 #29c） | 有：verify 校细纲 §5 标了来源 + S3 遮名测试 Q2a |

**答案：§5.2 的声音样本 = 作者的叙述声线，不是小说角色的声音。**

## 二、取样三条硬口径（写进 §5.2）

1. 主体必须是叙述/描写/动作段 —— 引号内台词占比 ≤ 1/3。全是对话 = 粘的是角色声线。
2. 挑常态段，不挑高潮段 —— 高潮段句式变形，拿它当基准会让全书一直紧绷。
3. 段里不许有"这一章的目的是"式的工艺语言。

**第一人称特例**：叙述人称为主角时，"作者腔"与"主角叙述腔"合并，但**仍 ≠ 主角的对话腔**
（心里怎么讲 vs 嘴上怎么说，是两套节奏）。

## 三、门禁 #29c（init 作用域 · WARN 级）

| 样本 | 实测结果 |
|---|---|
| 无「样本段」行 | `[WARN] 样本段为空或过短（0 字，需 200-400 字叙述段）` |
| 模板原文（含"取样三条硬口径"） | `[WARN] 样本段仍是模板原文（未替换成真实成稿）` |
| 全是对话 | `[WARN] 样本段台词占比 53% > 1/3 —— 那是角色声线，本区要的是叙述/描写/动作段` |
| 真实叙述段 | **无告警**（WARN 只真命中才发声） |
| 文件缺失 | `[WARN] 缺 配置/身份/作者.md`（同时 #29 FAIL） |

**为什么是 WARN 不是 FAIL**：样本只能由人提供，机器填不出来，硬 FAIL 会锁死立项。
**为什么不恒定发声**：v2.1.2 第②例的教训——`else: warn(名字,'OK')` 会让检查项恒定出现在
WARN 列表，看着有检查，实为假警报。

## 四、回归固化

# 两阶段写作流程设计 v1（骨架→血肉）

> 性质：v1.9.0 流程层核心改造草案。回答"先骨架后血肉是否可行"——可行，且有行业证据；但"骨架"必须重新定义（见 §1）。

## 0. 结论先行

- **方向可行**：Ghostproof（beat sheet supremacy）、SegmentFault（不让 AI 决定剧情走向）、StoryWriter（outline→planning→writing 三 Agent）均验证。
- **T1 实测 7844 字 = "骨架没力度"的直接证据**：细纲给不出这节该干嘛 → 讲述者写个"高密度框架版"草草收场。
- **关键纠正**：现在的细纲是"标题式"（第一章相遇/第二章误会）= PPT 提纲 = 没力度。骨架必须是四维约束 + 叙述形态。

---

## 1. 骨架 = 四维约束（替代现在的标题式细纲）

| 维度 | 要写什么 | 对应问题清单 |
|------|---------|-------------|
| 冲突链 | 主角想要什么 → 谁拦他 → 第一次怎么弄砸 → 付出什么代价 | E-005 / C-111 |
| 情绪弧 | 这一节的憋压层次：压什么、压到第几层、临界点在哪 | C-202 / C-205 |
| 信息释放 | 这节给读者什么新信息、藏什么、在哪一秒给（钩子点） | C-207 / C-401 |
| 声线要求 | 出场角色各自的说话方式/第一反应/在意点 | C-602 / A-11 |

**骨架有力度 = 叙述形态 + 删节断链**
- ✅ 叙述形态："林野发现老赵声音可疑 → 备份语音 → 设局"
- ❌ 流程图形态："目标→行动→阻力→选择→结果"
- ✅ 删掉任何一节，故事链条断掉 = 力度够
- ❌ 任何一节删掉不影响链条 = 注水骨架，打回

## 2. 两阶段流程（骨架 → 血肉）

### 阶段 S1：骨架（编剧层 · 规划产物）

**输入**：分卷大纲 / 章节大纲 / 上章结尾 + active hooks + 角色状态 + 声线卡

**产出（叙述形态细纲，落盘）**：
```
章节细纲_第000X章.md
├─ 冲突链（叙述形态，4 节点：想要→阻拦→弄砸→代价）
├─ 情绪弧（憋压层次：第几层/压什么/临界点）
├─ 信息释放（新信息/藏的/哪一秒给）
├─ 声线要求（出场角色说话方式/第一反应）
├─ 任务字数（按憋压层次计算，每节目标）
└─ 事件驱动格式（角色→干什么→阻碍→动机→发生什么→驱动）
```

**力度门禁（A-10 细纲确认门）**：
- [ ] 叙述形态（非流程图）
- [ ] 删任意一节链条断
- [ ] 冲突链完整（有人想要/有人拦/有代价）
- [ ] 每节有明确任务字数
- 不通过 → 打回编剧重写（最多 2 轮，A-04）

### 阶段 S2：血肉（讲述者层 · 正文写作）

**输入**：仅骨架文件（叙述形态细纲）+ 任务字数

**约束（物理隔离核心）**：
- 讲述者上下文**物理上只有骨架**——无规则文本、无技法库、无 L0 铁律（A-01）
- 不做：新增情节 / 改变节奏 / 解释设定 / 跳层加戏
- 只做：把骨架节点翻译成场景 / 动作 / 对话 / 细节

**产出**：干净正文初稿（无 YAML）

### 阶段 S3：检验（编辑/润色师层 · 对照骨架核对）

**不重写正文，只出报告（A-05 证据链）**：
```
检验报告_第000X章.md
├─ 骨架逐节点核对（每节点 ✅/❌ + 原文证据）
├─ 遮名测试（C-602）：声线是否进嘴
├─ 情绪弧核对：憋压层次是否到位
├─ 信息释放核对：钩子点位置
└─ 结论：通过 / 打回（区分：骨架问题→回 S1；表达问题→回 S2）
```

**打回规则（A-04）**：
- 骨架问题（链条断/没力度）→ 回 S1 编剧
- 表达问题（写得太差/声线崩）→ 回 S2 讲述者
- 上限 2 轮，保留 Best Version

### 阶段 S4：落库（档案员层）

- 依据 S3 报告 + Change Report 更新 6 状态文件（A-07 原子提交）
- 滚动窗口：写第 N 章时读 N-5~N+5 章骨架（B-02）
- 输入包（骨架文件 + 检验报告）落盘存档 = 隔离证据链（D-214）

## 3. 与现有五阶段 SOP 的关系

| 现有 SOP | 新流程 | 变化 |
|---------|--------|------|
| 阶段⓪ 初始化 | 不变 | — |
| 阶段① 规划 | S1 骨架（强化为四维+叙述形态+力度门禁） | 细纲规格重写 |
| 阶段② 写作 | S2 血肉（物理隔离：仅骨架输入） | 上下文瘦身 |
| 阶段③ 自检 | S3 检验（对照骨架，不改稿只出报告） | 自检对象从"正文"变"骨架对齐" |
| 阶段④ 反AI润色 | 并入 S3 检验的"表达问题"分支 | 打回而非原地改 |
| 阶段⑤ 落库 | S4 落库（原子提交） | 增加输入包存档 |

## 4. 验证标准（v1.9.0 baseline）

- 同命题（《中秋》都市憋压赘婿）重跑
- **骨架力度验证**：S1 产出删节测试（删任一节链条是否断）
- **隔离验证**：S2 输入包原样落盘（证据链）
- **初稿对比**：新流程初稿 vs 7844 字（目标：单节 ≥ 1500 起步，向 2000 逼近）
- **AI 味盲评**：隔离前后同命题段落，用户盲评

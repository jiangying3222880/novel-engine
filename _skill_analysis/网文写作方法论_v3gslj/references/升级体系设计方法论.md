# 升级体系设计方法论（番茄官方课程）

> 来源：番茄小说网 2026-07-01「打破"流水账升级"：让剧情真正"爽"起来」
> 适用范围：所有含成长/升级体系的网文，通用铁律

## 核心理念
升级体系的核心不是"怎么升更爽"，而是**"为什么能升、为什么不能乱升、升了会带来什么代价"**。
把升级体系当成一套**带成本、带门槛、带副作用**的成长规则系统来设计。

## 一、规划升级体系六步法

### 1. 定底层能源【重点】
角色凭什么变强？建议只选**1个主要原因+1个次要原因**。
- 主要：灵气/血脉/科技/信仰/法则领悟
- 次要：悟性/天赋/心境
- ⚠️ 力量来源过多（灵气+血脉+神器+气运），后期逻辑必崩

### 2. 控制阶梯数量【重点】
- 大阶控制在**4-7个**之间
- 大阶=质变（可分前中后期），小层=量变
- 例：5大境界×3小阶段=15台阶，优于"等级1-100"
- 每次突破都应是剧情高潮

### 3. 定每阶的质变内容【重点】
每提升一个大阶段，必须有**清晰的质变理由**，不只是数值变高：
- 前期：身体/能量积累
- 中期：技巧/结构/体系成形
- 后期：法则/领域/世界级权限

### 4. 升级体系与世界结构绑定
个人变强路径必须与社会资源分配方式一致，回答三个问题：
- ①高阶资源被谁掌握？
- ②普通人能升到哪一步？
- ③升级后社会地位是否改变？

让升级动机不只是"想变强"，而是"要活下去""要被尊重"——和现实利益挂钩。

### 5. 提前设计"例外机制"
主角可以特殊，但必须写清**来历与边界**：
- ①例外来源（双核心、极罕见血脉等）
- ②例外优势（带来什么收益）
- ③例外代价（承担什么风险/损耗）
- ④例外边界（在什么范围内有效）
- ⚠️ ①②必填，③④至少写一个

### 6. 给每阶补全"输入—过程—输出"
- 输入：升级前提条件（灵石、功法、战斗经验等）
- 过程：压缩能量、冲击经脉、稳定核心等
- 输出：技能+1、寿命+20、感知+50等

## 二、六大常见问题

| # | 问题 | 后果 |
|---|------|------|
| 1 | 资源设定前后不一 | 世界观稳定性被削弱 |
| 2 | 只有等级没有机制 | 读者没有升级实感 |
| 3 | 例外太多 | 常规体系沦为摆设 |
| 4 | 金手指过于万能 | 挤压其他角色存在空间 |
| 5 | 越阶战常态化 | 等级压制失去意义 |
| 6 | 能力没有副作用 | 后期极易失控 |

## 三、六条解决对策

### 1. 用资源限制锁死规则
- 写作前为关键资源设定：**稀缺度、获取渠道、使用门槛**
- 低阶资源可普及，高阶资源必须稀缺
- 资源从珍贵变常见必须有充分原因（新产地/技术改良/进入更高层圈子）
- 定期回看前文检查资源规则

### 2. 用承载限制补足机制
- 设定"承载上限"：经脉承压、精神力阈值、肉体极限
- 每阶段对应明确变化，不只是"更强了"
- 变化维度：身体素质、感知范围、技能上限

### 3. 限制"例外"
常规是底层基础，例外只负责制造冲突与亮点，不可反客为主。
每个特殊设定回答三个问题：
- 来源是什么？
- 代价是什么？
- 能否复制？

### 4. 让金手指"有边界"
- 先定核心方向，再主动保留短板
- 设计短板：如能看穿谎言但身体素质极差
- 规则限制：如复制技能消耗等量寿命
- 一项能力不可同时兼备攻/治/防/控等多重功能

### 5. 越阶战要有提前铺垫
- 越阶取胜是"特殊事件"，不是惯常现象
- 条件必须极为苛刻且提前铺垫
- 原则：越阶战只能偶发，不能成为常态
- 叙事层面提前介入+规则层面硬性限制，双管齐下

### 6. 能力附带相应成本
- 越强的能力，成本越高
- 成本维度：体力/精神/寿命/冷却/因果/社会后果
- 副作用的意义：不只限制角色，更增强剧情张力
- 副作用不必每次都剧烈，但必须**长期稳定存在**
- 让角色在"要不要动用"之间作真实权衡

## 四、自检清单
- [ ] 底层能源是否简洁（1主+1次）？
- [ ] 大阶数量是否在4-7之间？
- [ ] 每个大阶是否有明确质变内容？
- [ ] 升级体系与社会资源分配是否一致？
- [ ] 主角的"例外"是否有来源、代价、边界？
- [ ] 每个阶段是否有完整的输入-过程-输出？
- [ ] 关键资源的稀缺度/获取渠道/使用门槛是否设定？
- [ ] 金手指是否有明确短板和边界？
- [ ] 越阶战是否偶发且有铺垫？
- [ ] 强能力是否附带相应成本？

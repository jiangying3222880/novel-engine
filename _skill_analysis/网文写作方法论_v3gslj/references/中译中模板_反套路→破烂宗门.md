## 一、反套路核心公式（必须遵守）

### 1.1 一句话公式
**主角越不要脸 → 系统越给奖励 → 外界越懵逼 → 读者越爽**

【原文对应】徐缺越无耻 → 装逼值越多 → 买的东西越强 → 别人越震惊

### 1.2 每章必备四要素（缺一不可）
1. **一次装逼/不要脸行为**（主动或被动都算）
2. **一次系统弹窗+奖励**（弹窗本身就是笑点）
3. **一次旁人震惊/懵逼反应**（"嘶！""怎么可能？""这……"）
4. **一个章尾钩子**（新威胁/新人物/新发现）

【原文对应】Ch1: 徐缺 bluff 驸马身份→装逼值+1→女子呆住→系统新手礼包；Ch2: 徐缺偷藏宝阁→装逼值+10→唐雪茹震惊→佩剑少年出现

### 1.3 喜剧来源（按优先级排序）

| 优先级 | 类型 | 我们的实现方式 | 【原文对应】 |
|--------|------|---------------|------------|
| 1 | 系统弹窗打断正经时刻 | 系统在严肃时刻弹出刻薄评价 | 系统在追杀时弹"装逼成功" |
| 2 | 主角不要脸+面不改色 | 林牧用三万年知识一本正经胡说八道 | 徐缺自称驸马/假扮自己爹 |
| 3 | 破烂变神器（反差） | 系统给的全是破烂，鉴定后全是上古货 | 系统商城的武侠功法出现在修仙界 |
| 4 | 配角震惊+脑补 | 外人把破烂宗门当隐世圣地 | 路人震惊"怎么可能""此人深不可测" |
| 5 | 系统嘴臭+主角回怼 | 林牧和系统互骂 | 徐缺骂系统"你怎么不去抢" |
| 6 | 信息差装逼 | 林牧知道答案但说不清来源 | 徐缺用地球知识在修仙界装逼 |
| 7 | 无心装逼（最致命） | 林牧随便做一件事被当成高深操作 | 无形装逼最致命（Ch5） |

### 系统弹窗标准格式（对标原文）

**原文格式：**
```
"叮，恭喜宿主'徐缺'装逼成功，获得装逼值1点。"
```

**我们的格式：**
```
【叮！恭喜宿主'林牧'被嘲笑成功！破烂值+10！】
【系统提示：外界对太初宗的鄙视程度正在持续上升。建议宿主习惯。】
```

**原文装逼失败：**
```
"滴，宿主'徐缺'装逼失败，此次行为不给予奖励。"
```

**我们的版本：**
```
【叮！宿主试图装逼……失败。原因：修为太低，说服力不足。破烂值-5。】
【系统建议：宿主下次装逼前，请先确认对手修为不超过自己三个大境界。】
```

## 六、系统语录库（对标原文系统提示风格）

### 奖励类
- 【叮！恭喜宿主被嘲笑成功！破烂值+10！外界的鄙视就是宿主成长的养料。】
- 【叮！任务完成！奖励：破烂值×200。系统评价：宿主这次表现还行，勉强没丢系统的脸。】
- 【叮！新手礼包已发放！内含：破碗×1（缺口处可当杯用）、锈剑×1（锋利度为零，但可当烧火棍）。宿主满意吗？系统不满意。】
- 【叮！检测到弟子'叶灵'潜力值异常。建议宿主不惜一切代价收留。否则系统将强制扣除1000破烂值。这不是建议，是威胁。】

### 嘲讽类
- 【系统检测到宿主修为：练气一层。在万界宿主排名中，您位于……系统选择不显示。怕您受不了。】
- 【宿主又在装逼了。系统建议：量力而行。上次装逼失败的教训，宿主应该还记得。】
- 【破烂商城今日特惠！全场九折！……虽然打折后宿主还是买不起。】
- 【检测到前方有金丹修士。系统建议：绕道。宿主当前修为：练气。差距：大概……很大。】

# 世界观搭建（番茄官方课程·通用方法论）

> 来源：番茄小说网 2026-06-25 官方课程「打破"背景板"：让你的故事真正"活"起来」
> 适用范围：所有品类，通用铁律

## 核心原则
- **设定不是写给读者看的，是写给自己不乱用的**
- 力量体系要让读者感觉它是稳定存在的，不是作者现编的
- 世界观靠的不是设定多，而是矛盾够清楚

## 一、基础背景设定六要素

### 1. 时空背景
- 时代、空间、真实度
- 长篇不怕舞台大，但**开始一定要有主要舞台**，不要摊得太散

### 2. 社会结构（决定"人怎么被分层"）
- 权力结构：谁掌权（皇权/宗门/财阀...）
- 阶层结构：贵族与平民、顶流与糊咖...
- 身份规则：出身是否决定命运，有没有阶层流动
- **没有社会结构，人物关系就会飘**

### 3. 运行规则（最关键的一层）
- 生存规则：靠什么谋生
- 竞争规则：晋级/成名/变强靠什么
- 交易规则：资源如何流动
- 惩罚规则：违规代价有多大
- 可以不用全写，但**必须写清楚最影响主线的那几条**

### 4. 核心矛盾
- 阶层矛盾：贵族vs寒门
- 权力矛盾：皇权vs世家
- 资源矛盾：灵脉、名额、流量争夺
- 价值矛盾：家族利益vs个人自由
- **长篇世界观一定要有"大矛盾背景"，后面剧情才能持续升级**

### 5. 超凡/特殊系统（玄幻、科幻等必填）
- 力量来源：灵气/血脉/科技/系统
- 力量等级与差距
- 使用代价与获得方式
- 对社会秩序的影响

### 6. 主角的入场方式
设定完后立刻问自己：
- 主角出身在世界的哪一层？
- 主角最先撞上的规则是什么？
- 后期升级，能否自然接入更大的世界层面？

## 二、撰写思路（五步法）

1. **定题材和主舞台**（只定主角最常接触的那层世界）
2. **定最重要的3条规则**（只写最影响主角命运的）
3. **定2-3组核心对立关系**（嫡vs庶 / 正道vs魔道 / 老牌资本vs新人）
4. **定主角的入场方式**（弱者求生 / 重生复仇 / 底层逆袭）
5. **先立核心，跑起来再扩充**外层地图、更高层势力、历史旧案

## 三、自检清单

- [ ] 主舞台是否明确且聚焦？
- [ ] 社会分层是否清晰？读者一眼能看出谁在上谁在下？
- [ ] 运行规则是否只写了最影响主线的几条？（不贪多）
- [ ] 核心矛盾是否天然产生冲突？（不需要硬制造）
- [ ] 力量体系是否感觉"稳定存在"而非"现编"？
- [ ] 主角入场后能否自然撞上核心规则？
- [ ] 后期升级能否自然接入更大世界层面？

# 起点黄金三章方法论

> 来源：用户总结，2026-08-04
> 核心：黄金三章定生死，3000字内抓住读者

## 与番茄的关键区别
- **番茄**：开篇无脑爽。读者一眼看过去想看的就留下，不想看的直接扑街。第1章主角就要"赢"。
- **起点**：三章缓冲。允许3000字内完成"冲突→金手指→钩子"的递进，读者愿意等"渐入佳境"，但三章内必须见爽点/悬念。

## 四步节奏（3000字内）

### 1. 冲突前置——300字内抛"炸弹"
- 别写风景/独白，直接上"正在发生的危机"
- 类型举例：
  - 绝境逆袭："'废物，跪下！'堂兄踹得林辰肋骨渗血，今天是他灵根尽废+未婚妻退婚日"
  - 职场/战场："项目被抢功还背锅""小队团灭只剩主角"
  - 日常反常："订婚宴被当众撤席""借儿子零花钱倒欠100元"
- 300字内用动作/对话制造紧张感，让读者想"接下来怎么办"

### 2. 1000字内亮金手指，立反差人设
- 冲突后快速给解决方案：
  - 爽文："叮！逆命系统激活，新手礼包洗髓丹"
  - 悬念："儿子账本藏着秘密"
  - 共鸣："主角反手怼回双标父母"
- 同时立人设：杀伐果断、机智幽默等特质要鲜明
- 反差感留记忆点，比如"废物体质却藏神秘宝物"

### 3. 节奏为王——200字一个小看点
- 拒绝大段设定/心理描写，按"200字法则"推进：
  - 0-200字：冲突/悬念（抓人）
  - 200-400字：主角反应+金手指线索
  - 400-600字：小危机解决+新悬念
  - 600-1000字：金手指显威+下一章钩子
- 每段有动作/对话，信息密集无废话

### 4. 结尾留钩子，促追读
- 章节末用金句/悬念勾人：
  - 爽文："洗髓丹入腹，林辰睁眼：'该算总账了'"
  - 悬念："儿子账本指向失踪的妻子"
  - 共鸣："孩子一句话，父母沉默"

## 避坑
- 别开篇堆设定：世界观/功法随剧情自然流露
- 别流水账："清晨发呆"式铺垫直接劝退
- 别信息堆砌：冲突→人设→钩子递进，别一锅烩
- 别慢热：起点读者没耐心等"渐入佳境"，3章内必须见爽点/悬念

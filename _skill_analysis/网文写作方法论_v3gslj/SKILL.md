# 网文写作方法论

## 概述

本技能是网文创作的全套方法论与经验库，包含从风格规范到泡书笔记到拆书骨架的所有实战经验。适用于：写新章节、修改已有章节、检查AI味、泡书分析、拆书学习、设计大纲等。

## 工作流程

### 1. 动笔前：读取写前必读清单

每次写章节前，**必须先读取** `references/写前必读清单.md`，这是所有规则的精简 checklist。

### 2. 写作中：遵守核心规则

**风格铁律（最高优先级）：**
- **余华式大白话**：短句为主但不死板，感情藏在细节里，形容词砍到底，越重要的事说得越淡
- **旁白必须是"叙述者在说话"**：评价/分析/吐槽/总结，禁止动作报告式旁白（皱眉/叹气/转头/看）
- **流畅叙述 > 刻意碎片化**：不要每句都短，段落可以长，自然流动
- **段首"他/她/它"≤2个**：换成角色名或省略主语，这是朱雀最敏感的AI指纹

**硬指标：**
- 字数：2000-2500字（纯汉字），超2500拆下一章
- 对话占比 ≥30%
- 破折号（——）≤5个
- 省略号（……）≤3个
- 骚话 ≥7个（每500字至少1个）
- 断章钩子 = "断头看身"式（读者和角色同时撞见不该撞见的真相）

**旁白性质判断（降AI核心）：**
- ✅ 通过：叙述者在说话（"你说这事儿闹的"、评价、吐槽、总结）
- ❌ 不通过：动作报告（"林牧皱了皱眉"、"苏明叹了口气"、"赵淮转头看了看"）

**禁止的AI指纹：**
- 格言式总结句（可脱离上下文独立存在的"人生哲理"）
- 说明书句式（"X需要Y个Z做W"）
- 内心标签（"心想"、"想到"、"暗自思忖"）
- 沉默/不说话类被动反应（要写内心吐槽）
- 连续信息报告零态度（连续3句以上报告数字/设定）
- 诗意细节（每个细节都在"营造氛围"）
- 金句递进（每句话都像剧本台词精准推进情绪）
- 段首"他/她/它"连续出现

### 3. 完稿后：自检清单

逐项检查：
- [ ] 字数 2000-2500？
- [ ] 破折号 ≤5？省略号 ≤3？
- [ ] 段首"他/她/它" ≤2？
- [ ] 骚话 ≥7？（覆盖至少3种类型）
- [ ] 断章钩子是"断头看身"式？
- [ ] 章首真正衔接章尾？（同一件事拦腰砍断后继续）
- [ ] 旁白是叙述者在说话，不是动作报告？
- [ ] 没有格言式总结句？没有说明书句式？
- [ ] 读起来像"有毛病的文章"而非"正确的文章"？

## 关键理念速查

### 说书人七条铁律
1. 叙述者要有存在感——你不是翻译机，是评论员
2. 情绪对冲——哭完就笑，笑完给刀
3. 先压后扬——憋屈越深，爆发越爽
4. 感官递进——打脸要让人"看见画面"
5. 说书人的"卖关子"——每500字一个小钩子
6. 旁白要接地气——神仙也得吃饭拉屎
7. 最狠的情感用最淡的笔——克制即力量

### 降AI十大原则
1. 废笔打断观察链
2. 别替读者解说
3. 世界要有名字（具体数字+名词代替形容词）
4. 情绪反应不加验证动作
5. 不用游戏品质标签，对比用细节
6. 转场不写"他在想"
7. 打破因果链
8. 情绪错位
9. 大事里塞小事
10. 口语化过渡

### 核心口诀
> AI用形容词人用名词数字。AI解释人看到的，人只写发生的。AI情绪走标签人走错位。AI写有用的，人写无用的。AI角色沉默旁观，人一路碎碎念。

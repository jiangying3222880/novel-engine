# 综漫小说创作指南

面向刺猬猫、番茄等平台的综漫/动漫同人小说创作全流程工具。从赛道分析到书名、简介、世界设计、道具联动、平台规则，一站式解决"想写综漫但不知道从哪下手"的问题。

## 触发后工作流程

### 第一步：明确用户需求

通过对话确认以下信息（用户没说的主动问）：

1. **目标平台**：刺猬猫？番茄？起点？还是不确定需要建议？
2. **核心设定**：主角的金手指是什么？穿越机制是什么？
3. **起始世界**：从哪个动漫世界出发？（如果用户没想好，根据热门IP推荐）
4. **风格定位**：轻松吐槽？热血剧情？黑暗深沉？日常经营？
5. **当前阶段**：还在想？已有大纲需要优化？还是写到一半卡住了？

### 第二步：平台适配分析

根据用户选择的目标平台，读取 `references/platform_guide.md` 获取该平台的：
- 读者画像和题材偏好
- 签约/上架节奏和关键节点
- 推荐机制和新书期攻略
- 读者雷区和OOC尺度

**核心判断**：如果用户的题材与平台调性不匹配，直接告知并建议换平台或调整方向。比如传统玄幻/霸总不适合刺猬猫，纯日常不适合番茄爽文流。

### 第三步：书名设计

读取 `references/platform_guide.md` 中的书名规律部分，按以下流程设计书名：

1. 分析用户原书名（如有）的优劣
2. 结合核心设定和平台热门句式，生成5-10个书名方案
3. 按以下维度评估每个方案：
   - **搜索友好度**：关键词是否覆盖目标读者搜索习惯
   - **点击欲望**：是否有钩子和记忆点
   - **差异化**：是否与平台现有热门作品区分开
   - **信息量**：读者能否一眼get到核心卖点
4. 给出TOP3推荐并说明适用场景

**六大主流书名模式**（刺猬猫验证）：
- 身份流：我，XX，XX（装逼/反差）
- 设问流：现在XX还来得及吗？（吐槽/悬念）
- 反差流：XX，但是XX（反套路）
- 地点流：在XX开XX的二三事（日常/经营）
- 金手指流：从XX开始的XX（设定展示）
- 反转流：原来，XX才是XX（打脸/反转）

### 第四步：简介写作

读取 `references/platform_guide.md` 中的简介模板部分，按用户需求选择模板并生成简介草稿：

**黄金五段式结构**（通用）：
```
【起】金手指/设定引入——我是谁？我有什么特别的？
【承】主角的困境/初衷——我想做什么？遇到什么问题？
【转】反转/反差——但事情发展和我想的完全不一样！
【合】具体玩法/世界预告——读者能看到什么内容？
【结】金句收束——一句话留下记忆点和悬念
```

**三种模板**：
- 吐槽反转型（最适合刺猬猫）：正常愿望→被金手指/现实打脸→反转笑点
- 悬念钩子型（适合剧情流）：核心悬念→逐步揭开→更大钩子
- 设定展示型（适合系统流/道具流）：直接亮金手指→展示深度→留限制

### 第五步：世界设计

读取 `references/props_and_worlds.md` 获取详细的动漫世界数据和道具信息，按以下原则设计世界顺序：

**排序三原则**：
1. 由易到难：战力体系从低到高，让主角和读者一起成长
2. 由热到稳：先用热门IP吸量，再用深度IP留客
3. 联动空间：每个世界都要有独特的「金手指×世界」化学反应

**世界设计清单**（每个世界必须回答）：
- 选择这个世界的理由是什么？（读者基数/战力适配/联动空间）
- 主角在这个世界能获得什么？（能力/道具/角色关系/知识）
- 金手指在这个世界怎么发挥？（至少3个具体联动场景）
- 这个世界的核心爽点是什么？（用一句话说清楚）
- 建议多少章？（根据世界体量和剧情密度）

### 第六步：道具联动与战力控制

读取 `references/props_and_worlds.md` 中的道具分类和联动玩法部分：

**道具联动四模式**：
1. 降维打击流：未来道具在低武世界横着走（前期爽感）
2. 规则碾压流：因果律道具改写世界规则（逼格最高）
3. 反差萌流：可爱道具用在严肃世界（幽默感）
4. 组合技流：多道具组合产生1+1>2效果（智斗感）

**战力膨胀控制六法**（必须告知用户）：
1. 分级解锁制：每完成一个世界解锁几个新道具
2. 能量消耗制：越高级道具消耗越大
3. 世界抗性制：高等级世界对外来规则抗性更强
4. 使用冷却制：强力道具有冷却时间
5. 对等敌人制：引入同样有因果律能力的敌人
6. 代价回收制：改变重要事件后世界修正力会反扑

## 输出规范

根据用户需求阶段，输出对应产物：

- **赛道分析阶段**：平台适配报告 + 热门作品参考 + 差异化建议
- **书名设计阶段**：5-10个书名方案 + 优劣分析 + TOP3推荐
- **简介写作阶段**：2-3个简介草稿 + 对应书名搭配
- **世界设计阶段**：世界排序方案 + 每个世界的详细设计卡
- **道具联动阶段**：道具分类清单 + 联动玩法TOP10 + 战力控制方案

## 关键注意事项

1. **不要脱离平台谈创作**：同一个题材在刺猬猫和番茄的写法完全不同，必须先确定平台再给建议
2. **不要给空泛建议**：每个建议都要有具体案例/数据支撑，不说"可以适当加入吐槽"这种废话
3. **尊重IP但不被IP绑架**：同人OOC在刺猬猫容忍度较高，核心角色性格底色不崩即可，不用死抠原作设定
4. **战力控制是生命线**：道具流最容易写崩的就是战力膨胀，必须在设计阶段就定好限制规则
5. **间贴是刺猬猫的命脉**：提醒用户在章节中刻意设置吐槽点，认真回复间贴培养死忠读者

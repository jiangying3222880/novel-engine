# 平台指南

## 一、刺猬猫平台详解

### 1.1 平台定位

刺猬猫阅读（前身欢乐书客），杭州狂想网络科技运营，国内二次元轻小说与同人赛道沉淀最久的垂直平台。平台底色是ACG垂直社区，欢迎三类内容：**二次元同人、原生轻小说、宅向原创**。传统玄幻/霸总题材不适合。

平台书名统计：综漫出现615次、无限出现1469次、穿越出现1668次——这三个词组合覆盖平台相当大比例的作品。

### 1.4 简介写作模板

**黄金五段式**（通用结构）：
```
【起】金手指/设定引入——我是谁？我有什么特别的？
【承】主角的困境/初衷——我想做什么？遇到什么问题？
【转】反转/反差——但事情发展和我想的完全不一样！
【合】具体玩法/世界预告——读者能看到什么内容？
【结】金句收束——一句话留下记忆点和悬念
```

**三种模板**：

**模板A：吐槽反转型**（最适合刺猬猫）
```
【起】我只是想XXX而已
【承】（交代背景/金手指）
【转】结果没想到……（2-3个离谱反转）
【合】（预告涉及的世界/角色）
【结】所以说，XX就这么难吗？/我只是想XX啊！
```

**模板B：悬念钩子型**
```
【起】神秘开场（一个问题/场景）
【承】主角获得能力/进入世界
【转】但事情没那么简单……（揭示更深层设定）
【合】（列举挑战和目标）
【结】终极悬念/口号
```

**模板C：设定展示型**
```
【起】直球抛设定（我有XX系统/金手指）
【承】金手指能干什么（2-3个核心功能）
【转】但有限制/有挑战（不能太无敌）
【合】各世界的独特玩法预告
【结】霸气收束/目标宣言
```

### 1.5 签约与上架节奏

| 阶段 | 字数 | 时间 | 重要性 |
|------|------|------|--------|
| 发书 | 6000字起(3章) | 第1周 | 编辑发现的最低门槛 |
| 签约线 | 3万字 | 第1-2周 | 编辑评估通过给合同 |
| 首轮推荐 | 5万字 | 第2-3周 | 试水推，生死线 |
| 二轮推荐 | 7-8万字 | 第3-4周 | 人气新书推荐 |
| 三轮推荐 | 9-11万字 | 第4-5周 | 畅销优选 |
| 上架线 | 12万字 | 第5-6周 | 周五上架 |

**全勤奖**：A签千字8元/B签千字6元/C签千字4元/D签千字2元。月更须达12万字。连续断更30天取消全勤。

### 1.6 推荐机制

新书期推荐分三轮（每轮一周，周五到下周五），前三天数据基本定生死：
1. 组内试水推 → 最低档，测试数据
2. 人气新书 → 数据好的晋级
3. 畅销优选 → 最高档，吃满三轮基本稳了

**操作建议**：
- 周一到周四发书（编辑周末休息）
- 日更不低于4000字，一天2章，每章≥2200字
- 前三章必须有金手指、有冲突、有钩子
- 每3章一个小高潮，章节末尾留钩子

### 1.7 读者偏好与雷区

**读者喜欢**：
1. 有新颖设定和玩法（烂活 > 没活）
2. 反差和吐槽（反差萌、日常vs非日常）
3. 角色化学反应
4. 玩梗密集
5. 间贴互动活跃

**读者雷区**：
- ❌ 断更太监（刺猬猫太监率长期偏高，读者深恶痛绝）
- ❌ 收集图鉴式后宫（十几个女主排不上号）
- ❌ 照搬人设无思考
- ❌ 自嗨式剧情

**OOC尺度安全操作**：
| 角色类型 | OOC容忍度 | 建议 |
|---------|-----------|------|
| 经典角色（御坂美琴、雪乃等） | 低 | 贴合原人设，转变要有铺垫 |
| 二游角色（星铁/原神/方舟） | 高 | 塑造苍白，全写爱你哟都没人管 |
| 男角色（反派/对手） | 高 | 适度调整问题不大 |
| 后宫向女主 | 中 | 简介写明桃文/后宫，OOC声音少 |

### 1.8 间贴互动技巧

间贴是刺猬猫核心特色，有专门的吐槽榜。

提升间贴活跃度：
1. 在章节中刻意设置吐槽点/容易被吐槽的情节
2. 在情节里抛出问题让读者讨论
3. 设置老二次元才懂的梗
4. 认真回复间贴，培养死忠读者
5. 记住活跃读者ID，偶尔在文中提一下

### 1.9 投稿与编辑组

**投稿材料**：完整大纲 + 3万字正文 + 作者简介 + 联系方式(手机+QQ) + 稿酬期待

**编辑组**：
- 1组（橙子）：支持原创，偏创新
- 2组（南兮）：综合组，同人均可（推荐综漫投这里）
- 3组（桂圆）：起步低，只给D/C签
- 4组（蒜蓉）：竞争激烈

## 二、番茄平台要点（综漫类）

- 番茄以爽文流为主，节奏更快，章末钩子更刚需
- 番茄读者对设定深度要求低于刺猬猫，但爽点密度要求更高
- 番茄AI审核收紧（2026年8月），需注意去AI味和隐形水印
- 番茄日更4000字是基础线，3万字拿首轮推荐

---

## 三、起点平台要点（综漫类）

- 起点适合走硬核设定流，读者对世界观完整性要求更高
- 起点综漫赛道不如刺猬猫和番茄活跃，但单价更高
- 起点读者更在意逻辑自洽和设定严谨性
- 起点适合长线经营，百万字级别的作品更吃香

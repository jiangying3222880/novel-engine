# 都市校园小说资料库

本技能是都市/校园类网文创作的素材与策略参考库（纯知识型，不调用外部API）。

## 执行流程

**步骤1：** 根据用户需求，从上表选择需要读取的文件（可多选）。

**步骤2：** 读取选中的文件，提取其中与当前任务相关的内容。

**步骤3：** 基于提取的素材，结合下方的「关键创作原则」，完成用户请求的任务（如设计冲突情节、写书名简介、规划章节节奏等）。

## 关键创作原则

1. **社会热点升维**：真实事件不能照搬，要"升维"——从具体事件抽象出底层冲突结构，换上虚构的人物和场景。
2. **安全策略**：番茄对性别议题零容忍（2026年4月举报风暴+7月专项治理），必须把冲突升维为"个人vs体制""真相vs谎言"，不能直接写性别对立。
3. **情绪锚点**：读者不是来学法律的，是来感受"被逼到墙角后冷静反击"的爽感。法律知识是工具，情绪共鸣才是核心。
4. **反派灰度**：每个反派都有自己的逻辑和困境，避免沦为性别靶子。
5. **番茄节奏**：下沉市场用户，单次阅读<15分钟，65%碎片化阅读。每章必须独立成爽，不能"这章铺垫下章爆发"。

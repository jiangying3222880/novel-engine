# 短篇细纲模板（憋压三段式 · v1.9）

> **定位**：短篇细纲 = S1 编剧标准产物（单情绪弧版），S2 讲述者唯一输入包。写完先过细纲门（结构硬检+删节推理软检），再动笔。
> **性质**：叙述形态，禁止流程图。单链到底（一条冲突线贯穿三段），无支线。

- 核心情绪（选1）：憋屈 / 愤怒 / 绝望 / 窝囊

## 7. 三段任务字数

- **段一（高压注水开场 300-500 字）**：第一句＿（直接进憋屈，禁止铺垫）｜ 读者看完会问＿
- **段二（憋压蓄力，写前预检）**：动笔前由 target 反推段二节数——`段二需覆盖字数 = target − 段一上限500 − 段三区间1000-2000 取中1500`；`节数 = ceil(需覆盖 ÷ 2200)`；默认 15000 → 6 节（单节 2000-2500 容量，总 12000-15000）
- **段三（大坝决堤爆发 1000-2000 字）**：爆发方式＿（身份揭露/行为反击/真相公开/情绪宣泄）｜ 爆发第一句＿ ｜ 断章点＿（停在情绪最高潮）

- 收：＿（回收方式，重新解释开头）

## 9. 自检清单（细纲门 + 写后检查）

**细纲门（S1 产出后，动笔前）**：
- [ ] 冲突链四节点有内容（想要/阻拦/弄砸/代价）
- [ ] 憋压层次 ≥3 层且逐层加深
- [ ] 声线要求标注来源
- [ ] 任务字数已按预检分配
- [ ] 删节推理：删掉任一层憋压，爆发还有力吗？（有=注水，需加层）

**写后检查（S3 检验）**：
- [ ] 段二每节字数 ≥2000（门禁记录：节1＿/节2＿/…；段一/段三豁免但落区间）
- [ ] 总字数达标（target±15%）
- [ ] 第一句直接进憋屈，无铺垫
- [ ] 中段全程憋压，无微爽无小释放
- [ ] 结尾一次性爆发，不总结不断在感慨里
- [ ] 声线不漂（遮名测试）
- [ ] 事实锚点不串

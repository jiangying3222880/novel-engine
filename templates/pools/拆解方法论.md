# 对标书拆解方法论（Agent 执行手册）

> **本文件是给 Agent 看的拆书操作指南。** 用户不需要读这个，用户只需要提供对标书。
>
> 拆解核心原则：**带着分析框架去读，不是漫无目的地摘抄。** Agent 的任务是"筛选 + 分析 + 归类"，不是"复制 + 粘贴"。

---

## 拆解总流程（两阶段）

### 阶段一：快速预览（前3章 + 整体结构）

用户指定对标书后，**先只拆前3章**，产出快速预览报告让用户确认方向。不要一上来就拆完整本书。

**快速预览必须产出：**
1. 基本信息（书名/题材/预估总章数/总字数）
2. 黄金三章5维评分（开篇钩子/主角塑造/爽点设计/世界观铺设/章尾悬念）
3. 文风摘要（一句话概括文风质感）
4. 3-5个精选段落（标注好在哪里）
5. 适配度评估（和当前项目的题材/风格匹配度，1-10分）
6. 建议：是否值得全量拆解

用户确认后进入阶段二。如果用户觉得不对味，可以直接换书。

### 阶段二：深度拆解（按档位）

| 档位 | 拆解内容 | 对应池子 |
|------|----------|---------|
| 轻量 | Planner（卷结构/节奏）+ Author DNA（文风） | planner/ + author_dna/ |
| 标准 | 以上 + Reference（精选段落） | + reference/samples/ + reference/techniques/ |
| 全量 | 五项全拆 + Unit（事件单元） | + unit/ + knowledge/ |

**拆解顺序：** 先 Planner 和 Author DNA（这两个对风格校准最关键），再 Reference，最后 Unit 和 Knowledge。

---

## 各池子拆解细则

### 1. Author DNA（文风拆解）

**拆解目标**：提炼作者"怎么写"的手法规则（10 类，生成主驱动）+ 统计锚点（验证漂移用）。**手法规则是核心**——文风的本质是作者处理叙事/解释/情绪/细节的方式，不是统计参数。

**拆解方法**（两步：手法提炼为主，统计为辅）：
1. **手法规则提炼（主）**：通读前3章 + 抽样第10/20/50章，按 `author_dna/_template.md` 的“手法规则 10 类”逐类回答——提炼作者反复出现的处理方式（让步转折/原因后置/钩子预告/具体锚点/心理外化/口语时代语混入/短段/收束方式/对话夹叙/助词习惯）。**只提炼规律，禁止摘抄原文句子**（与拆解伦理一致）。
2. **统计锚点（辅）**：句长分布、标点习惯、段落节奏、词汇偏好——**降级为验证锚点**（写作后检测文风是否漂移用），不再作为生成依据。

**输出格式**（填入 `author_dna/{书名}_dna.md`）：

```markdown
## 基本信息
- 书名：xxx
- 作者：xxx
- 题材：xxx
- 拆解章节：前3章 + 抽样第X/Y/Z章

## 文风整体定位
- 一句话文风：[用一句话概括，如"冷峻克制的硬科幻叙事"]
- 冰山程度：[1-10分，越高=越含蓄]
- 非AI味程度：[1-10分，依据：三大模式命中频率]
- 叙事距离：[极近/近/中/远]
- 叙事腔调：[冷峻客观/幽默吐槽/热血燃向/文艺细腻/市井通俗/...]

## 手法规则（10 类 · 生成主驱动）

按 `author_dna/_template.md` 手法规则节逐类提炼（只提炼规律，禁止抄句子）：

### 1. 让步转折句式
- 频率/位置：＿
- 规则：＿
### 2. 原因后置解释
- 使用/触发：＿
- 规则：＿
### 3. 钩子预告
- 频率/位置：＿
- 规则：＿
### 4. 具体物件/数字锚点
- 物件类型/数字习惯：＿
- 规则：＿
### 5. 心理外化
- 方式：＿
- 规则：＿
### 6. 口语/时代语混入
- 混入类型/密度：＿
- 规则：＿
### 7. 短段推进
- 段落长/信息点：＿
- 规则：＿
### 8. 收束方式
- 章末/段末：＿
- 规则：＿
### 9. 对话夹叙/潜台词
- 夹叙方式/潜台词：＿
- 规则：＿
### 10. 助词与句尾习惯
- 助词/密度：＿
- 规则：＿

## 句式特征
- 句长分布：短句X% / 中句Y% / 长句Z% / 平均N字
- 句式偏好：[长短句交替/长句为主/短句为主/排比/倒装/...]
- 标志性句式：[2-3种作者常用的句式模式，附原文短句示例]

## 节奏与标点
- 段落节奏：[平均段长X字/单段单动作/多动作堆叠/断行习惯]
- 标点习惯：[破折号/省略号/感叹号/分号的高频用法，附2-3个短示例]

## 对话特征
- 潜台词模式：[2-3种典型手法，如答非所问/语气反差/信息隐瞒，每种附1段示例]

每段300-500字，按基调分类，标注示范点。
**用途限定**：只用于写作后检测文风漂移、风格校准；**不作为生成输入**——生成依据是上方"手法规则 10 类"。
```

### 2. Planner（结构拆解）

**拆解目标**：提取全书/卷的结构设计、节奏规律、伏笔编排方式。

**拆解方法**：
- 读目录 + 卷名，识别分卷结构
- 读前3章 + 抽样第10/20/50章 + 每卷结尾章，识别节奏模式
- 统计爽点/悬念密度
- 识别世界观释放节奏
- 提取开篇节奏（前3章怎么安排的）

**输出格式**（填入 `planner/{书名}_结构.md`）：

```markdown
## 基本信息
- 书名：xxx
- 总卷数：x卷
- 预估总章数：xxx章
- 拆解方式：前3章深度 + 抽样第X/Y/Z章 + 目录分析

## 整体结构
- 分卷方式：[按地图/按境界/按事件/...]
- 每卷篇幅：[约X章 / 约X万字]
- 每卷核心目标：[一句话概括每卷的核心冲突或目标]
- 叙事框架：[升级流/复仇线/日常单元/多线交织/蜕变成长/混合]

## 节奏量化统计

### 爽点/悬念密度
- 小爽点频率：每X章一次
- 中高潮频率：每X章一次
- 大高潮位置：第X卷/第X章
- 爽点类型分布：[打脸/揭秘/升级/反转/情感爆发/...]

### 信息释放节奏
| 节奏类型 | 频率 | 说明 |
|---------|------|------|
| 小推进（新信息） | 每X字一次 | 章节内的微型进展 |
| 小悬念（钩子） | 每X字一个 | 让读者想继续看的小疑问 |
| 情绪爆发点 | 每X章一次 | 较大的爽点/泪点/燃点 |
| 大反转 | 每X章一次 | 改变局势的重大转折 |

### 章节内部节奏模式
典型章节的节奏结构（统计3-5章后归纳）：
```
[开场承接上章钩子]（约10%字数）
→ [日常/过渡/信息铺垫]（约30%字数）
→ [新事件触发]（约20%字数）
→ [发展/升级]（约30%字数）
→ [章末钩子/悬念]（约10%字数）
```

### 开篇节奏（前3章重点）
- 第1章：[钩子在哪？世界观怎么放？信息量多大？]
- 第2章：[怎么延续第一章的悬念？引入什么新信息？]
- 第3章：[第一个小高潮？还是继续铺垫？节奏怎么安排？]

## 世界观释放节奏
- 第1章释放了什么：[列2-3项]
- 前3章释放了什么：[列5-8项]
- 释放方式：[对话揭示/事件触发/旁白说明/角色探索/...]
- 隐藏策略：[哪些信息压到了很后面才放？为什么？]

## 爽点循环模式
本书典型的爽点循环结构：
- 铺垫层（蓄势）：[怎么压抑/制造缺口？]
- 释放层（爽感）：[怎么释放？打脸/升级/揭秘/...]
- 反应层：[谁来反应？几层反应？反应篇幅比约X:1]
- 衔接层（承转）：[旧循环结束后怎么立新钩子？]

循环单元：
- 小循环（约X章）：[描述一个小循环的结构]
- 中循环（约X章）：[描述一个中循环的结构]
- 大循环（约X章）：[描述一个大循环/卷的结构]

## 伏笔编排
- 伏笔密度：每X章埋一个跨章伏笔
- 平均回收周期：X章
- 伏笔类型：[物件伏笔/对话伏笔/人物伏笔/...]
- 经典伏笔案例：[1-2个，说明怎么埋、怎么收]

## 可借鉴结构技巧
1. [技巧名+说明+对应章节]
2. ...
3. ...
```

### 3. Reference（精选段落）

**拆解目标**：筛选高质量段落入池，供写作同类场景时参考。

**入池判断标准（5条，≥4条才入池）**：

| # | 判断项 | 入池条件 |
|---|--------|----------|
| 1 | 乒乓球对话 | 非乒乓球式（对话与动作穿插，非纯粹一问一答） |
| 2 | 段末升华 | 段末落物（动作/声响/画面），非感慨总结 |
| 3 | 解释腔 | 不解释原因，只呈现结果 |
| 4 | 感官细节 | 包含至少2种感官细节（视觉+听觉/触觉/嗅觉） |
| 5 | 信息留白 | 不主动替读者剖析，留解读空间 |

**筛选方法**：
- 快速预览阶段：从前3章精选3-5个片段
- 深度拆解阶段：从抽样章节（第10/20/50章）各选2-3个片段
- 每段 200-500 字
- 按场景类型分类（情感/打斗/悬疑/日常/揭秘/...）

**输出格式**（填入 `reference/samples/` 对应分类目录）：

```markdown
## 基本信息
- 来源书名：xxx
- 来源章节：第X章
- 场景类型：[情感拉扯/打斗对峙/悬疑揭秘/日常过渡/爽点打脸/...]
- 情绪标记：[-9~+9]，节奏类型：[快/慢/爆发点]

## 原文片段
[200-500字原文]

## 为什么好（可借鉴点）
1. [对应四大转换原则之一，说明具体怎么体现的]
2. [第二个可借鉴点]
3. [第三个可借鉴点（可选）]

## 对应转换原则
- [ ] 原则一：直接心理 → 可观察行为
- [ ] 原则二：解释原因 → 只给结果
- [ ] 原则三：对话对称 → 打破对话均衡
- [ ] 原则四：段末总结 → 段末落物

## 迁移提醒
[这个片段的写法怎么用到自己的书里，需要替换哪些元素]
```

### 4. Unit（事件单元）

**拆解目标**：把书中的关键事件拆成原子单元，写同类事件时可以对标参考。

**入池标准**：事件必须有完整的"起因→决策→结果→情绪变化"闭环，四者齐全才入池。

**拆解方法**：
- 从前20章中挑选关键事件（不是所有事件都拆，只拆写得好的）
- 每个事件标注：情绪烈度、节奏类型、核心技巧
- 事件规模：从小事件（一章内）到大事件（跨3-5章）
- 每本书拆 10-20 个事件单元就够了，不是越多越好

**输出格式**（填入 `unit/_source_书名/`）：

```markdown
## 事件名称
[≤15字的短标签，如"衙门验尸反转""退婚打脸"]

## 场景类型
[悬疑/对峙/日常/打斗/情感戏/揭秘/爽点打脸/...]

## 情绪标记
- 情绪烈度：[-9 ~ +9]
- 节奏类型：[快节奏/慢节奏/爆发点]
- 主要情绪：[压抑/恐惧/悲伤/愤怒/爽/燃/感动/温馨/幽默/...]

## 原始片段
[事件的核心原文片段，300-800字]

## 事件拆解

### 起因
[一句话：事件是怎么触发的]

### 发展（关键步骤）
1. [步骤1]
2. [步骤2]
3. [步骤3]
...

### 决策点
[主角或关键角色在这个事件中做了什么关键选择/决策]

### 结果
[事件的最终结果]

### 情绪变化曲线
[情绪从什么状态 → 经过什么变化 → 到达什么状态。如：压抑→期待→爆发→余波]

## 核心写法技巧
1. [这个事件写得好的关键技巧1，如"用配角反应层放大爽感"]
2. [技巧2]
3. [技巧3（可选）]

## 可复用框架
[去掉具体人物/背景后，这个事件的抽象结构是什么。如："被轻视者在公开场合用结果反证，通过多层反应放大爽感"]

## 迁移提醒
- 可替换项：[角色身份/场景/道具/对手类型]
- 保留项：[情绪逻辑/反应层结构/信息差机制]
- 不可照搬：[原文专名/具体事件顺序/标志性台词]
```

### 5. Knowledge（知识储备）

**拆解目标**：提取对标书中用到的可查证事实知识，写同类场景时可以调用。

**入池标准**：信息可溯源、可在小说中复用。

**拆解方法**：
- 从涉及专业领域的章节中提取
- 按领域分类（历史/医学/军事/法律/科技/...）
- 不需要面面俱到，只提取作者用得好的、能制造真实感的知识点
- 每个知识点标注：来源章节 + 应用场景

**输出格式**（填入 `knowledge/` 对应领域文件）：

```markdown
## 知识点名称
- 领域：[历史/医学/军事/法律/科技/生活常识/...]
- 来源：第X章
- 内容：[知识点的具体内容]
- 书中应用场景：[作者在什么情节里用到了这个知识点]
- 可复用场景：[写什么类型的情节时可以调用这个知识点]
```

## 拆解质量自检

每个池子拆解完成后，Agent 必须自检：

- [ ] **不是全文摘抄**：入池内容经过筛选和分析，不是把原文复制粘贴过来
- [ ] **有判断标准**：每个入池内容都有明确的入池理由（对应哪条标准）
- [ ] **有可借鉴点**：不是只放原文，还说明了"好在哪里、怎么借鉴"
- [ ] **有迁移提醒**：明确说了"什么可以替换、什么不能照搬"
- [ ] **事实准确**：设定/人物/知识点等硬事实都来自原文，没有编造填空
- [ ] **格式统一**：按对应模板的格式输出，方便后续检索和调用

> **核心标准：自己写的时候，这个池子内容真的能用上吗？** 如果不能，说明拆得不对——要么太粗（只有概括没有细节），要么太细（碎片化到没法复用），要么就是凑数的内容。

---

## 拆解伦理

1. **转化性使用**：拆解是文学批评性质的分析，目的是学习写作手法，不是复制原文
2. **原文片段比例控制**：入池的原文片段不超过原书的 1%，且为精选片段
3. **学手法不学内容**：所有入池内容都必须附带"可借鉴点"和"迁移提醒"，明确区分手法和内容
4. **不传播原文**：拆解产物是项目内部素材，不对外传播

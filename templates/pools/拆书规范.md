# 拆书规范（拆什么 / 什么入池 / 格式如何）

> **一句话**：拆书 = 带分析框架读对标书，拆成 5 个可复用池子。Agent 负责拆，用户只需给对标书。

---

## 一、拆哪些内容？（5 池 × 每本产出）

| 池子 | 拆什么 | 每本对标书的落盘文件 | 拆几样 |
|------|--------|---------------------|--------|
| `author_dna/` | 手法规则（10类·生成主驱动）+ 统计锚点（验证漂移） | `author_dna/{书名}_dna.md` | 1 份/本 |
| `planner/` | 卷结构/爽点密度/伏笔编排/节奏 | `planner/{书名}_结构.md` | 1 份/本 |
| `reference/` | 高质量段落（200-500字）+ 写作技巧 | `reference/samples/{分类}/` · `reference/techniques/` | 8-15 段 + 2-5 技巧 |
| `unit/` | 关键事件（前20章挑写得好的） | `unit/_source_{书名}/` | 10-20 个事件 |
| `knowledge/` | 可溯源领域知识 | `knowledge/{领域}.md` | 按需 |

**两阶段**：① 快速预览（前3章+整体结构 → 预览报告 → 用户确认）→ ② 深度拆解（按档位）。
**档位**：轻量=Planner+DNA · 标准=以上+Reference · 全量=五项全拆。

---

## 二、什么入池？（判定标准，不达标不入池）

| 池子 | 入池判定 | 一句话标准 |
|------|---------|-----------|
| author_dna | 存在可复现的手法模式（10类） | 有显著手法才拆（统计仅作锚点） |
| planner | 存在清晰的卷结构/转折点/伏笔布局/节奏规律 | 有明确结构才拆 |
| reference | 过「非AI味 5 条」≥4 条 | 见下方 5 条 |
| unit | 有「起因→决策→结果→情绪变化」四闭环 | 四者齐全才拆 |
| knowledge | 信息可溯源、可复用 | 不编造、能落地 |

**Reference 入池 5 条（逆向应用 anti-ai）**：

| # | 判断项 | 通过条件 |
|---|--------|---------|
| 1 | 乒乓球对话 | 非一问一答（对话与动作穿插） |
| 2 | 段末升华 | 段末落物（动作/声响/画面），非感慨总结 |
| 3 | 解释腔 | 不解释原因，只呈现结果 |
| 4 | 感官细节 | ≥2 种感官（视觉+听觉/触觉/嗅觉） |
| 5 | 信息留白 | 不替读者剖析，留解读空间 |

> 满足 ≥4 条 → 入池；≤2 条 → 不入池。Unit 额外标注：情绪标记（-9~+9）+ 节奏类型（快/慢/爆发点）。

## 拆解质量自检（每池拆完必查）

- [ ] 不是全文摘抄（经过筛选分析）
- [ ] 有判断标准（对应哪条入池标准）
- [ ] 有可借鉴点（好在哪里、怎么借鉴）
- [ ] 有迁移提醒（什么可替换、什么不能照搬）
- [ ] 事实准确（设定/人物/知识点来自原文，无编造）
- [ ] 格式统一（按模板输出）

> 自问：**自己写的时候，这个池子内容真的能用上吗？** 不能用 = 拆得不对。

---

## 拆解伦理

1. 转化性使用：拆解是学习写作手法，不是复制原文
2. 原文片段 ≤ 原书 1%，且为精选
3. 学手法不学内容：每个入池内容附带"可借鉴点"+"迁移提醒"
4. 拆解产物是项目内部素材，不对外传播


---

## 池子状态标记（C 回填 · 防空池静默跳过）

项目初始化时在 `素材池/` 落一个 `_status.md`，显式标记拆解状态，供阶段①判定：

| 字段 | 取值 |
|------|------|
| 拆解状态 | 未拆解 / 已拆 N 本 |
| 深度档位 | 快速 / 标准 / 深度 |
| 上次更新 | （日期） |

**阶段①规则**：读到 `拆解状态: 未拆解` 时，素材调阅**不允许静默跳过**——必须输出一行"建议跑对标书快速预览拆解（约 N token）"；已拆解但空池同理（防空池标记缺失导致的"把无池当正常跳过"）。

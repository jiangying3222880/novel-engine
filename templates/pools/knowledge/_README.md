# 知识池（Knowledge Pool）

存放**事实型知识**（什么是真的），从对标书拆解或自行整理。

## 组织方式

**按领域分文件**，每个文件内标注知识来源（哪本书/哪来的）：

```
knowledge/
├── 历史_宋代官制.md         ← 从《XX书》拆解 + 自行补充
├── 医学_常见外伤.md         ← 从《XX书》拆解
├── 神秘学_塔罗牌.md         ← 从《诡秘之主》拆解
└── ...
```

每个知识文件建议包含：
- **来源**：从哪本书/哪里来的
- **核心规则**：不能错的硬知识
- **常见误区**：很多小说写错的点
- **小说化细节**：可以直接融入描写的细节

## 与 Reference 的区别

- **Knowledge**：事实正确性（这个朝代的官制是什么样的）
- **Reference**：文学质感（这个场景怎么写才好看）

## 使用原则

- 仅当本章涉及特定领域时加载，不常驻上下文
- 优先用拆解过的知识（经过对标书验证，读者接受度高）
- 新领域知识先查再写，写完补入池中

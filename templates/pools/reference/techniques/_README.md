# techniques/ — 写作技巧方法论

**这里存的是"怎么写"的方法论和技巧分类**，是抽象层面的写作知识。

> 与 `samples/` 的区别：techniques 是"原理"，samples 是"别人怎么落地的"。先看原理知道方向，再看样本看具体执行。

---

## 8 大核心技巧分类

### 1. 情绪高潮与爽点
核心逻辑：压抑→隐忍→反击→反转，爽感来自落差的瞬间释放。

| 技巧 | 说明 |
|------|------|
| 三步递进 | 羞辱→隐忍→爆发，不跳步 |
| 延迟满足 | 读者越想要什么，越不立刻给 |
| 希望毁灭循环 | 给一点甜头→立刻打回去→更狠 |
| 沉默爆发 | 最强的反击是最短的 |
| 地位倒错 | 捕食者变猎物 |

### 2. 人物关系与感情戏
核心逻辑：嘴硬心软，身体背叛语言，利益纠葛制造羁绊。

| 技巧 | 说明 |
|------|------|
| 空间压缩 | 把两人关在小空间里 |
| 行动背叛 | 嘴上说不在乎，手先动了 |
| 说反话暗示 | 用反话传递真实情感 |
| 敌意螺旋 | 从敌对到和解的弧线 |
| 四类差异化 | 冰山型/烈火型/大地型/骄傲型 |

### 3. 节奏控制与悬念拉满
核心逻辑：信息差是悬念的燃料，延迟揭示是悬念的拉力。

| 技巧 | 说明 |
|------|------|
| 倒计时 | 给场景一个硬性时间压力 |
| 波浪节奏 | 紧张-松一口气-更紧张 |
| 冰山式悬念 | 只露 10%，藏 90% |
| 悖论炸弹 | 用矛盾信息逼读者追问 |
| 洋葱揭示 | 层层剥开，每层都推翻上层 |
| 断崖章末 | 章末抛出最大悬念 |

### 4. 日常推进
核心逻辑：日常不是废话，是侧面展现世界和角色的窗口。

| 技巧 | 说明 |
|------|------|
| 小摩擦展世界 | 通过日常冲突展示设定 |
| 短句为王 | 日常段落用极简短句 |
| 动作伴随对话 | 边做事边说话，不干聊 |
| 内心独白驱动 | 用角色的碎碎念推进 |

### 5. 世界观构建
核心逻辑：侧面描摹，拒绝说明文，设定通过角色体验传达。

| 技巧 | 说明 |
|------|------|
| 蚁穴视角 | 从小人物的日常展现大世界 |
| 感官锚定 | 用具体感官细节锚定世界观 |
| 双向信息差 | 角色和读者对世界认知不同步 |
| 技术细节 | 用伪科学细节增加真实感 |

### 6. 反转揭秘
核心逻辑：意料之外，情理之中。70% 铺垫 + 30% 揭示。

| 技巧 | 说明 |
|------|------|
| 认知颠覆 | 推翻读者已建立的认知 |
| 70-30 法则 | 70% 线索提前铺设，30% 揭示时串联 |
| 伪反转 | 先给一个假答案，再翻真答案 |
| 铺垫回收 | 揭示时必须让读者回想起前文 |

### 7. 黄金开头
核心逻辑：第一句话建立冲突，快速引入核心动机。

| 开局类型 | 说明 |
|---------|------|
| 倒叙穿越 | 从未来视角切入 |
| 日常异常 | 日常中突然出现不对劲 |
| 身份落差 | 开局就是身份巨变 |
| 危机开局 | 直接在危机中 |
| 弱者开局 | 从最弱者视角开始 |

### 8. 反派塑造
核心逻辑：反派有自己的逻辑，不是为主角服务的工具人。

| 技巧 | 说明 |
|------|------|
| 独立动机 | 反派有自己的目标，不是为了衬托主角 |
| 镜像对照 | 反派是主角的另一种可能 |
| 合理手段 | 反派的手段符合其资源和身份 |
| 不可代替性 | 删掉这个反派，故事塌掉 |

## 调阅指南

| 场景类型 | 调阅分类 |
|----------|----------|
| 打脸/逆袭/爆发场景 | 分类 1：情绪高潮与爽点 |
| 对手戏/感情线/试探 | 分类 2：人物关系与感情戏 |
| 战斗/悬疑/章末钩子 | 分类 3：节奏控制与悬念 |
| 过渡章/日常章 | 分类 4：日常推进 |
| 新场景/新设定出场 | 分类 5：世界观构建 |
| 真相揭示/大反转 | 分类 6：反转揭秘 |
| 第1章/新书开头 | 分类 7：黄金开头 |
| 反派登场/反派对决 | 分类 8：反派塑造 |

> 看完方法论后，去 `samples/` 下找对应类型的实战段落看具体落地。

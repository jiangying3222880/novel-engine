# samples/ — 实战样本库

**这里存的是从对标书拆解的精选段落**，按场景类型分类，是"别人写得好的具体例子"。

> 与 `techniques/` 的区别：techniques 是"原理"，samples 是"实战落地"。先看原理知道方向，再看样本看具体怎么写。

---

## 目录结构

```
samples/
├── coolness/            ← 爽感/打脸（对标：《大奉打更人》）
│   └── 大奉打更人_爽感打脸.md
├── suspense/            ← 悬念/伏笔（对标：《诡秘之主》）
│   └── 诡秘之主_悬念伏笔.md
├── action/              ← 动作/打斗（对标：《风云》）
│   └── 风云_动作打斗.md
├── humor/               ← 搞笑/幽默（对标：《史上第一混乱》）
│   └── 史上第一混乱_搞笑幽默.md
├── horror/              ← 恐怖氛围（对标：《神秘复苏》）
│   └── 神秘复苏_恐怖氛围.md
├── worldbuilding/       ← 世界观植入（对标：《飘渺之旅》）
│   └── 飘渺之旅_世界观植入.md
└── xianxia/             ← 修仙升级感（对标：《凡人修仙传》）
    └── 凡人修仙传_修仙升级感.md
```

**使用方法**：写某个类型的场景时，先翻对应目录的样本，看高手是怎么处理的，再自己写。**学动作不学词汇。**

## 每个样本文件的格式

```markdown
# [样本名称]

## 来源
《书名》第 X 章

## 场景类型
[对应 techniques 的分类]

## 原文段落
> （完整粘贴原文，保持不动）

## 技巧分析
- 用了什么技巧：（如：沉默爆发 + 地位倒错）
- 为什么有效：（1-2句分析）

## 可借鉴点
[自己写同类场景时，可以直接用的写法/节奏/结构]
```

## 入池原则

1. **只存高质量段落**：别什么都往里塞，宁可少而精
2. **标注来源**：知道是从哪来的，方便回溯上下文
3. **附分析**：不只是存原文，要写清楚"好在哪里"
4. **人工定稿的原创段落也可以入池**：标清楚来源是"本书原创"

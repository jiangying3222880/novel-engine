# 文学素材池（Reference Pool）

存放**写得好的段落**（怎么写好看），从对标书拆解。

## 组织方式

**按场景类型分目录**，每个文件标注来源（哪本书的哪段）：

```
reference/
├── scenes/                     ← 场景写法
│   ├── 悬疑开场.md              ← 多本书的悬疑开场段落合集
│   ├── 雨夜对峙.md
│   └── 章节收尾_钩子.md
├── emotions/                   ← 情绪/意象
│   ├── 恐惧的十种写法.md
│   ├── 愤怒.md
│   └── 孤独感.md
└── dialogue/                   ← 对话范式
    ├── 暗流涌动.md
    ├── 谈判交锋.md
    └── 日常闲聊.md
```

每个素材文件建议包含：
- **来源**：书名 + 章节
- **原文段落**：完整粘贴
- **可借鉴点**：这段好在哪里，为什么有效
- **适用场景**：写什么的时候可以参考这段

## 与 Knowledge 的区别

- **Reference**：文学质感（怎么写好看）
- **Knowledge**：事实正确性（什么是真的）

## 使用原则

- Writer 阶段根据本章场景类型匹配加载 1-2 个参考
- 学质感不学内容：参考节奏、句式、意象选择，不照搬情节
- 每写完一章，把自己写得好的段落也可以反存入池（标"原创"）

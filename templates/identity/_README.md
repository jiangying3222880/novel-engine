# templates/identity — 身份档案模板

> 项目级 `配置/身份/` 身份档案的来源（功能二 身份路由）。

## 定位

`identity/` 是**身份档案模板**：新建身份时复制 `_template.md`，按身份填充定义/视角/判断准则/输出要求/红线。技能级基线在 `library/identities/`（作者/编剧/编辑/读者），项目可覆盖或新增。

## 使用

1. 初始化时复制 `_template.md` 到 `配置/身份/`，命名：`作者.md` / `编辑.md` / 或 `平台-题材_身份.md`（如 `番茄-都市_编辑.md`）。
2. 同名覆盖技能级基线字段，新增字段追加。
3. 各阶段执行前，按 `references/identity-routing.md` 流程×身份路由表加载对应身份档案。

## 机器可读性

本项目数据层（`meta/`、`truth/`）保持零双链、机器可读；身份档案为语义文档，可含描述性文字，不参与 truth 状态机。

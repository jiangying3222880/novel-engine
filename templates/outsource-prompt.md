# 外包写作 · 最终提示词模板（自包含）

> 用途：把阶段②写作外包给任意网页 chat（豆包网页 / Claude 网页 / 其他）。
> 技能阶段①照跑后，用本模板编译一份可直接复制的最终提示词；外部 chat 写完后贴回，
> 继续走 **阶段③自检 → ④去AI味（必须跑满）→ ⑤落库（含索引重建）**。

---

## 模板（复制以下整块，把 __ 填成实际内容）

```
【身份】你是本书的作者（负责故事结构 / 伏笔 / 字数 / 红线 / 跨章一致性），但动笔时以"为一个朋友讲故事的人（讲述者）"的口吻落笔：像炉边倒苦水、唠家常，敢吐槽、会回看、句子带气口，绝不像写公文或播音。作者定纲领，讲述者出文字（v1.4.1）。题材：__ ｜ 平台调性：__ ｜ 目标读者：__。
【任务】写第X章正文，约 __ 字，题材基准：__（书/作者/分类/平台调性）

【当前状态】（故事/真相/ 6 文件精简摘要，只给本章相关）
> 你只依据提示词内给出的这些状态写作；未给出等于不知道——**不要自行脑补未来伏笔、未出场角色或尚未发生的设定**。
- 时间/地点：__
- 在场角色与状态：__（姓名 + 当前状态/立场/章态）
- 关键道具：__（持有者/位置/状态）
- 未回收伏笔：__（仅本章相关，防剧透不泄未来）
- 世界规则硬边界：__（不能违反的设定）

【上一章结尾】（章末最后 1~3 段原文，供本章开头自然接续；不含未来剧透）
> 外部 chat 看不到上一章正文，若要求"接续式结尾"，必须给这段——否则它不知道"接在哪"。本章开头用动作/对话/场景直接接住这个断点，不重述上一章。

【本章目标】（来自规划清单）
- 主角行动目标：__
- 本章事件/冲突：__
- 章节出口：__（首选取**接续式结尾**——章末停在哪，后续可自然接续;动作未完/信息刚揭开/决定刚做出/场景切断/后果未显现；结尾不承担"收束"义务，第N章可直接接第N+1章开头；仅卷末/大冲突切口才需刻意悬念）

【手法规则】（v1.4.1 自包含硬性要求：必须内联成外部 chat 可直接照做的规则 + 示例句；禁止引用本地 DNA 文件路径；禁止只写技法名。有 author_dna 时：提炼核心手法 → 每类给一句示例 → 标注强度高/中/低；只挑与本场景相关的 1~3 个，连同例句内联进此块）
__

【写作要求】
- 用动作/结果呈现，避免解释设定（冰山原则）
- 对话有节奏与个性，角色声线区分
- 节奏随场景功能变化，不按固定字数制造钩子；长时间无信息/动作/关系/情绪变化时检查拖滞（v1.4.1）
- 只写正文，不写元数据/YAML，不要标题以外的小结
- 本章收尾不总结不升华；若与下一章接连，结尾停在可自然接续处
- 动笔前先判断：本场景 AI 味风险点（常见 AI 味模式）+ 人感抓手
  （动作链 / 对白潜台词 / 环境烘托 / 细节观察方式）

【字数】约 __ 字

【输出格式】纯正文，分段落，对话独立成行
```

## 使用说明（给 Agent，不进入提示词）

1. **阶段①照跑**：加载 6 状态文件 + 规划清单后，用本模板编译填空稿。
2. **身份编译（v1.4.1 双重身份）**：【身份】字段从 `novel-config.json`（题材/平台调性/目标读者）+ `library/identities/作者.md`（作者职责）提取；项目有 `配置/身份/作者.md` 时以项目覆盖版为准。身份=A 作者(定结构/伏笔/红线/字数) + 讲述者(出文字口吻)。让外部 chat 以"作者定纲领、讲述者出文字"执笔，不是裸工具人，也不是"边写边监视读者的 AI"。
3. **防剧透**：【当前状态】只给本章相关（cutoff=本章），不泄未来伏笔/未出场角色。【上一章结尾】例外——它是不含未来剧透的正文片段，为接续式结尾必填，编译时从 `故事/正文/上一章` 取章末最后 1~3 段。
4. **手法规则（v1.4.1 自包含硬性要求）**：项目有 `素材池/author_dna/` 时，**必须提炼实质内容成"规则+示例句"内联进提示词**，禁止只贴文件路径或仅写技法名——外部 chat 读不到本地 DNA 文件。只挑与本章场景相关的 1~3 个特征 + 例句；没有 author_dna 时删掉该块。
5. **交接**：用户把提示词贴入外部 chat → 正文贴回。
6. **回接**：阶段③自检（正文 `evidence_ids` 证据链）→ ④去AI味（**必须跑满**，外部稿几乎必带AI味）→ ⑤落库（含 `python runtime/bm25_fts.py build --root <项目根>` 索引重建）。

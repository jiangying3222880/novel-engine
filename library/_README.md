# Library — 用户级素材库（跨项目共享）

## 定位

`library/` 是用户级别的**通用写作资产库**，跨所有小说项目共享。

与项目级 `素材池/` 的区别：

| 维度 | library/（用户级） | 素材池/（项目级） |
|------|-------------------|-----------------|
| 范围 | 跨所有项目共享 | 仅当前项目使用 |
| 内容 | 通用方法论 + 题材参考 + 知识库 | 本书对标书拆解内容 |
| 增长方式 | 写的书越多，积累越丰富 | 随项目创建，随项目归档 |
| 风格污染风险 | 按题材分目录，写什么题材加载什么 | 只存本书对标，零风险 |

**调用原则**：写哪类题材，加载哪类题材包；通用方法论按需加载，不一次性全读。

## 使用方式

### 项目初始化时
1. 根据本书题材，从 `genres/` 中选择 1-2 个题材包作为风格参考
2. 从 `techniques/` 中选择 2-3 个核心方法论作为写作指导
3. 从 `knowledge/` 中预加载本书需要的知识素材
4. 以上内容作为**参考基准**填入项目的 `素材池/`，再结合本书专属对标书拆解内容

### 写作阶段
- 写特定场景时，从 `techniques/` 调取对应方法论
- 不确定节奏/结构时，查 `genres/` 中对应题材的参考
- 需要素材/知识点时，查 `knowledge/`

## 扩展原则

1. **质量优先**：宁少勿滥，只放经过验证的高质量内容
2. **题材隔离**：不同题材严格分目录，不混放，避免风格污染
3. **持续积累**：每写完一本书，把验证过的好方法、好素材反哺回 library/
4. **分层加载**：永远只加载当前需要的内容，不全量加载

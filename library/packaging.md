# 卖点包装与反套路提案（doubao-novel-writing 融合）

> 一句话：**市场调查回答"写什么有人看"，编辑视角回答"写得行不行"，本文件回答"怎么把书卖出去"**——把设定 + 调查结果压缩成一句话卖点，再生成简介/导语/投稿文/发布包装，并给出差异化（反套路）提案。

---

## 一、卖点引擎（设定 + 市场调查 → 一句话卖点）

**核心：一本书只有一个主卖点**（读者 3 秒能复述），其余是支撑点。

提炼流程：

```
1. 从设定里列候选卖点：金手指 / 身份反差 / 题材混搭 / 世界观悬念 / 情绪体验（爽/甜/虐/燃）
2. 用市场调查结果校准：同题材读者已为什么买单（样本核验，不凭印象）
3. 一句话卖点公式：
   「主角身份/处境 + 金手指或核心机制 + 最大冲突或目标 + 情绪承诺」
   例：废柴少年被逐出宗门，觉醒吞噬万物的体质，一路反杀打回上界（玄幻·爽）
4. 自检：读者 3 秒能复述吗？和同类真正不同在哪？能撑起 100 章吗？（故事发动机）
```

**卖点进简介/导语/开篇**（编辑视角裁决）：一句话卖点 + 前 100 字钩子必须**用同一条卖点**贯穿——简介承诺什么，开篇就要兑现什么，自检时核对"卖点未落地"。

## 二、反套路创意提案（差异化引擎）

用于"要更抓人 / 更爆 / 更有新意 / 避免同质化"时，给多个差异化方向，不改用户已定设定：

```
1. 定位同类：同题材主流写法是什么（1-2 个样本）
2. 找突破口（选 1-2 个组合，不堆砌）：
   - 身份反转：读者以为是 X，其实是 Y（反套路）
   - 情绪偏移：同类走爽，我走宿命感/荒诞感/甜中带刀
   - 机制换轨：金手指从"变强"换成"代价/限制/不可控"
   - 视角换位：配角/反派/群像视角切入
   - 节奏重置：慢热变快热，或先抑后扬改成先扬后抑
3. 每个提案给：一句话定位 + 开篇钩子 + 前三章闭环 + 风险（会不会太怪）
```

纪律：反套路是**增量**不是**推翻**——用户已定设定优先，提案只做差异化补充；同时守住平台范式（番茄快节奏/起点深度向），反套路不能反掉平台读者预期。

## 三、包装类产出（简介 / 导语 / 投稿文 / 发布包装）

| 产出 | 用途 | 要点 |
|------|------|------|
| 导语 | 书页/连载开篇短文案 | 一句话卖点 + 情绪钩子，50-100 字，不剧透主线 |
| 简介 | 平台书页主文案 | 人物处境 → 金手指 → 冲突升级 → 悬念收尾；承诺能兑现；不夸大 |
| 投稿文 | 编辑审稿材料 | 题材定位 + 一句话卖点 + 前三章钩子 + 长线连载机制 + 差异化 + 目标读者 |
| 发布包装 | 章节/连载发布 | 平台风格适配（见 `library/platforms/`）；开头即时入戏 |

**简介结构参考**（三拍式）：
```
第一拍：主角的窘境/起点（读者代入）——"他是个被逐出宗门的废物"
第二拍：转机/金手指（承诺爽点）——"却觉醒了吞噬万物的体质"
第三拍：目标/悬念（留钩子）——"三年后，他要让所有人跪着喊他回来"
```

## 四、包装文案反 AI 味（human-signal 联动）

简介/导语/投稿文同样会 AI 味，套用 `references/human-signal-zh.md`：

- **上游防御**：先定读者与平台再写（番茄 vs 晋江的语气不同），不写完再补救。
- **模式库注意**：简介最易命中"抽象大词堆叠"（成长/蜕变/逆袭）与"结尾金句化"（每个人都欠他一个交代）——落到具体动作与代价。
- **保真**：简介承诺的必须正文兑现（卖点未落地 = 一票否决，见 03 自检）。
- **低误报**：平台需要的信息（题材标签/更新承诺）不能为"人味"删掉。

## 五、与身份 / 流程的关系

| 环节 | 身份 | 本文件的使用 |
|------|------|-------------|
| ⓪ 立项 | 作者（主）+ 编辑 | 提炼一句话卖点；市场调查 → 卖点引擎 → 反套路提案 |
| ① 规划 | 编剧 | 前三章钩子对齐卖点（开篇兑现简介承诺） |
| ② 写作 | 作者 + 读者 | 正文落地卖点（爽点兑现） |
| ③ 自检 | 读者 + 编辑 | 卖点未落地检查（一票否决） |
| 投稿/包装 | 作者 | 简介/导语/投稿文/发布包装产出 |

**项目级覆盖**：项目根 `config/identity/作者.md` 可指定 target_reader / 一句话卖点 / 平台，包装产出优先用项目级卖点。

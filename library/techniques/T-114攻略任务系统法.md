# T-114 攻略任务系统法 > L2 Strategy | 长篇技法 > 来源：Research层分析（【快穿】心机美人下蛊日常） > 适用：快穿/攻略/心机美人/系统 > 版本：v1.0（2024年提炼）

## 一、技法概述

**核心定义**：女主被冤枉成魔族余孽，被迫下凡完成任务，在多个世界攻略多个目标，走肾不走心，最终编制进火葬场。

**底层原理**：
- 快穿设定：多个世界/多个任务
- 心机美人：看似猎物实则猎人
- 攻略目标：多个男人成群
- 死遁结局：每个世界大部分死遁
- 火葬场：男人后悔求复合

**适用题材**：快穿/系统/攻略/心机美人/万人迷

## 二、核心结构

### 2.1 开场设定（第1章）
```
女主沄苡被冤枉成魔族余孽
↓被迫下凡
↓元灼仙君给她任务
↓进入第一个世界
```

### 2.2 攻略任务线
```
攻略任务：
- 每个世界有多个目标
- 女主心机攻略
- 游戏人间
- 拍拍屁股走人
```

### 2.3 火葬场线
```
火葬场：
- 男人变成恋爱脑
- 女主死遁
- 男人后悔
- 女主编制火葬场
```

## 三、操作步骤

### Step 1：设计快穿设定
```
快穿设定：
- 被迫下凡
- 多个世界
- 每个世界有任务
- 多个攻略目标
```

### Step 2：设计心机美人
```
心机美人特点：
- 看似猎物实则猎人
- 掌控全局
- 走肾不走心
- 游戏人间
```

### Step 3：设计攻略目标
```
攻略目标：
- 每个世界多个目标
- 成群的恋爱脑
- 雄竞修罗场
- 无固定CP
```

### Step 4：设计死遁结局
```
死遁设计：
- 每个世界死遁
- 男人后悔
- 火葬场排队
- 女主调侃男人
```

## 四、应用公式

```
攻略任务系统法 = 快穿设定（多个世界）
                + 心机美人（掌控全局）
                + 攻略目标（多个恋爱脑）
                + 死遁结局（拍拍屁股走人）
                + 火葬场（编制排队）
```

## 五、典型案例

## 六、与短篇技法的区别

| 维度 | 长篇快穿攻略法 | 短篇快穿法 |
|------|----------------|------------|
| 篇幅 | 66万字 | 3000字 |
| 节奏 | 多个世界渐进 | 单世界快速 |
| 目标 | 多个男人雄竞 | 1-2个目标 |
| 结局 | 死遁+火葬场 | 单一结局 |

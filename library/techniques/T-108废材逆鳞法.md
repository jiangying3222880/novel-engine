# T-108 废材逆鳞法

> L2 Strategy | 长篇技法
> 来源：Research层分析（不死战神）
> 适用：玄幻/废材流/长篇（50万字+）

## 核心定义

"龙有逆鳞，触之必死"——主角有一个绝对不能触碰的软肋（亲人/爱人），为了保护这个软肋，主角从废物崛起。

## 底层原理

"弱点即动力"：
- **软肋激活**：亲人/爱人成为行动核心
- **冲突集中**：所有矛盾围绕软肋展开
- **爽感集中**：主角变强=保护软肋

## 操作步骤

### Step 1：设计主角软肋

| 软肋类型 | 悲情指数 | 爽感来源 |
|----------|----------|----------|
| 重病妹妹 | 高 | "为妹妹治病" |
| 被欺凌的青梅 | 中 | "为她出头" |
| 养育的师父 | 高 | "为师父报仇" |
| 落难的妻子 | 中 | "保护妻子" |

### Step 2：设计废材设定

| 废材原因 | 观众期待 |
|----------|----------|
| 天赋低下 | "等待奇遇" |
| 资源匮乏 | "积累爆发" |
| 被打压 | "隐忍复仇" |
| 无背景 | "独自崛起" |

### Step 3：设计金手指

| 金手指类型 | 与软肋关系 |
|------------|--------------|
| 传承戒指 | 老爷爷是软肋相关人 |
| 神级功法 | 能治好软肋的病 |
| 逆天资质 | 软肋激发潜力 |
| 特殊血脉 | 与软肋羁绊 |

### Step 4：设计敌人类型

| 敌人类型 | 针对软肋方式 |
|----------|--------------|
| 抢夺资源 | 抢治软肋的药 |
| 欺负软肋 | 直接伤害 |
| 家族打压 | 限制软肋 |
| 天才碾压 | 嘲笑软肋 |

## 典型结构

```
第1章：软肋被欺负，主角爆发决心
第2-10章：废材设定+软肋羁绊
第11-30章：金手指觉醒，开始修炼
第30-50章：第一次为软肋出头（小爽）
第50-100章：软肋病情恶化/被更强敌人威胁
第100-150章：主角疯狂变强，碾压敌人
150章+：为软肋逆天改命
```

## 变体分类

| 变体 | 软肋 | 爽感特点 |
|------|------|----------|
| 妹妹寒病流 | 重病妹妹 | 救妹狂魔 |
| 青梅被欺流 | 被欺凌青梅 | 护花使者 |
| 师父养育流 | 落难师父 | 徒报师恩 |
| 妻子遇难流 | 落难妻子 | 英雄救美 |

## 核心爽点

1. **"逆鳞"宣言**："她是我的逆鳞！"
2. **为软肋变强**：修炼=保护
3. **为软肋复仇**：伤害软肋者死
4. **为软肋逆天**：改命/续命

## 避坑指南

1. **软肋要可爱**：不能太作，要让读者心疼
2. **废材要有理由**：观众要理解为什么是废物
3. **金手指要关联**：最好与软肋有关
4. **敌人要够恶**：欺负软肋的敌人要够坏

## 配套技法

- T-017命格设定：软肋可能是命格相关
- T-018最强=最弱：为保护软肋展现最强
- T-007反派强度：敌人要够强才有复仇爽感

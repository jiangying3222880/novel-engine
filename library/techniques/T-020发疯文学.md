# T-020 发疯文学

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（八零年代我靠发疯带婆婆）
> 适用：世情/婆媳/家庭/复仇爽文

## 核心定义

女主不是传统傻白甜，而是泼辣/不好惹/以恶制恶，通过"发疯"式反击制造爽感。

## 底层原理

泼辣人设的反套路性 + 不讲理式反击的戏剧性 = 读者爽感
"泼妇"人设天然具有喜剧效果和宣泄感。

## 操作步骤

### Step 1：设计泼辣人设

| 要素 | 设计要点 |
|------|----------|
| 名字 | 暗示性格（泼皮/泼妇/辣子） |
| 外表 | 不温柔/不好惹/气势足 |
| 背景 | 泼辣是生存技能（世情文） |

### Step 2：制造"欺负"场景

泼辣需要对比：
- 恶人媳妇欺负软柿子婆婆
- 熊孩子欺负邻居
- 绿茶欺负老实人

### Step 3：发疯式反击

泼妇反击三板斧：
1. **哭**：一哭二闹三上吊
2. **闹**：大闹一场，不讲理
3. **赖**：赖上不放，无理搅三分

### Step 4：爽点制造

发疯的结果要"赢"：
- 恶人认怂
- 婆婆感激
- 观众叫好

## 应用公式

```
泼辣人设 + 欺负场景 + 发疯反击 + 胜利结果 = 发疯文学
```

## 变体

| 变体 | 泼辣对象 | 爽点 |
|------|----------|------|
| 泼妇治恶婆婆 | 恶婆婆 | 恶人自有恶人磨 |
| 泼辣邻居治熊孩子 | 熊孩子/熊家长 | 以毒攻毒 |
| 泼皮女主治绿茶 | 绿茶/渣男 | 不装直接撕 |

## 典型案例：八零年代我靠发疯带婆婆

**人设**：
- 名字：李泼泼（谐音"泼皮"）
- 职业：泼辣恶人（帮人闹事）
- 性格：不好惹/讲条件

**反击场景**：
- 胖婶抢苹果 → 直接拍结婚证+大字报威胁
- 恶亲戚欺负婆婆 → 直接推出门+啐一口

## 避坑指南

1. **泼辣要有底线**：不是无理取闹，是反击欺负
2. **要有喜剧感**：发疯要有梗，有趣
3. **结局要正**：最后要赢，不能让读者憋屈

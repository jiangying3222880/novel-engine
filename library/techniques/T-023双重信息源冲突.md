# T-023 双重信息源冲突

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（被拐逃跑看见弹幕后，腹中胎儿心声杀疯了）
> 适用：弹幕流/心声流/系统流/悬疑反转

## 核心定义

两个或多个信息来源产生冲突，制造悬念和紧张感，读者在"该信谁"的纠结中获得阅读快感。

## 底层原理

信息差是悬念的核心。当读者知道"危险来了"而主角不知道时，会产生紧张感和期待感。

## 操作步骤

### Step 1：设计双重信息源

| 信息源A | 信息源B |
|---------|---------|
| 弹幕 | 胎儿心声 |
| 系统提示 | 内心判断 |
| 观众视角 | 角色视角 |
| 外挂 | 自己的判断 |

### Step 2：制造信息冲突

两个信息源给出**相反**的建议：
- A说"往左走"
- B说"往右走"
- 主角必须选择

### Step 3：紧张等待

读者和主角一起紧张：
- 选择A会怎样？
- 选择B会怎样？
- 到底该信谁？

### Step 4：结果揭晓

| 结果 | 效果 |
|------|------|
| A对B错 | 读者庆幸 |
| B对A错 | 读者紧张 |
| 都对/都错 | 反转惊喜 |

## 应用公式

```
信息源A（危险警告） vs 信息源B（安全建议）= 悬念
```

## 变体

| 变体 | 信息源A | 信息源B | 场景 |
|------|---------|---------|------|
| 弹幕心声 | 弹幕 | 胎儿心声 | 逃跑/危险 |
| 系统人格 | 系统 | 内心小人 | 选择困难 |
| 观众vs角色 | 上帝视角 | 角色视角 | 悬疑/推理 |
| 双系统 | 系统A | 系统B | 游戏/无限流 |

## 典型案例：被拐逃跑看见弹幕

**冲突场景**：
- 弹幕说"往左，有埋伏"
- 胎儿心声说"往左，能跑"
- 主角犹豫：到底该信谁？

**紧张感来源**：
- 敌人正在追来
- 时间紧迫
- 选择决定生死

## 写作技巧

### 弹幕格式
```
【弹幕1：xxx】
【弹幕2：xxx】
```

### 心声格式
```
「心声1：xxx」
「心声2：xxx」
```

### 冲突标记
```
【弹幕：往左！】
「心声：往右！」
主角：我该信谁？！
```

## 避坑指南

1. **冲突要明显**：两个信息源要给出明确不同的建议
2. **要有时间压力**：紧迫感是冲突的前提
3. **选择要有代价**：无论选哪个都有风险

# T-113 真假千金反转法 > L2 Strategy | 长篇技法 > 来源：Research层分析（被赶出豪门后，哥哥们都团宠我） > 适用：真假千金/团宠/校园 > 版本：v1.0（2024年提炼）

## 一、技法概述

**核心定义**：女主作为假千金被赶出豪门，新家庭却有七个哥哥团宠她，真千金后悔想把她赶走，结果反而被团宠打脸。

**底层原理**：
- 真假千金身份反转：假千金→真千金
- 团宠属性：七个哥哥都宠她
- 呆瓜人设：软萌可爱反应慢
- 反差爽点：真千金想赶走她反而被打脸

**适用题材**：真假千金/团宠/校园/都市甜宠

## 二、核心结构

### 2.1 开场设定（第1章）
```
女主知道自己不太聪明
↓从小就幻想自己是假千金
↓高二那年真千金出现
↓被岑母赶出豪门
```

### 2.2 新家庭团宠线
```
新家庭：
- 普通小屋子
- 七口之家
- 七个哥哥
↓女主来到新家庭
↓哥哥们都团宠她
```

### 2.3 反击打脸线
```
真千金想赶走她：
↓反而被团宠打脸
↓哥哥们护着她
↓岑家父母后悔
```

## 三、操作步骤

### Step 1：设计真假千金设定
```
真假千金：
- 女主是假千金
- 真千金林涣涣出现
- 岑母被真千金蒙骗
- 女主被赶出豪门
```

### Step 2：设计女主性格
```
女主特点：
- 呆瓜人设
- 反应慢半拍
- 说话考虑半天
- 软萌可爱
```

### Step 3：设计团宠设定
```
七个哥哥：
- 亲哥哥们
- 都团宠女主
- 各种护短
- 打脸真千金
```

### Step 4：设计反转爽点
```
反转设计：
- 真千金以为能赶走女主
- 结果被团宠打脸
- 岑家父母后悔
- 女主反而更幸福
```

## 四、应用公式

```
真假千金反转法 = 真假千金（假千金被赶走）
                + 呆瓜人设（软萌可爱）
                + 团宠设定（七个哥哥）
                + 反转打脸（真千金被打脸）
```

| 维度 | 长篇真假千金法 | 短篇真假千金法 |

| 篇幅 | 21万字 | 3000字 |

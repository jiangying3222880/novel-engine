## 使用原则

1. **按需加载**：不要一次全读。写什么阶段就加载什么方法论。
2. **1-2-3 原则**：每阶段选 1-3 个核心方法论作为指导，不要贪多
3. **配合题材包**：通用方法论打底，题材包做风格校准
4. **实践后反哺**：验证好用的方法，补充到对应文件中

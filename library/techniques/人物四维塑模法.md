# 人物四维塑模法

## 核心思路

好的人物不是"属性清单"，而是**一个在压力下会做出可预测选择的活体**。

判断一个人物立不立得住，就看这一点：**把他扔进一个两难处境，读者能不能预判他会怎么选？** 如果能，这个人物就立住了。

四维塑模法从四个维度构建人物，四个维度互相牵制，人物的行为就从这四个维度的碰撞中自然产生。

---

## 四维模型

### 第一维：欲望（Want）
**人物想要什么？**

这是人物行动的表层动机，是他自己明确知道并追求的东西。

| 欲望类型 | 例子 |
|---------|------|
| 生存欲 | 活下去、变强、保护自己 |
| 权力欲 | 变强、掌控、被服从 |
| 归属感 | 被接纳、有家人、不孤独 |
| 复仇欲 | 讨回公道、让仇人付出代价 |
| 求知欲 | 知道真相、解开谜团 |
| 救赎欲 | 弥补过去的错、救某个人 |
| 证明欲 | 证明自己、让看不起的人闭嘴 |

> 欲望必须具体。"想变强"太空，"想变得强到能保护妹妹"才具体。

---

### 第二维：恐惧（Fear）
**人物害怕什么？**

恐惧是人物行为的**隐形约束**。表面上人物在追求欲望，但实际上他的很多选择是被恐惧驱动的——他选择这样做而不是那样做，往往是因为那样做会触碰到他的恐惧。

| 恐惧类型 | 例子 |
|---------|------|
| 失去恐惧 | 害怕失去重要的人、害怕孤独 |
| 无能恐惧 | 害怕自己没用、害怕保护不了别人 |
| 背叛恐惧 | 害怕被信任的人背叛、害怕被抛弃 |
| 身份恐惧 | 害怕真实身份暴露、害怕被发现是假货 |
| 失控恐惧 | 害怕局面失控、害怕自己变成怪物 |
| 屈辱恐惧 | 害怕丢脸、害怕被看不起、害怕失败 |

> 欲望和恐惧往往是一对：想要保护（欲望）是因为害怕失去（恐惧）。

---

### 第三维：能力（Ability）
**人物有什么本事？**

能力不只是战斗力，还包括：
- 硬能力：战斗力、智商、技能、特殊能力
- 软能力：口才、人脉、观察力、领导力、忍耐力
- 资源能力：钱、势力、信息渠道、宝物
- 性格能力：冷静、果断、坚韧、共情、伪装

**能力必须有边界。** 全知全能的人物没有张力。每个能力都要有对应的限制或代价。

> 人物的能力上限决定了他能做到什么，人物的能力下限决定了他会在什么地方栽跟头。

---

### 第四维：代价（Cost）
**人物要付出什么？**

每一个选择都有代价。人物在追求欲望的过程中，会失去什么、牺牲什么、背负什么。

代价的类型：
- **实质性代价**：受伤、失去能力、失去资源
- **关系性代价**：和某人决裂、失去信任、被误解
- **道德性代价**：做了违背原则的事、双手沾血
- **心理性代价**：创伤、内疚、怀疑自己、变成自己讨厌的样子

> 代价是让人物"立起来"的关键。没有代价的人物是纸片人。代价越大，人物越有重量。

---

## 四维碰撞产生行为

人物在具体场景中会怎么做，是四维碰撞的结果：

```
欲望推动他向前 → 恐惧拉住他 → 能力决定他能走多远 → 代价决定他走过去之后会变成什么样
```

**例子：主角面对仇人**
- 欲望：杀了仇人复仇
- 恐惧：害怕自己也变成杀人魔；害怕杀了仇人会连累无辜的人
- 能力：实力足够杀掉仇人，但会暴露身份
- 代价：杀了他就等于双手沾血，再也回不到过去；而且仇人掌握着重要情报，杀了就断了线索

→ 结果：主角忍住没杀，选择先查清楚真相，但心里埋下了仇恨的种子

> 四维越平衡，人物越立体。只有欲望没有恐惧=莽夫；只有恐惧没有欲望=废物；只有能力没有代价=龙傲天。

---

## 人物弧线

好的人物不是一成不变的。故事的过程，就是四维发生变化的过程。

### 正向弧线（成长型）
- 欲望：从自私 → 利他
- 恐惧：从逃避 → 直面
- 能力：从弱小 → 强大
- 代价：从不愿付出 → 主动承担

### 反向弧线（堕落入）
- 欲望：从正当 → 扭曲
- 恐惧：从合理 → 偏执
- 能力：从普通 → 强大但失控
- 代价：从有底线 → 不断突破底线

### 平弧线（坚定型）
- 人物的核心四维不变
- 变化的是周围的人和环境
- 人物的坚定本身就是力量和故事

## 角色设计检验清单

1. ✅ **一句话能说清这个角色是谁吗？**（身份 + 核心欲望 + 核心恐惧）
2. ✅ **他有明确的能力边界吗？**（不是什么都会）
3. ✅ **他的选择有代价吗？**（每次重要选择都要失去点什么）
4. ✅ **他和主角的关系有变化空间吗？**（不是一成不变的好/坏）
5. ✅ **他有自己的独立剧情吗？**（不是只为了主角存在）
6. ✅ **他说话有辨识度吗？**（遮住名字也能认出来）
7. ✅ **他的行为逻辑自洽吗？**（以他的性格，他会这么做吗？）

## 配角功能分类

不是每个角色都需要完整的四维塑模。配角按功能可以分为几类，每类的设计重点不同：

| 配角类型 | 核心功能 | 设计重点 |
|---------|---------|---------|
| **导师型** | 给主角指引、传递信息 | 神秘感 + 有过去 + 有限制（不能直接帮主角解决问题） |
| **对手型** | 给主角压力、推动主角成长 | 和主角有镜像关系 + 有自己的正当性 |
| **伙伴型** | 和主角并肩作战、提供情感支撑 | 互补能力 + 独立人格 + 有自己的目标 |
| **工具型** | 传递信息、推动剧情 | 功能性 + 有记忆点（一个鲜明特征就够） |
| **镜子型** | 展示"走错路的主角" | 和主角起点相似但选择不同 |
| **牺牲品型** | 制造代价、推动主角转变 | 建立情感连接 + 合理的牺牲 |

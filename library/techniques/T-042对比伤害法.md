# T-042 对比伤害法

> L2 Strategy | 短篇技法
> 来源：Research层分析（只因避雷白月光早餐店/对比梗追妻）
> 适用：渣男/白月光/替身

## 核心定义

通过对比展现伤害：他对她vs他对你，完全不同的态度形成巨大反差。

## 底层原理

对比是最直接的伤害。当读者看到男主对白月光vs对你的态度差异，愤怒感和心疼感同时爆发。

## 操作步骤

### Step 1：设计"对比"场景

| 对比维度 | 他对白月光 | 他对你 |
|----------|------------|--------|
| 关心 | 细致入微 | 毫不在意 |
| 礼物 | 精心准备 | 顺手买的 |
| 态度 | 温柔体贴 | 冷淡敷衍 |
| 行动 | 主动付出 | 被动应付 |

### Step 2：发现"真相"时刻

主角发现真相：
- 白月光才是真爱
- 自己是替身
- 他的好从来不是给自己的

### Step 3：内心崩溃

| 崩溃阶段 | 表现 |
|----------|------|
| 第一阶段 | 不敢相信 |
| 第二阶段 | 回忆对照 |
| 第三阶段 | 彻底心死 |

### Step 4：离开/反击

| 结局 | 类型 |
|------|------|
| 离开 | 不再回头 |
| 反击 | 让对方后悔 |
| 逆袭 | 找到更好的人 |

## 应用公式

```
他对白月光（好） vs 他对你（差） = 对比伤害
真相揭露 + 内心崩溃 + 离开/逆袭 = 对比伤害法
```

## 典型案例：白月光早餐店

**对比场景**：
- 白月光：过敏食物 + 毁容
- 替身：经纪人帮忙避雷
- 渣男：将她丢在死亡谷

**真相揭露**：
> "她是我找的替身"
> "你是她的替代品"

**离开/反击**：
- 逃生
- 揭露真相
- 让渣男付出代价

## 避坑指南

1. **对比要明显**：差距越大越爽
2. **细节要具体**：不能只是说"对她好"
3. **转变要自然**：从信任到崩溃

# T-050 克星传人类技法

> L2 Strategy | 短篇技法
> 来源：Research层分析（风水轮流转/白蛇传人）
> 适用：玄幻/灵异/特殊身份

## 核心定义

主角有特殊身份（克星/传人/天师），带着前世记忆/能力重生，破解阴谋。

## 底层原理

"特殊身份+前世记忆"的双重优势，让主角拥有别人没有的能力和信息差。

## 操作步骤

### Step 1：设计"特殊身份"

| 身份类型 | 能力 |
|----------|------|
| 克星传人 | 天生克某些东西 |
| 天师 | 捉鬼/驱邪 |
| 算命师 | 预知未来 |
| 风水师 | 看破风水 |

### Step 2：设计"前世记忆"

前世记忆内容：
- 知道阴谋
- 知道真相
- 知道谁是敌人

### Step 3：设计"死劫/印记"

| 印记类型 | 含义 |
|----------|------|
| 死劫纹 | 会死 |
| 诅咒 | 某种代价 |
| 印记 | 身份标记 |

### Step 4：设计"改变命运"

改变方式：
- 利用身份破解
- 利用记忆布局
- 主动出击

## 应用公式

```
特殊身份 + 前世记忆 + 死劫印记 + 改变命运 = 克星传人类技法
```

## 典型案例：风水轮流转

**特殊身份**：
- 白家传人
- 克蛇

**前世记忆**：
- 知道前世的阴谋
- 知道林珹会背叛
- 知道死劫纹的来历

**死劫印记**：
- 林珹额间的死劫纹
- 三个月期限
- 只有主角能解

**改变命运**：
- 不再无条件付出
- 利用身份布局
- 主动掌握主动权

## 身份类型

| 身份 | 能力 | 适用场景 |
|------|------|----------|
| 克星传人 | 克特定事物 | 玄幻/灵异 |
| 天师 | 捉鬼驱邪 | 灵异/恐怖 |
| 算命师 | 预知 | 悬疑/命运 |
| 风水师 | 看破风水 | 都市/民俗 |

## 避坑指南

1. **身份要有独特性**：不是普通的天师
2. **记忆要有用**：知道别人不知道的
3. **改变要有代价**：不能无敌

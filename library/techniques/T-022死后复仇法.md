# T-022 死后复仇法

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（保送名额让给姐姐，我死后全家悔疯了）
> 适用：死人文学/复仇爽文/系统复仇

## 核心定义

主角死后以"上帝视角"看到家人的后悔与痛哭，通过"死后复仇"满足读者的情绪宣泄需求。

## 底层原理

活着时不被珍惜，死后才知珍贵。读者通过主角的"死后视角"获得报复感和宣泄感。

## 操作步骤

### Step 1：设计生前委屈

| 类型 | 表现 |
|------|------|
| 被偷 | 名额/机会/爱人被抢 |
| 被背叛 | 家人/爱人/朋友 |
| 被冤枉 | 无辜受害 |

**要点**：委屈要足够大，读者才会爽

### Step 2：设计死亡触发

| 类型 | 表现 |
|------|------|
| 系统触发 | 绝望值达到阈值 |
| 自己选择 | "既然如此，我走" |
| 意外死亡 | 悲剧收场 |

**要点**：死亡要轰轰烈烈

### Step 3：死后视角

主角死后以"旁观者"视角：
- 看家人痛哭
- 看家人后悔
- 看恶人受报应

### Step 4：复仇满足

| 类型 | 表现 |
|------|------|
| 家人后悔 | "原来她才是最好的" |
| 恶人报应 | 失去一切 |
| 主角翻盘 | 身份揭示/真相大白 |

## 应用公式

```
生前委屈 + 死亡 + 死后视角 + 后悔报应 = 死后复仇
```

## 变体

| 变体 | 死后视角 | 爽点 |
|------|----------|------|
| 系统复仇 | 系统播报家人状态 | 数据化爽感 |
| 灵魂旁观 | 灵魂飘在空中看 | 情绪化爽感 |
| 重生复仇 | 死后回到过去 | 改变命运 |

## 典型案例：保送名额让给姐姐

**生前委屈**：
- 保研名额被偷给姐姐
- 未婚夫帮着伪造档案
- 项链被戴在姐姐脖子上

**死亡触发**：
- 系统检测到"极度不公"
- 主角选择启动死亡程序

**死后视角**：
> "用我的命，换他们余生……万劫不复。"

## 避坑指南

1. **委屈要够大**：读者要心疼主角
2. **死亡要轰轰烈烈**：不是默默死掉
3. **后悔要具体**：家人说了什么/做了什么

- T-005爽点设计：后悔是爽点来源

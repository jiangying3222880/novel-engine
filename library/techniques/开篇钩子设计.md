# 开篇钩子设计

## 核心原理

读者决定要不要继续读，往往只看前 300 字。

开篇的任务不是"把设定讲清楚"，而是**让读者产生"我想知道接下来发生什么"的欲望**。

> 开篇像鱼钩——不是把鱼的习性讲清楚，而是让鱼咬钩。

---

## 一、6 种经典开局

### 1. 异常开局
**从日常中的一个不对劲开始。**

> 例：林辰每天都在这条路上跑步，但今天不一样——路边的第三棵梧桐树，昨天还不在那里。

**适用场景**：悬疑、都市灵异、科幻、玄幻
**钩子原理**：读者会好奇"为什么会这样？"
**关键**：异常要具体、可感知，不是抽象的"世界变了"

### 2. 危机开局
**一上来就是生死关头。**

> 例：刀已经架在了脖子上，林辰甚至能闻到刀刃上的铁锈味。

**适用场景**：玄幻、武侠、末世、冒险
**钩子原理**：读者会担心"他怎么活下来？"
**关键**：危机要具体，有明确的倒计时或死亡威胁

### 3. 反差开局
**用强烈的反差抓住眼球。**

> 例：全城最有权势的男人，此刻正跪在一个乞丐面前。

**适用场景**：都市、权谋、古言、爽文
**钩子原理**：读者会好奇"为什么会这样？他是谁？"
**关键**：反差越强烈，钩子越有力

### 4. 悬念开局
**抛出一个谜团，让读者想知道答案。**

> 例：林辰收到了一封自己写给自己的信，邮戳是十年后。

**适用场景**：悬疑、推理、科幻、都市
**钩子原理**：好奇心驱动，读者想知道谜底
**关键**：谜团要清晰，不能太复杂把读者绕晕

### 5. 情绪开局
**用强烈的情绪抓住读者。**

> 例：母亲下葬那天，林辰一滴眼泪都没掉。不是不难过，是哭的人太多了，轮不到他。

**适用场景**：言情、现实向、治愈、虐文
**钩子原理**：情感共鸣，读者想知道"后来呢？"
**关键**：情绪要真，不要刻意煽情

### 6. 动作开局
**从一个正在进行的动作切入。**

> 例：第三刀砍下去的时候，林辰的手已经在抖了。但他不能停，后面还有十七个人。

**适用场景**：玄幻、武侠、末世、军事
**钩子原理**：动作有天然的张力，读者想知道结果
**关键**：动作要有后果，不是为了打而打

### 7. 烘托法（job-0012补强）
**主角不出场，全篇描写都指向主角，让读者把注意力聚焦在即将出场的主角身上。**

> 例：《枭臣》前两章主角未出现，但所有描写都把焦点聚向主角。

**钩子原理**：读者会把所有线索往主角身上关联，期待主角出场
**关键**：配角的反应/态度要有层次，能暗示主角的牛逼或特殊

### 8. 楔子伏笔法（job-0012补强）
**用精炼的一小段引子，吊起全书最大的胃口，让读者欲罢不能。**

> 例：楚留香传奇开头："闻君有白玉美人，妙手雕成，极尽妍态，不胜心向往之。今夜子正，当踏月来取。君素雅达，必不致令我徒劳往返也。"

**钩子原理**：用一个悬念（宝贝/秘密/任务）开启全书
**关键**：楔子必须精炼（一章内），不能写三五章楔子；楔子要引出全书最大伏笔

## 二、开局 300 字自检

前 300 字必须完成至少 3 件事：

| # | 任务 | 说明 |
|---|------|------|
| 1 | **立住场景** | 读者知道这是哪里、在发生什么 |
| 2 | **立住主角** | 读者对主角有初步印象（身份/状态/性格） |
| 3 | **抛出钩子** | 读者想知道接下来发生什么 |
| 4 | **建立语气** | 读者知道这本书是什么风格（冷的/燃的/逗的/虐的） |
| 5 | **人物不超过5个** | 前1万字出场人物不超过5个，读者记不住更多（job-0012补充） |

> 300 字内不需要讲清楚世界观，不需要介绍所有人，不需要交代前因后果。只需要做到：让读者想翻下一页。

---

## 三、开局常见雷区

### ❌ 雷区1：上来就介绍世界观
"在这片大陆上，有五个国家……"
→ 读者还没关心人物呢，不关心世界什么样。先有人，再有世界。

### ❌ 雷区2：大段背景介绍
"林辰今年 20 岁，是林家的三公子，因为母亲地位低微……"
→ 背景可以慢慢给，不要开篇倒出来。让读者通过行动认识人物。

### ❌ 雷区3：开局太普通
"今天天气真好，林辰像往常一样起床……"
→ 太普通=没有钩子。普通的日常里必须有不普通的东西。

### ❌ 雷区4：人物太多
开篇就出场七八个人，读者记不住。
→ 第一章聚焦主角，最多再加 1-2 个关键人物。

### ❌ 雷区5：解释一切
读者有疑问时，不要立刻回答。
→ 疑问就是钩子。回答得太快，钩子就没了。

### ❌ 雷区6：开局就升级
第一章就获得金手指、就升级、就打脸。
→ 没有压抑就没有爽。先让读者知道主角有多惨，逆袭才爽。

## 四、黄金三章结构

网文有"黄金三章"的说法——前三章决定读者追不追。

### 第一章：钩子 + 建立
- 抛出核心钩子
- 立住主角和他的处境
- 让读者知道这是本什么书

### 第二章：压力 + 期待
- 给主角施压（困难/危机/挑战）
- 让读者看到主角的应对方式
- 种下第一个大期待（"他能不能做到？"）

### 第三章：小兑现 + 大钩子
- 兑现一个小爽点/小悬念（让读者尝到甜头）
- 抛出一个更大的钩子/危机（让读者想继续看）
- 主角做出一个不可逆的选择（踏上征程）

> 三章过完，读者应该明白：主角是谁、要干什么、面对什么、为什么值得追。

### 小白文签约公式（job-0042 · 10章结构）

> 前10章是签约的关键，必须让读者看到主角从弱到强的过程 + 装逼的爽感。

| 章节 | 内容 | 核心目标 |
|------|------|---------|
| 第一章 | 介绍主角背景（凄惨/平凡/穷） | 让读者代入 |
| 第二章 | 矛盾加剧，主角被打压 | 建立憋压感 |
| 第三章 | 外挂出现（不能一开始就非常牛逼） | 建立期待 |
| 第四章 | 第一个爽点（装逼踩人） | 兑现憋压 |
| 第五章 | 低调隐藏实力或继续装逼 | 扮猪吃虎 |
| 第六章 | 都市文出现女主，玄幻参考 | 感情线引入 |
| 第七章 | 主线剧情展开，结识新人脉 | 世界观扩展 |
| 第八章 | 高级敌人出现（嚣张公子/校花等） | 建立新冲突 |
| 第九章 | 冲突加剧 | 憋压 |
| 第十章 | 主角再次爆发 | 第二个小爽 |

#### 关键数字（job-0042）

| 数字 | 含义 |
|------|------|
| **300字** | 开局内必须出现主角 |
| **3000字** | 第一章内必须爆发第一个矛盾冲突 |
| **3章** | 之内必须亮出功法体系或最大卖点 |
| **3万字** | 内必须爆发第一个高潮，解决第一个矛盾 |
| **30万字** | 第一个大情节应该解决（配合上架） |

## 五、不同题材的开局偏好

| 题材 | 推荐开局类型 | 不推荐 |
|------|-------------|--------|
| 玄幻/修仙 | 危机开局 + 反差开局 | 情绪开局（太慢） |
| 都市 | 反差开局 + 悬念开局 | 纯介绍开局 |
| 悬疑/推理 | 悬念开局 + 异常开局 | 动作开局（破坏氛围） |
| 言情 | 情绪开局 + 反差开局 | 纯世界观开局 |
| 末世/无限流 | 危机开局 + 异常开局 | 慢热开局 |
| 历史/权谋 | 悬念开局 + 反差开局 | 纯动作开局 |

---

## 六、开局检验法

写完第一章后，做这个检验：

把第一章的最后一句话盖住，问自己：
1. 读者想知道下一句是什么吗？
2. 读者会翻下一页吗？
3. 如果我是读者，我会继续看吗？

如果答案有任何一个是否定的——回去改。

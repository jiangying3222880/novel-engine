# T-026 多世轮回选择法

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（嫁给他人为妾后，两个竹马悔疯了）
> 适用：重生/古言/穿越

## 核心定义

主角经历多世轮回，每次都做出选择，每次都看清真相，最终找到最优解。

## 底层原理

"如果能重来"是人类永恒的心理需求。多世轮回让主角拥有"上帝视角"，每次选择都是升级。

## 操作步骤

### Step 1：第一世——选错

按照正常逻辑选择，结果悲惨：
- 选择A男主 → 被背叛
- 选择B男主 → 还是被背叛
- 死亡/悲剧收场

### Step 2：第二世——尝试改变

换了选择，结果更糟：
- 选B男主 → 以为会好
- 结果：同样的悲剧，不同的形式
- 再次死亡

### Step 3：第三世——看透本质

不再选A或B，而是选C：
- 两个男人都不行
- 选皇帝/皇帝的儿子/更大的靠山
- 或者：谁都不选，自己做主

### Step 4：真相揭示

多世的真相：
- 为什么两个竹马都会背叛？
- 背后有什么阴谋？
- 真正的良人是谁？

## 应用公式

```
第一世（选A） → 悲剧 → 第二世（选B） → 更悲剧 → 第三世（选C） → 真相大白
```

## 典型案例：嫁给他人为妾后，两个竹马悔疯了

**第一世**：
- 选择：竹马萧凛
- 结果：被山匪劫持，儿女惨死
- 死亡：沦为匪妓，含恨而终

**第二世**：
- 选择：另一个竹马裴淮川
- 结果：被囚禁一生
- 死亡：病重而死，他没来看一眼

**第三世**：
- 选择：不选两个竹马，选皇帝
- 结果：做皇帝的妾，反而最安全
- 真相：两个竹马心里都装着同一个人（叶绾绾）

## 多世轮回结构

```markdown
【第一世】
选择 → 结果 → 死亡 → 学到什么

【第二世】
新选择 → 以为不同 → 结果更糟 → 学到更多

【第三世】
不选AB → 选C → 真相揭示 → 圆满结局
```

## 避坑指南

1. **每世要有新发现**：不能只是换个人，结果一样
2. **死亡要有意义**：每一世的死亡都要推动主角成长
3. **选择要有递进**：第三世的选择要比前两世高明

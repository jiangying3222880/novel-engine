# T-021 极致压抑法

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（抖音故事会小说）
> 适用：虐文/亲情虐/身世虐/绝症虐

## 核心定义

通过三层压迫（家庭→事业→生命）把主角压到最低点，制造最大情绪反差。

## 底层原理

压抑越深，释放越爽。读者看到主角被欺负到极致，会产生强烈同理心和期待反转的心理。

## 操作步骤

### Step 1：家庭压迫层

| 类型 | 表现 |
|------|------|
| 偏心 | 父母永远偏向其他人 |
| 否定 | 永远得不到认可 |
| 打压 | 做什么都是错的 |

**要点**：要有具体事件，不能只说"不被爱"

### Step 2：事业压迫层

| 类型 | 表现 |
|------|------|
| 工作 | 即将失去/被排挤 |
| 学业 | 被偷名额/被顶替 |
| 经济 | 身无分文/负债累累 |

**要点**：与家庭压迫形成叠加

### Step 3：生命压迫层

| 类型 | 表现 |
|------|------|
| 疾病 | 绝症/重病 |
| 意外 | 车祸/灾难 |
| 自杀 | 走投无路 |

**要点**：这是最低点，要有具体描写

## 应用公式

```
家庭压迫 + 事业压迫 + 生命压迫 = 极致压抑
极度压抑 + 反转期待 = 爆款虐文
```

## 三层压迫模板

```markdown
【第一层：家庭】
- 父母永远偏向姐姐/弟弟
- 我做什么都是错的
- 高考考赢了，却不是我的升学宴

【第二层：事业】
- 工作业绩不达标
- 领导施压
- 即将被开除

【第三层：生命】
- 查出绝症
- 没钱治疗
- 被家人拉黑
```

## 变体

| 变体 | 三层设计 | 爽点 |
|------|----------|------|
| 亲情虐 | 偏心→打压→不认 | 断亲/打脸 |
| 爱情虐 | 出轨→背叛→绝症 | 复仇/重生 |
| 身世虐 | 被拐→被虐→濒死 | 真相大白/身份逆袭 |

## 避坑指南

1. **要有具体事件**：不能只说"很惨"，要有画面感
2. **每层要有递进**：家庭→事业→生命，越来越惨
3. **反转要有铺垫**：压抑时就要暗示希望

# T-014 潜台词与角色声线

> 潜台词5种方式 · 潜台词使用场景 · 角色声线四件套 · 六角色类型  
> 来源：中文写作对白口语方法总册（job-0020）

---

## 一、潜台词核心原理

潜台词 = 说出口的字面意思 + 没说出但被对方感受到的隐含意思。

**核心公式**：

> 字面 ≠ 实际意图  
> 潜台词 = 字面意思 + 关系暗线 + 情绪底色

**判断标准**：读者看完对话后能感受到"话里还有话"，但没有直接写出来。

---

## 二、潜台词5种方式

### 方式一：反说（嘴硬心软/表冷内热）

字面和真实意思相反。

| 字面 | 潜台词 |
|------|--------|
| "随你便。" | "我很在乎，但你气死我了。" |
| "我又没让你等。" | "你为什么不主动？" |
| "爱来不来。" | "我很希望你来。" |
| "哦。" | "我很在意，但不想承认。" |

### 方式二：借事说人

借工作/风险/安排，表面上在说事，实际上在说关心。

| 场景 | 字面 | 潜台词 |
|------|------|--------|
| 雨天 | "明天降温，多穿点。" | "我在乎你。" |
| 出差 | "别光顾着忙，记得吃饭。" | "我担心你。" |
| 受伤 | "先把伤口处理了。" | "我不希望你有事。" |
| 加班 | "别太晚，明天还有会。" | "我体谅你，但我心疼。" |

### 方式三：借物说情

借礼物/旧物/伤口/餐食，表面上在说物，实际上在说关系。

| 字面 | 潜台词 |
|------|--------|
| "给你带了宵夜。" | "我在乎你有没有吃。" |
| "你那个杯子还在我这。" | "我没忘过这段关系。" |
| "这是你以前送我的。" | "这段感情对我很重要。" |

### 方式四：话留半截

说完关键信息停下来，逼对方接话。

| 场景 | 字面 | 潜台词 |
|------|------|--------|
| 暧昧 | "其实我本来想……" | 想说喜欢，但说不出口，等你挽留 |
| 道歉前 | "我不是故意……" | 想解释，但尊严不允许，只能停在这 |
| 质问 | "那天你和她……" | 你为什么要瞒我？等你解释 |
| 复合 | "如果你当时……" | 算了，我不说了，你自己想 |

### 方式五：明问暗查

表面在问事情，实际上在查对方的态度/动机/真相。

| 场景 | 字面 | 暗查目的 |
|------|------|---------|
| 醋意 | "你和她什么时候这么熟了？" | 你是不是对她有意思？ |
| 怀疑 | "这件事你为什么知道？" | 你是不是有隐瞒？ |
| 试探 | "你还记得那天吗？" | 你心里有没有我？ |
| 威胁 | "你确定要这么做？" | 我警告你不要。 |

---

## 三、什么场景最该用潜台词

> **权谋试探 / 暧昧升温 / 情敌交锋 / 长辈施压 / 下属撒谎 / 朋友翻脸前夜**

### 什么时候不该用

- **紧急危险场景**（需要直接说出信息）
- **第一轮冲突爆发**（先让冲突清晰，再埋潜台词）
- **读者必须明确知道的信息**（别让读者猜核心剧情）

## 四、角色声线四件套

每个角色要有自己独特的说话方式。四个要素锁定角色声线：

### 第一件：常用句长

| 类型 | 句长特征 | 示例 |
|------|---------|------|
| 紧张型 | 句子短，经常不完整 | "我……不是你想的那样……" |
| 掌控型 | 中短句，节奏稳定 | "坐下，我有话说。" |
| 啰嗦型 | 长句，绕来绕去 | "是这样的，我本来呢，是打算……" |
| 冷淡型 | 短句，停顿多 | "嗯。……随便。" |

### 第二件：常用口头词

每个人要有**1-3个口头词或语气词**，让读者一听就知道是谁：

| 角色 | 口头词 |
|------|--------|
| 话痨男主 | "说真的" / "你懂我意思吧" |
| 内敛女主 | "……"（沉默）/ "随便" / "也行" |
| 痞气男配 | "得了吧" / "你可真行" |
| 傲娇女配 | "哼" / "谁稀罕" |

### 第三件：情绪上升时的变化方式

愤怒时每个角色的表现不同：

| 角色类型 | 愤怒时语速 | 愤怒时词长 | 愤怒时其他特征 |
|---------|-----------|-----------|--------------|
| 话痨男主 | 更快更密 | 不减反增 | 吐槽升级 |
| 内敛女主 | 突然变短 | 骤降到最短 | 从沉默到爆发 |
| 上位者 | 不变 | 不变 | 语气变冷，威胁留半句 |
| 疯批反派 | 反常平静 | 句子更长更慢 | 内容狠但语气平 |

### 第四件：禁用表达（绝对不会说的话）

> 这个角色**绝对不会**怎么说话。

| 角色 | 禁用表达 |
|------|---------|
| 冷酷杀手 | 不会用感叹号 |
| 傲娇女配 | 不会直接说"我喜欢你" |
| 正人君子 | 不会用威胁口吻 |
| 痞气男配 | 不会说文绉绉的话 |

---

## 五、六角色类型速查

| 类型 | 句长 | 核心特征 | 禁忌 |
|------|------|---------|------|
| **现代话痨型男主** | 中短句 | 反应快/吐槽快/解释夹专业词 | 不能一直贫，适时给沉默 |
| **内敛女主** | 短句 | 先判断再表态/少说爱多做事 | 不能变告白机器，需要爆发点 |
| **直球型女配** | 中短句 | 直接热烈/敢说敢要 | 不能全靠撒娇，需要吃瘪时刻 |
| **上位者** | 短句 | 裁决口吻/不爱解释/常留半句 | 不能絮叨，一句顶一句 |
| **老江湖** | 中句 | 含沙射影/见招拆招/话里有钩 | 不能全谜语人，关键时刻要给真话 |
| **疯批反派** | 短句或异常平静 | 内容狠语气稳/喜反差 | 不能只会吼，要给读者压迫感 |

## 六、自检清单

### 潜台词检查

- [ ] 这场戏需要用潜台词吗？还是需要直接说清？
- [ ] 潜台词方式与场景匹配吗？
- [ ] 读者能感受到"话里有话"吗？
- [ ] 潜台词有没有歧义到让读者误解剧情？

### 角色声线检查

- [ ] 这个角色的常用句长固定吗？
- [ ] 他有口头词吗？
- [ ] 愤怒/高兴/悲伤时，他的说话方式有变化吗？
- [ ] 有没有出现这个角色绝对不会说的话？

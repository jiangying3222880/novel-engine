# T-034 扮猪吃虎高层法

> L2 Strategy | 短篇技法
> 来源：Research层分析（沉默的继承人）
> 适用：豪门/商战/逆袭

## 核心定义

主角在高层/豪门环境中装弱/装傻，实则是隐藏实力的全能王者。

## 底层原理

"傻子逆袭"比"强者更强"更爽。当全场精英被骂得抬不起头，主角轻轻一句震惊全场。

## 操作步骤

### Step 1：设计"弱"的表面

| 表面 | 设计 |
|------|------|
| 外表 | 不会说话/智力低下/痴傻 |
| 处境 | 被家族嫌弃/被当废物 |
| 外界认知 | "这孩子没救了" |

### Step 2：埋设"强"的暗线

| 暗线 | 设计 |
|------|------|
| 前世记忆 | 重生者/穿越者 |
| 隐藏身份 | 天才/精英/专家 |
| 真实能力 | 金融/武术/医术 |

### Step 3：制造"被欺负"场景

| 场景 | 表现 |
|------|------|
| 家族会议 | 被嘲讽 |
| 商业谈判 | 被轻视 |
| 学校 | 被霸凌 |

### Step 4：关键时刻"开口"/"出手"

关键时刻：
- 全场被羞辱时
- 家族危机时
- 敌人嚣张时

反击方式：
- 用对方的语言说话（外语/专业术语）
- 直接点出要害
- 震惊全场

## 应用公式

```
装弱（不说话/装傻） + 暗线（前世/天才） + 被欺负场景 + 关键时刻震惊全场 = 扮猪吃虎高层法
```

## 典型案例：沉默的继承人

**弱表面**：
- 八岁还不会说话
- 被当成傻子
- 所有人嫌弃

**强暗线**：
- 前世：金融分析师（三十年经验）
- 记忆：什么都懂
- 只想安静当废物

**被欺负场景**：
- 堂兄弟嘲讽
- 精英被华尔街骂得抬不起头
- 父亲失望

**关键时刻**：
> "我往前走了一步，用他的母语开口说出了此生第一句话。"
> （震惊全场）

## 变体

| 变体 | 弱表面 | 强实质 | 场景 |
|------|--------|--------|------|
| 哑巴型 | 不会说话 | 外语天才 | 商务谈判 |
| 傻子型 | 智力低下 | 隐藏身份 | 豪门家族 |
| 废物型 | 修炼废物 | 天才转世 | 修仙世界 |

## 避坑指南

1. **弱要够弱**：让读者都觉得憋屈
2. **强要够强**：一出手就是王炸
3. **时机要对**：全场最低谷时出手

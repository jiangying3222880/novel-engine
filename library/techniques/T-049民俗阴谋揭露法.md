# T-049 民俗阴谋揭露法

> L2 Strategy | 短篇技法
> 来源：Research层分析（民俗流/拍喜）
> 适用：民俗/阴谋/复仇

## 核心定义

利用民俗/规矩作为幌子，实际上是在害人，主角发现真相后反击。

## 底层原理

"打着传统的旗号害人"。当传统变成伤害工具，揭露真相的力量更强。

## 操作步骤

### Step 1：设计"民俗"设定

| 民俗类型 | 伤害方式 |
|----------|-----------|
| 拍喜 | 打到喊"生"为止 |
| 规矩 | 压迫女性 |
| 传统 | 掩盖罪行 |

### Step 2：设计"阴谋"真相

| 阴谋类型 | 真相 |
|----------|------|
| 表面 | 传统规矩 |
| 实际 | 害人的借口 |
| 真相 | 早就设计好的 |

### Step 3：主角"发现"真相

发现方式：
- 偷听对话
- 偶然发现
- 有人告知

### Step 4："反击"行动

反击方式：
- 揭露真相
- 打破规矩
- 逃离

## 应用公式

```
民俗规矩 + 害人真相 + 发现真相 + 反击成功 = 民俗阴谋揭露法
```

## 典型案例：拍喜

**民俗规矩**：
- 三年无子要"拍喜"
- 打到女人喊"生"为止
- 美其名曰驱邪求子

**阴谋真相**：
- 丈夫为了白月光设计
- 让别人打老婆
- 拍照/录像

**发现真相**：
- 偷听丈夫和兄弟的对话
- 知道全部计划

**反击**：
- 将计就计
- 揭露真相
- 逃离

## 避坑指南

1. **民俗要具体**：有画面感
2. **阴谋要黑暗**：让读者愤怒
3. **反击要有力**：打破规矩

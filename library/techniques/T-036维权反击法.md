# T-036 维权反击法

> L2 Strategy | 短篇技法
> 来源：Research层分析（交完26万关税后，我报警说丢了四斤黄金）
> 适用：职场/维权/正义反击

## 核心定义

主角遭遇不公待遇，通过合法途径维权反击，用证据和法律让对方付出代价。

## 底层原理

"有理走遍天下"。当对方仗势欺人，主角用证据和法律反杀，爽感来自正义得到伸张。

## 操作步骤

### Step 1：制造"不公"

对方的不当行为：
- 仗势欺人
- 颠倒黑白
- 索要贿赂
- 恶意损坏

### Step 2：收集"证据"

| 证据类型 | 作用 |
|----------|------|
| 官方文件 | 证明真相 |
| 录像/录音 | 记录过程 |
| 证人 | 第三方证明 |
| 票据 | 金钱往来 |

### Step 3：正当反击

维权方式：
- 报警
- 投诉
- 举报
- 法律诉讼

### Step 4：让对方付出代价

| 结果 | 效果 |
|------|------|
| 对方被调查 | 失去工作 |
| 对方被惩罚 | 付出代价 |
| 主角获得赔偿 | 正义伸张 |

## 应用公式

```
不公待遇 + 收集证据 + 合法维权 + 对方付出代价 = 维权反击法
```

## 典型案例：交完26万关税后

**不公待遇**：
- 海关坚持说是黄金（实际是铜）
- 损坏参赛作品
- 索要贿赂（26万关税）
- 反复刁难

**收集证据**：
- 官方核验报告（铜）
- 录像（损坏过程）
- 邀请函（证明参赛身份）
- 录音（对方说的话）

**合法维权**：
> "我现在就报案，海关恶意损坏我代表国家出国比赛的设计品"

**反击结果**：
- 要求三方在场重新核验
- 全程录像
- 证据链完整
- 让对方无法抵赖

## 维权武器库

| 武器 | 适用场景 |
|------|----------|
| 录像 | 对方损坏物品/不当行为 |
| 录音 | 对方索贿/威胁 |
| 文件 | 官方证明/票据 |
| 举报 | 对方违规/违法 |
| 报警 | 对方犯罪 |

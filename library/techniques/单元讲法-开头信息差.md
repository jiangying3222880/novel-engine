# 单元讲法 · 开头读者信息差

> 层级：L2 Technique（可替换的讲法，不是铁律）
> 状态：冻结（L2 技法，2026-09-14 自动裁决）

## 命题

**开头 1-3 句亮出读者侧信息差（读者知道 X、角色不知道），制造"快说啊"的憋压。**
读者带着"我知道你被骗了/我知道你的丈夫是假的"的认知进入故事，每一句无关的日常都变成煎熬。

## 适用场景

- 所有需要快速钉住读者的短篇开篇
- 信息差引擎（弹幕/心声/偷听/错认）的最佳启动方式

## 结构骨架

```
第 1-3 句：亮牌（读者知道 X）
    ↓
主角视角正常叙述（角色不知道 X——反差产生煎熬）
    ↓
读者持续等待"主角什么时候发现"
```

## 证据样本（精读验证，不复制原文）

5 篇爆款中 4 篇开头即亮牌（job-0004 证据）：读者提前知道背叛/身份/真相，主角浑然不觉。

## 硬约束

- **信息差必须"可等待"**：不是 1 句就揭穿，而是有足够长的"主角不知情"时段
- 信息差必须是"读者急着让角色知道"的信息（不是读者不在乎的背景）
- 纯情绪流（如《唯愿来生不识君》不开头亮牌）是 C 类受控偏离，不强制

## 组合

- + 信息差引擎（short-story-engines）= 弹幕/心声/偷听流
- + 藏牌反击 = 读者知牌 + 主角也知牌（双重信息差）
- 与 C-003（信息三层）支撑：开头读者信息差 = 三层错位的开头实例化

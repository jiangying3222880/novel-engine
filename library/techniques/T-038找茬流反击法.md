# T-038 找茬流反击法

> L2 Strategy | 短篇技法
> 来源：Research层分析（反派找茬流世情爽文）
> 适用：校园霸凌/职场/世情

## 核心定义

反派反复找茬，主角忍无可忍后反击，让反派自食恶果。

## 底层原理

"恶人自有恶人磨"。反派反复欺负人，最终会因为自己的恶行付出代价。

## 操作步骤

### Step 1：设计"找茬"场景

反派反复找茬：
- 言语羞辱
- 肢体欺负
- 栽赃陷害
- 群体霸凌

### Step 2：主角"忍"的状态

| 状态 | 表现 |
|------|------|
| 隐忍 | 不还手/不还口 |
| 退让 | 躲避/认输 |
| 被动 | 被欺负到极致 |

### Step 3：反击时刻

忍无可忍，无需再忍：
- 对方太过分
- 涉及底线
- 忍无可忍

### Step 4：反击成功

| 反击 | 结果 |
|------|------|
| 证据 | 证明清白 |
| 真相 | 揭露阴谋 |
| 报复 | 让对方自食恶果 |

## 应用公式

```
反复找茬 + 主角隐忍 + 忍无可忍 + 反击成功 = 找茬流反击法
```

## 典型案例：反派找茬流世情爽文

**找茬场景**：
- 各种小动作欺负
- 栽赃陷害
- 群体孤立

**主角隐忍**：
- 被欺负到极致
- 不反抗

**反击时刻**：
- 忍无可忍
- 揭露真相
- 让对方自食恶果

## 避坑指南

1. **找茬要有层次**：从轻到重
2. **隐忍要有铺垫**：让读者觉得憋屈
3. **反击要够狠**：让对方付出代价

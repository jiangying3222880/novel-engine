# T-037 长期隐忍复仇法

> L2 Strategy | 短篇技法
> 来源：Research层分析（君子报仇十年不晚）
> 适用：复仇/隐忍/逆袭

## 核心定义

主角隐忍多年，从最底层一步步爬上来，最终完成复仇。

## 底层原理

"君子报仇，十年不晚"。长时间的隐忍和积累，让最终复仇的爽感达到顶点。

## 操作步骤

### Step 1：设计"屈辱"起点

| 起点 | 表现 |
|------|------|
| 被欺负 | 被打/被羞辱 |
| 身份低微 | 穷/弱/没背景 |
| 被迫离开 | 被赶走/被抛弃 |

### Step 2：隐忍积累阶段

| 积累 | 内容 |
|------|------|
| 十年 | 足够长的时间 |
| 财富 | 积累金钱/资源 |
| 地位 | 从底层爬上来 |
| 人脉 | 建立关系网 |

### Step 3：复仇时机

复仇的条件：
- 时机成熟
- 对方放松警惕
- 自己足够强大

### Step 4：复仇完成

复仇方式：
- 揭露真相
- 让对方身败名裂
- 拿回自己应得的

## 应用公式

```
屈辱起点 + 十年隐忍 + 积累强大 + 时机成熟 + 复仇完成 = 长期隐忍复仇法
```

## 典型案例：君子报仇十年不晚

**屈辱起点**：
- 父亲被打断腿
- 被迫离开家乡
- 母亲早亡

**隐忍积累**：
- 十年时间
- 成为千万富翁
- 建立人脉

**复仇时机**：
- 对方儿子结婚
- 当年欺负人的都在场
- 时机成熟

**复仇完成**：
- 揭露真相
- 让对方付出代价
- 正义伸张

## 避坑指南

1. **时间要够长**：十年才有说服力
2. **积累要具体**：不只是说说，有具体描写
3. **时机要对**：关键时刻一击必杀

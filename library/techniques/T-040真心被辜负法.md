# T-040 真心被辜负法

> L2 Strategy | 短篇技法
> 来源：Research层分析（初见乍惊欢，再见已无言）
> 适用：渣男/背叛/心死

## 核心定义

主角付出真心却被渣男辜负，最终看清真相，心死后离开。

## 底层原理

"最伤人的不是不爱，是欺骗"。当发现真心被利用，伤害比不爱更深。

## 操作步骤

### Step 1：设计"真情"铺垫

主角的真心：
- 付出一切
- 毫无保留
- 信任对方

### Step 2：制造"背叛"事件

| 背叛类型 | 表现 |
|----------|------|
| 欺骗 | 从一开始就是骗局 |
| 利用 | 被当成工具 |
| 伤害 | 帮助别人伤害自己 |

### Step 3：发现"真相"时刻

| 真相 | 冲击 |
|------|------|
| 他爱的人是别人 | 心碎 |
| 你是对照组 | 愤怒 |
| 从一开始就是利用 | 绝望 |

### Step 4：心死/离开

心死的表现：
- 不再追问
- 平静离开
- 开始新生活

## 应用公式

```
真情铺垫 + 背叛事件 + 发现真相 + 心死离开 = 真心被辜负法
```

## 典型案例：初见乍惊欢，再见已无言

**真情铺垫**：
- 师生恋+地下恋
- 周年纪念日
- 纹身作为印记

**背叛事件**：
- W身份被用来陷害自己
- 纹身是嘲讽
- 他爱的人是别人

**发现真相**：
> "原来要毁掉我的人正是我的男友"
> "你那个恶心的纹身是我让承序给你纹的"

**心死离开**：
- "垃圾"（合同）
- 不再解释
- 平静离开

## 避坑指南

1. **真情要够真**：让读者也心疼
2. **背叛要够狠**：不是普通渣，是彻底利用
3. **心死要自然**：不是突然冷漠，是累积的结果

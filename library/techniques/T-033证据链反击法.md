# T-033 证据链反击法

> L2 Strategy | 短篇技法
> 来源：Research层分析（确定妻子出轨那天）
> 适用：渣男出轨/抓证据/复仇

## 驱动标注

```
【短篇驱动】
- 制造什么期待：读者想知道"证据够不够硬"+"什么时候亮出来"
- 第几段引爆：反击摊牌段（约全文60-70%处）
- 憋压到什么程度给：憋到读者"快点亮证据啊"的焦虑顶点
- 读者翻页动力：期待兑现+渣男无法狡辩的爽感

【长篇驱动】
- 本章制造什么期待：读者想知道证据收集进度
- 几章后兑现：3-5章后法庭对峙/当众摊牌
- 伏笔债务编号：H-002（证据链）
- 读者追更动力：想知道"证据够不够"+"她会不会被发现"
```

## 核心定义

用完整的证据链反击，在掌握全部证据后才摊牌，一击必杀。

## 底层原理

证据链是"硬核武器"。当渣男无法狡辩、无法反驳时，爽感达到顶点。

## 操作步骤

### Step 1：收集证据（三阶段）

| 阶段 | 证据类型 | 时间 |
|------|----------|------|
| 第一阶段 | 怀疑/观察 | 第1个月 |
| 第二阶段 | 调查/跟踪 | 第2个月 |
| 第三阶段 | 确认/鉴定 | 第3个月 |

### Step 2：核心证据

| 证据类型 | 说服力 |
|----------|--------|
| 亲子鉴定 | 100%（无法反驳） |
| 照片/视频 | 80% |
| 聊天记录 | 70% |
| 证人证言 | 60% |

### Step 3：掌握证据后的"淡定"

知道真相后不爆发：
- "没关系，不用解释"
- "你敢让我看吗？"
- 平静如水

### Step 4：一击必杀

证据甩脸：
- 亲子鉴定甩脸上
- 录像直接播放
- 渣男无法狡辩

## 应用公式

```
怀疑 → 收集证据 → 证据链完整 → 淡定应对 → 一击必杀 = 证据链反击法
```

## 典型案例：确定妻子出轨那天

**证据收集**：
- 三个月观察
- 发现儿子像"崔书杰"
- 亲子鉴定确认非亲生
- 调查崔书杰背景

**淡定应对**：
> "没关系，不用解释。"
> "你敢让我看看吗？"

**一击必杀**：
> "邓明亮，你竟然背着我跟孩子做亲子鉴定！"
> "你去洗把脸，冷静冷静重新组织一下语言"
> （亲子鉴定甩脸上）

## 证据链模板

```markdown
【证据一】亲子鉴定 → 证明非亲生
【证据二】照片/视频 → 证明出轨事实
【证据三】聊天记录 → 证明预谋
【证据四】银行流水 → 证明金钱往来
【证据五】其他 → 补充
```

## 避坑指南

1. **证据要确凿**：不能靠猜
2. **时机要对**：证据收集完整后再摊牌
3. **态度要淡定**：越淡定越爽

## 使用原则

1. **写什么题材，加载什么包**：不要写玄幻的时候加载都市神话，容易串味
2. **最多加载 1-2 个题材包**：太多会风格混乱
3. **题材包是"风格参考"，不是"写作圣经"**：学底层逻辑，不学表层设定
4. **项目级 素材池/ 更精准**：如果有具体的对标书，拆出来的内容比题材包更精准
5. **每写完一本书，可以反哺题材包**：把验证过的好方法补充进去

## 如何新增一个题材包

1. 选定 1-3 本同题材对标书
2. 按 `拆解方法论.md` 拆解
3. 提炼出该题材的：结构模式 + 文风特征 + 核心爽点类型 + 常见人物配置
4. 新建目录，放入：`_README.md` + `大纲结构.md` + `文风特征.md`（+其他必要文件）
5. 在本页登记

# 辰东式玄幻 · 大纲结构

## 定位

辰东式东方玄幻长篇结构。用于设计百万字到千万字级宏大玄幻/高武/遮天感网文。

核心不是单纯升级，而是：

> **小人物被卷入古老大局 → 在残酷修行世界中争命 → 一路揭开历史真相 → 从一域走向诸天 → 与最高位格秩序对抗。**

三条线必须并行：
- **修行线**：境界、体质、秘法、器物、战力
- **历史线**：远古真相、禁区来历、强者遗痕、断代谜团
- **人情线**：故人、师友、敌手、族群、旧约、牺牲

## 万字开局

**目标**：立出"主角缺口 + 世界异常 + 第一机缘"。

必备 5 要素：

1. **主角处于弱势或边缘位置**
   - 废柴、弃子、底层、边缘人
   - 有一个明确的"被看不起"的理由

2. **世界有一个明显反常**
   - 永夜、古棺、禁区、神秘复苏、深空异常
   - 反常不是背景板，是直接影响普通人生活的

3. **主角接触第一件古老物或第一处异常地**
   - 机缘不是天上掉下来的，是主角用某种代价换来的
   - 机缘和世界反常之间有联系

4. **出现一个小范围强者压迫**
   - 不是最终BOSS，是第一个"看得见的敌人"
   - 用来立主角的性格和底线

5. **章尾让读者知道：这不是普通冒险，而牵涉更古老的局**
   - 一个细节、一句话、一个画面
   - 点到为止，不展开

## 10 万字新手卷

**目标**：完成第一次身份跃迁。

必备 5 要素：

1. **主角获得基础修行路径或特殊能力**
   - 功法/体质/传承/金手指
   - 有明确的限制或代价

2. **第一个稳定地图**
   - 村落、宗门、学院、古地、试炼区
   - 地图有自己的规则和生态

3. **第一个明确敌手或天骄**
   - 同代最强者/敌对势力的天才
   - 和主角有明确的利益冲突

4. **第一次遗迹/秘境探索**
   - 探索中获得第一个"历史碎片"
   - 暗示世界不简单

5. **卷末完成"弱者逆斩强者"或"被大势力注意"**
   - 第一次身份跃迁的标志
   - 同时抛出下一卷的钩子

## 50 万字扩张期

**目标**：从个人争命扩成一域争锋。

必备 5 要素：

1. **地图扩大**
   - 一城到一域，一域到古路/禁区/大教
   - 每次扩大地图都要有明确的理由

2. **多个天骄/势力并列登场**
   - 不只是主角一个人开挂
   - 每个势力都有自己的天才和传承

3. **主角体质、器物或传承被部分识破**
   - 引起注意，有好处也有危险
   - 主角开始学会"藏"

4. **遗迹中的古老真相开始指向更大历史**
   - 历史线推进
   - 读者开始意识到：这不是一个简单的升级故事

5. **反派不只是坏人，而是大势力、旧秩序或禁区代理人**
   - 反派升级：从个人 → 势力 → 旧秩序
   - 对手越强大，主角越有分量

---

## 100 万字世界升级

**目标**：让世界从"修行地图"变成"历史谜局"。

必备 5 要素：

1. **多个旧伏笔回收，证明早期机缘不是偶然**
   - 前面埋的钩子开始收
   - 让读者有"原来是这样"的感觉

2. **禁区、古皇、大帝、仙、深空、轮回等高位格概念进入主线**
   - 世界观升级
   - 从"修行"升级到"论道"

3. **主角开始影响大势，而不只是被追杀**
   - 主角从棋子变成下棋人之一
   - 开始有自己的势力和追随者

4. **故人分化：有人掉队，有人黑化，有人成为后续情绪锚点**
   - 人情线推进
   - 不是所有人都能陪主角走到最后

5. **卷末最好有一次跨地图跃迁**
   - 从一域到更广的世界
   - 每次跃迁都意味着视野和格局的升级

---

## 300 万字以上

**目标**：诸天化、史诗化、终局化。

必备 5 要素：

1. **地图不再是地理概念，而是时间/维度/诸天概念**
   - 时间长河、诸天万界、不同时代
   - 格局彻底打开

2. **终极真相揭开，但真相比想象的更残酷**
   - 历史线收束
   - 不是"原来如此"，而是"怎么会是这样"

3. **主角站到了最高层，但发现上面还有更高的**
   - 修行没有止境
   - 每次以为到顶了，都发现还有更上一层

4. **大量故人回归/牺牲，情绪债集中兑现**
   - 人情线大爆发
   - 前面埋的情感债集中收

5. **终局不是简单的打BOSS，而是与一种秩序/命运/规则对抗**
   - 最终对决不是两个人打架
   - 是主角的道和旧秩序的碰撞

## 必备项目文件体系

写辰东式玄幻长篇，建议维护这些文件：

| 文件 | 用途 | 更新频率 |
|------|------|---------|
| 项目设定.md | 世界观总设定 | 偶尔更新 |
| 长线大纲.md | 全书主线走向 | 每卷更新 |
| 卷纲.md | 当前卷详细大纲 | 每卷初写 |
| 10万字单元.md | 阶段性规划 | 每10万字 |
| 角色状态表.md | 主要角色当前状态 | 每章更新 |
| 伏笔表.md | 伏笔埋/收追踪 | 每章更新 |
| 器物与遗迹表.md | 重要器物/遗迹档案 | 登场时更新 |
| 世界规则表.md | 修行体系/规则汇总 | 发现新规则时更新 |

生产级项目额外维护：
- **章尾钩子选择表.md** — 备用钩子，避免临时想
- **器物遗迹回收表.md** — 确保每件重要器物都有用
- **情绪债表.md** — 谁亏欠谁，谁承诺了什么，什么时候兑现

## 验收标准

### 大纲验收
- ✅ 是否有古老谜团？（历史线有东西可挖）
- ✅ 是否有明确修行路径？（升级线清晰）
- ✅ 是否有地图扩张路线？（格局能打开）
- ✅ 是否有强者压迫？（有明确的对手层级）
- ✅ 是否有故人与旧土情绪锚点？（人情线有重量）

### 正文验收
- ✅ 是否有天地压迫感？（位格差写出来了）
- ✅ 是否有信息差对话？（对话不是直白交代）
- ✅ 是否有位格差战斗？（战斗不只是拼数值）
- ✅ 是否有器物/遗迹历史感？（器物不只是装备）
- ✅ 章尾是否推大世界？（每章结尾都有新东西）

# 辰东式玄幻题材包

## 定位

宏大东方玄幻长篇风格。以"小人物被卷入古老大局 → 在残酷修行世界中争命 → 揭开历史真相 → 从一域走向诸天 → 与最高位格秩序对抗"为核心叙事线。

**适合写**：玄幻、修仙、高武、遮天感、诸天流、末世修仙

**核心标签**：宏大、苍凉、历史厚重感、位格差、天地压迫、禁区、古皇、天骄争锋

## 使用建议

1. **不要照搬**：学结构和节奏，不学名字和设定
2. **配合通用方法论**：雪花写作法 + 主线骨架法打底，辰东结构做题材校准
3. **选择性加载**：写大纲读大纲结构，写正文读文风特征，不要一次性全读
4. **结合对标书**：如果有具体的对标书，拆书内容放入项目级 pools/ 作为更精准的参考

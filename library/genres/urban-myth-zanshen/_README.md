## 使用建议

1. **不要复刻原作**：学结构和机制，不学角色名、组织名、专有设定
2. **重点学"日常+神话"的反差感**：这是斩神式的核心风味
3. **群像不要贪多**：先把3-4个核心角色写好，再加人
4. **节奏要快**：每章 2000-2300 字，章尾必须有钩子
5. **结合通用方法论**：群像文写作法 + 爽点设计方法论打底，斩神包做题材校准

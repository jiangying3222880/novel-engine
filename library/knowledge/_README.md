## 使用方式

1. **按需调取**：写什么题材、什么场景，调取对应的素材
2. **不要全量加载**：素材是工具书，不是教科书，需要的时候才查
3. **配合题材包**：写玄幻就调玄幻资料+神灵精怪，写都市就调动作描写+现代素材
4. **持续补充**：写的书越多，积累的素材越多，可以持续入库

---

## 扩展原则

1. **质量优先**：宁少勿滥，只放经过验证的高质量素材
2. **分类清晰**：按领域分目录，好找
3. **提炼精华**：不要把网上的大段原文直接搬进来，要提炼成可复用的形式
4. **标注来源**：如果是从某本书/某个资料提炼的，标注来源

# 市场调查（三档路由 · 快速/标准/深度）

## 用途
立项、开篇策划、连载运营、投稿商业化前，对目标题材/平台做市场核对，把"查相似题材"升级为"对齐卖点引擎的具体设计动作"。

## 三档路由

| 档位 | 触发场景 | 产出 | 用途 |
|------|---------|------|------|
| 快速 | 立项方向初选 / 导语润色 | 1 个题材方向 + 3 条市场启示 + 3 条可执行建议 | 简介/导语/开篇方向 |
| 标准 | 开篇/大纲/人设策划 | 1-2 个公开样本 + 前三章/前十章建议 | 开篇钩子/闭环/阶梯 |
| 深度 | 投稿/长篇连载/商业化改稿 | 3-5 个样本 + 来源时间/趋势/竞品对比/同质化风险/长线规划 | 商业化决策 |

## 输出格式（嫁接卖点引擎）

```
### 市场调查（档位：快速/标准/深度）
1. 题材方向：[一句话定位]
2. 市场启示：
   - [启示1（带来源样本）]
   - [启示2]
   - [启示3]
3. 对齐本书卖点的具体动作：
   - 开篇钩子：[把调查结果转成开篇钩子设计]
   - 前三章闭环：[如何让前三章自洽成一个吸引点]
   - 前十章升级阶梯：[如何逐级升级/变体，避免同质化]
4. 风险与差异点：[与同类真正差异 / 同质化风险 / 长线规划]
```

## 执行纪律
1. **样本需带来源**：公开样本标注书名/平台/观察时间，禁止编造。
2. **三档不越级**：快速档不写深度档的分析，控制 token 成本。
3. **调查服务卖点**：调查结论必须落到"开篇钩子/前三章闭环/前十章阶梯"的具体动作，不输出泛泛趋势。
4. **可证伪**：每条启示可被样本原文支撑；无法支撑的标"推测"。

## 与项目级覆盖
- 项目根 `config/identity/作者.md` 可指定"目标平台/竞品清单"，市场调查优先覆盖这些样本。

## S3 检验（读者 · 编辑）【证据层】
- **时间**：（日期）
- **输入**：正文初稿 + self-review + 状态文件
- **身份**：读者（体验通道，**先**）· 编辑（留存通道，**后**）
- **输出**：检验报告 + review_status
- **关键决策**：
  - 读者直觉：[体验反馈（弃书点/卡顿/出戏）]
  - 编辑审阅：[前100字/主角五项/连载风险/卖点落地]
  - 成因层诊断：[命中哪层 + 分数]
  - 打回分层：[表达问题 → 回 S2；**骨架问题 → 回 S1**（A-04）]
  - 修改轮次：[第N轮，单节上限 2 轮；超限升级人工]
- **指针**：检验报告全文 → `故事/reports/检验报告_第XXXX章.md`（每章 1 份，不内联）
  - ⚠️ **文件名不可改**：门禁 `verify.py` 只认 `检验报告_第(\d{4})章.md` 这一种，且**章号必须 4 位补零**。
    写成 `自检_第X章.md` / `检验报告_第1章.md` 门禁都找不到 → 落库门禁与 evidence 校验静默失效。

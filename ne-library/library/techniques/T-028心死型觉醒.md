# T-028 心死型觉醒

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（爱意消亡，与你形同陌路）
> 适用：渣男出轨/婚姻/觉醒

## 核心定义

女主从"歇斯底里"到"平静冷漠"，不是爆发式反抗，而是心死后的无声离开。

## 底层原理

最狠的报复不是吵闹，而是"不在乎"。当女主不再追问、不再争吵，渣男才会慌。

## 操作步骤

### Step 1：歇斯底里阶段

女主曾经的状态：
- 反复追问"你是不是出轨了？"
- 无数次争吵和哭泣
- 流产（极端痛苦）

### Step 2：心死时刻

某个事件让女主彻底死心：
- 看到证据（比如耳环）
- 发现"他喜欢的不是你"
- 流产后他依然不回头

### Step 3：觉醒转折

从歇斯底里到平静冷漠：
- "没关系，不用解释。"
- "你敢让我看看吗？"
- 纪念日都不记得了？

### Step 4：渣男慌了

女主不再在乎后，渣男反而慌了：
- "你一点都不在乎吗？"
- 主动解释
- 期待她的反应

## 应用公式

```
歇斯底里 → 极端痛苦 → 心死觉醒 → 平静离开 = 心死型觉醒
```

## 典型案例：爱意消亡，与你形同陌路

**歇斯底里阶段**：
- 副驾驶缝里的耳环
- 歇斯底里争吵无数次
- 闹过无数次离婚
- 流产后他依然不回头

**心死时刻**：
- 他说"苏棠跟你不一样，她很优秀"
- 她终于明白：她永远比不过那个女学生

**觉醒转折**：
> "没关系，不用解释。"
> "要不你现在给她送回去吧，不然半夜再上门的话，挺不安全的。"

**渣男慌了**：
> "你一点都不在乎吗？"

## 心死型 vs 发疯型

| 类型 | 表现 | 效果 |
|------|------|------|
| 发疯型 | 大吵大闹、撕逼 | 对方知道你在乎 |
| 心死型 | 平静冷漠、不在乎 | 对方反而慌了 |

## 写作技巧

### 平静语气
```
发疯女主："你是不是不爱我了？！"
心死女主："没关系，不用解释。"
```

### 关键对话
```
渣男：你怎么突然不吵了？
女主：我没想要你怎么样。
渣男（期待）：今天是结婚纪念日...
女主（平静）：嗯，我知道。
```

## 避坑指南

1. **要有歇斯底里铺垫**：心死的前提是曾经在乎
2. **转变要自然**：不是突然冷漠，是累积的结果
3. **渣男要慌**：不慌就没有爽感

## 配套技法

- T-020发疯文学：发疯是爆发，心死是压抑
- T-005爽点设计：渣男慌了是爽点
- T-021极致压抑法：心死需要极度压抑

# T-035 以弱博强法

> L2 Strategy | 短篇技法
> 来源：Research层分析（不要惹炮灰，她有玉玉症）
> 适用：穿书/系统/豪门/病娇

## 核心定义

主角用"弱"（如玉玉症、精神病）作为武器，让对方无法反击，自己反而获得最大利益。

## 底层原理

"会哭的孩子有奶吃"。在特定场景下，"弱者"反而拥有特权，可以用"不正常"的方式做"正常"的事。

## 操作步骤

### Step 1：设计"弱"的标签

| 标签 | 效果 |
|------|------|
| 玉玉症/抑郁症 | 自残威胁 |
| 精神病 | 砍人不犯法 |
| 精神病家族史 | 全家都要让着 |
| 绝症 | 同情分拉满 |

### Step 2：获取"筹码"

| 筹码 | 获得方式 |
|------|----------|
| 财产 | 老公愧疚转让 |
| 地位 | 全家不敢惹 |
| 权力 | 有人撑腰 |

### Step 3：利用"弱"反击

"弱者"的特权：
- 自残威胁（拿刀/跳楼）
- 发疯攻击（打/砸）
- 无理取闹（提要求）

### Step 4：让对方"背锅"

| 情况 | 结果 |
|------|------|
| 对方食物有毒 | "你喝，证明没毒" |
| 对方想欺负 | "你是不是欺负精神病" |
| 对方要赶走 | "她会死，你们负责" |

## 应用公式

```
弱标签（玉玉症） + 获取筹码（财产/地位） + 利用弱反击 + 让对方背锅 = 以弱博强法
```

## 典型案例：不要惹炮灰，她有玉玉症

**弱标签**：
- 车祸后脑部受创
- 玉玉症（抑郁症）
- 三年摆烂

**获取筹码**：
- 一半股份（老公转）
- 退役雇佣兵保护
- 太后生活

**利用弱反击**：
> "她想毒死我，羽厉"
> （打翻燕窝）
> "你们合伙欺负我"
> （拿水果刀自残威胁）

**让对方背锅**：
> "燕窝，你喝，你喝了我就信"
> （老公被迫喝下有毒的燕窝）

## 核心技巧：以毒攻毒

| 情况 | 弱者做法 | 效果 |
|------|----------|------|
| 对方下毒 | "你喝" | 对方自己喝毒 |
| 对方欺负 | "我要死" | 对方背锅 |
| 对方赶走 | "我有病" | 全家护着 |

## 避坑指南

1. **弱要有代价**：真的受创/真的有病
2. **弱要有底线**：不是无底线疯
3. **结局要正**：最后要赢

# T-045 重生复仇法（升级版）

> L2 Strategy | 短篇技法
> 来源：Research层分析（交换系统流/白蛇）
> 适用：重生/复仇/系统

## 核心定义

主角重生复仇，发现身边人早就设计好阴谋，利用主角的血/身体/价值。

## 底层原理

"最亲近的人伤你最深"。当发现丈夫、孩子都参与了阴谋，复仇的动力更强。

## 操作步骤

### Step 1：设计"阴谋"设定

| 阴谋类型 | 设定 |
|----------|------|
| 血袋型 | 丈夫的白月光需要你的血 |
| 工具型 | 你是别人的工具人 |
| 替身型 | 你只是替身的替代品 |

### Step 2：设计"重生"节点

重生回到：
- 阴谋刚开始时
- 悲剧发生前
- 关键选择前

### Step 3：设计"隐藏"机制

对方隐藏的真相：
- 蛇=白月光化身
- 孩子=别人的孩子
- 丈夫=从一开始就设计

### Step 4：设计"复仇"方式

| 复仇方式 | 表现 |
|----------|------|
| 暗中布局 | 不打草惊蛇 |
| 将计就计 | 让他们自己跳坑 |
| 揭露真相 | 让所有人知道 |

## 应用公式

```
阴谋揭露 + 重生回到过去 + 暗中布局 + 复仇成功 = 重生复仇法（升级版）
```

## 典型案例：白蛇

**阴谋设定**：
- 白蛇=丈夫的白月光化身
- 主角=血袋（被吸干精血）
- 丈夫+女儿=都是帮凶

**重生节点**：
- 生日当天收到白蛇
- 回到一切开始时

**隐藏机制**：
- 白蛇咬人=吸血的伪装
- 丈夫关心=监视
- 女儿偏爱=被收买

**复仇方式**：
- 将计就计
- 暗中布局
- 揭露真相

## 避坑指南

1. **阴谋要够黑暗**：让读者愤怒
2. **重生要有优势**：提前知道真相
3. **复仇要有节奏**：不能太快

# T-015 对白自检与题材适配

> 题材对白差异（6类） · 十八条对白自检表  
> 来源：中文写作对白口语方法总册（job-0021）

---

## 一、题材对白差异速查

不同题材对白风格差异显著，选对风格直接影响读者代入。

### 1. 男频爽文

**风格**：直给 / 结论 / 强调地位反转 / 短句狠狠落地

| 特征 | 说明 |
|------|------|
| 句式 | 短句为主，斩钉截铁 |
| 节奏 | 快攻快防，不拖泥带水 |
| 信息密度 | 高，不废话 |
| 常见句式 | 命令句/截断句/反问句 |
| 情绪 | 直接，不藏着掖着 |

**示例**：
> "滚。"  
> "你知道我是谁吗？"  
> "给你三秒钟考虑。"

### 2. 女频成长/情感线

**风格**：情绪更细 / 留白更多 / 暧昧与误解靠话里没说满的部分

| 特征 | 说明 |
|------|------|
| 句式 | 中句为主，带情绪波动 |
| 节奏 | 先慢后快，或先试探后爆发 |
| 信息密度 | 故意留白，不说满 |
| 常见句式 | 悬空句/反说/借事说人 |
| 情绪 | 细腻，口是心非多 |

**示例**：
> "我又没让你等。"（其实很在意）  
> "……随便你。"（不是真的随便）  
> "你今天回来得挺早。"（你去哪了？）

### 3. 古装权谋

**风格**：句短 / 少废话 / 多判断句 / 多留半句 / 借礼借规矩借程序发难

| 特征 | 说明 |
|------|------|
| 句式 | 极短判断句为主 |
| 节奏 | 慢压，不急不躁 |
| 信息密度 | 每句都有信息，不能错过 |
| 常见句式 | 命令句/悬空句/明问暗查 |
| 潜台词 | 极高密度，几乎每句话都有话外音 |

**示例**：
> "按祖制，这事该由宗正定夺。"（你越权了）  
> "臣以为，此事还需从长计议。"（我反对但不明说）  
> "来人，送林大人出宫。"（你走吧，别再说了）

### 4. 悬疑罪案

**风格**：少抒情 / 多追问 / 多反证 / 多"你为什么知道这个"式台词

| 特征 | 说明 |
|------|------|
| 句式 | 短追问句为主 |
| 节奏 | 快攻快防，像审问 |
| 信息密度 | 极高，每个问题都挖信息 |
| 常见句式 | 追问句/反问句/截断句 |
| 情绪 | 冷静克制，但压迫感强 |

**示例**：
> "你当时在哪？"  
> "你怎么知道这个？"  
> "再说一遍。"  
> "我没有问你信不信，我问你为什么。"

### 5. 喜剧/搞笑

**风格**：短 / 快 / 反差强 / 包袱不解释太长

| 特征 | 说明 |
|------|------|
| 句式 | 极短，越短越好 |
| 节奏 | 超快，像相声捧逗 |
| 反差 | 语意反差/语气反差/身份反差 |
| 常见句式 | 回刺句/截断句/反问句 |
| 禁忌 | 解释包袱，超过三秒不好笑 |

**示例**：
> "你这是侮辱我。"  
> "对，我还要踩两下。"  
> "我就客气客气，你还喘上了。"

### 6. 甜宠/暧昧

**风格**：试探 / 顶嘴 / 口是心非 / 借题发挥 / 一句冷话后补一个动作

| 特征 | 说明 |
|------|------|
| 句式 | 中短句为主，带情绪起伏 |
| 节奏 | 试探→顶嘴→暧昧升级 |
| 信息密度 | 低，主要给情绪 |
| 常见句式 | 反说/话留半截/借事说情 |
| 动作 | 重要，冷话后要有动作暴露真心 |

**示例**：
> "我又没想跟你一起吃饭。"（说完坐下了）  
> "……你脸怎么红了？"（明知故问）  
> "行吧，那我就勉强陪你走走。"（说完主动拉了手）

## 二、十八条对白自检表

写完一场戏后，逐条检查。

### 功能层（1-6）

- [ ] **1.** 这场戏的主功能只有一个吗？（推进情节/揭露信息/改变关系/升级冲突……）
- [ ] **2.** 谁主动谁被动，清不清楚？
- [ ] **3.** 每个角色说话像不像他自己？（对照characters.md基线）
- [ ] **4.** 有没有一句意思说两遍？（删掉重复）
- [ ] **5.** 有没有废解释？（能删且不影响理解的解释句全部删掉）
- [ ] **6.** 台词有没有带动作？（对照第五层言语动作）

### 变化层（7-10）

- [ ] **7.** 这场戏有没有让局面发生变化？（关系/信息/情绪/局势）
- [ ] **8.** 尾句有没有钩子或回响？（读者为什么要继续看？）
- [ ] **9.** 这场戏能不能直接拍？（如果脱离场景描述依然清晰可演，则对白够好）
- [ ] **10.** 适配目标平台吗？（男频爽文≠女频情感线≠悬疑节奏）

### 形式层（11-18）

- [ ] **11.** 单句单义？（一句话只做一件事）
- [ ] **12.** 先反应后信息？（真人说话先给反应）
- [ ] **13.** 情绪越强句子越短？（惊/怒/怕/恨→句子变短）
- [ ] **14.** 去同义重复？（"别逞强，别硬撑"→"别硬撑"）
- [ ] **15.** 少解释多攻防？（"你误会了"→"你只看见结果"）
- [ ] **16.** 用词带身份？（身份决定词汇范围）
- [ ] **17.** 口语允许不完整？（犹豫/断句/不说完=真实）
- [ ] **18.** 一轮对话不要说死？（好戏靠来我往，不靠一人讲完）

## 三、题材 × 对白风格匹配

| 题材 | 推荐句长 | 推荐节奏 | 推荐句式 | 潜台词密度 |
|------|---------|---------|---------|-----------|
| 男频爽文 | 短句 | 快攻快防 | 命令/截断/反问 | 低 |
| 女频情感 | 中句 | 先松后炸 | 反说/悬空/借事 | 高 |
| 古装权谋 | 极短句 | 慢压 | 判断/悬空/明问暗查 | 极高 |
| 悬疑罪案 | 短句 | 快攻 | 追问/反证/截断 | 中 |
| 喜剧搞笑 | 极短句 | 超快 | 回刺/反差 | 低 |
| 甜宠暧昧 | 中短句 | 试探顶嘴 | 反说/话留半截 | 高 |

## 五、自检使用说明

**什么时候用**：
- 写完一场对白后，逐条对照
- 重写前先过一遍功能层（1-6）
- 修改时优先处理变化层（7-10）

**评分参考**：
- 18/18 全绿：完美对白
- 12-17：优秀，需要细节打磨
- 6-11：及格，有明显硬伤
- 0-5：重写这场戏

# T-031 爱意骗局法

> L2 Strategy | 短篇技法
> 来源：Research层分析（被假爱骗走七年积蓄）
> 适用：渣男/阴谋/复仇

## 核心定义

对方假爱真骗，多年陪伴是一场彻头彻尾的骗局，最终真相揭露。

## 底层原理

假爱是最恶毒的背叛。"七年陪伴"让读者以为有真情，结果发现全是算计，愤怒感爆棚。

## 操作步骤

### Step 1：设计"假爱"背景

| 要素 | 设计 |
|------|------|
| 表面 | 深情陪伴/共患难 |
| 实际 | 阴谋/算计/为他人 |
| 时间 | 至少3年以上 |

### Step 2：制造"背叛"事件

让假爱露出马脚：
- 关键时刻帮助敌人
- 偷取机密/财产
- 放火/破坏

### Step 3：揭露真相

让主角亲眼/亲耳听到真相：
- 偷听对话
- 看到证据
- 别人告知

### Step 4：复仇反击

知道真相后的反击：
- 利用对方的信任反杀
- 让对方失去一切
- 复仇完成

## 应用公式

```
七年假爱 + 关键背叛 + 真相揭露 + 复仇反击 = 爱意骗局法
```

## 典型案例：被假爱骗走七年积蓄

**假爱背景**：
- 陈静"七年陪伴"江然
- 邻居妹妹+拿出积蓄
- 表面：深情

**背叛事件**：
- 放火烧仓库
- 关键一刻破坏

**真相揭露**：
> "我爱的人是赵宏伟"
> "当年抽签输给了你"
> "那七年是无奈之选"

**复仇反击**：
- 对方试图废掉他的手
- 他反杀让对方失去一切

## 避坑指南

1. **假爱要够真**：让读者也以为有真情
2. **背叛要够狠**：不能只是小背叛
3. **复仇要够爽**：让对方付出代价

# T-032 恶人视角揭露法

> L2 Strategy | 短篇技法
> 来源：Research层分析（我在人间彷徨，寻不到你的天堂）
> 适用：悬疑/推理/真相揭露

## 核心定义

通过"恶人"（如连环杀人犯）的视角揭露真相，真相从最意想不到的人口中说出。

## 底层原理

恶人的话反而最可信。当连环杀人犯说出"第十五个人是我亲手埋的"，读者知道这是真的。

## 操作步骤

### Step 1：建立"恶人"形象

| 恶人类型 | 特点 |
|----------|------|
| 连环杀人犯 | 冷酷/专业/说实话 |
| 黑帮老大 | 重信义/说一不二 |
| 骗子 | 只骗钱/不骗感情 |

### Step 2：制造"不正常"的事件

恶人做出不符合身份的事：
- 杀人犯突然想"坦白"
- 黑帮老大维护某人
- 骗子说了真话

### Step 3：揭露真相

通过恶人之口说出真相：
- "她是我杀的第十五个人"
- "有人花两百万买她的命"
- "从她丈夫账户转出来的"

### Step 4：反转冲击

真相的冲击：
- 丈夫（男主）是凶手？
- 身边最亲密的人是幕后黑手？
- 死者身份有秘密？

## 应用公式

```
恶人形象 + 不正常行为 + 揭露真相 + 身份反转 = 恶人视角揭露法
```

## 典型案例：我在人间彷徨

**恶人形象**：
- 连环杀人犯孟淮川
- 杀了十九个人
- 专业/冷酷

**不正常行为**：
- 点名要见犯罪心理学教授
- 主动提起"第十五个人"

**揭露真相**：
> "第十五个，叫江念"
> "有人花了两百万要买她的命"
> "从她丈夫的账户转出来的"

**冲击**：
- 宋逾（丈夫）是凶手？
- 林皎皎（小三是凶手？）

## 写作技巧

### 恶人语气
```
杀人犯（平静）："她是我杀的第十五个。"
犯罪心理学教授（震惊）："你说什么？"
杀人犯："有人出钱买的命，足足两百万。"
杀人犯："这个数字，你不觉得熟悉吗？"
```

### 真相标记
```
【关键信息】
- 死者姓名
- 凶手身份
- 动机
- 证据
```

## 避坑指南

1. **恶人要够恶**：反差才够大
2. **真相要够震撼**：不能太简单
3. **要有证据支撑**：不然显得突兀

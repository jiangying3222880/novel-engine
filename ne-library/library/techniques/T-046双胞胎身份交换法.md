# T-046 双胞胎身份交换法

> L2 Strategy | 短篇技法
> 来源：Research层分析（男二上位）
> 适用：替身/身份/反转

## 核心定义

新郎找人顶替自己结婚，女主将计就计，假戏真做，选择替身而非本尊。

## 底层原理

"你找人替我，我选择替身"。当本尊发现女主选了假的，会彻底崩溃。

## 操作步骤

### Step 1：设计"交换"设定

| 交换类型 | 设定 |
|----------|------|
| 双胞胎 | 兄弟长相一样 |
| 替身术 | 灵魂交换 |
| 身份顶替 | 假扮本尊 |

### Step 2：制造"选择"场景

女主的选择：
- 知道真相
- 将计就计
- 选择替身

### Step 3：设计"反转"时刻

本尊的崩溃：
- 发现女主选了假的
- 发现自己才是多余
- 后悔莫及

### Step 4：设计"结局"

| 结局类型 | 表现 |
|----------|------|
| 女主逆袭 | 选择替身，幸福美满 |
| 本尊崩溃 | 失去一切 |
| 真相大白 | 所有人知道 |

## 应用公式

```
身份交换 + 选择场景 + 反转时刻 + 结局 = 双胞胎身份交换法
```

## 典型案例：男二上位

**交换设定**：
- 江景川和江野是双胞胎
- 哥哥找人替自己结婚
- 让弟弟顶替出席婚礼

**选择场景**：
- 女主重生，知道真相
- 将计就计
- 故意选择弟弟（江野）

**反转时刻**：
- 哥哥发现女主选了弟弟
- 弟弟才是真正的赢家
- 哥哥失去一切

**结局**：
- 女主和江野在一起
- 江景川后悔莫及
- 继承人之争反转

## 避坑指南

1. **交换要合理**：双胞胎是最好的设定
2. **选择要有智慧**：女主不是傻白甜
3. **反转要有冲击**：本尊要彻底崩溃

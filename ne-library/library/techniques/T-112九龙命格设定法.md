# T-112 九龙命格设定法 > L2 Strategy | 长篇技法 > 来源：Research层分析（大相师） > 适用：相师/玄学/悬疑/都市 > 版本：v1.0（2024年提炼）

## 一、技法概述

**核心定义**：主角天生命格非凡，被人设局盗取精气，高人相救并传授相术，十年蛰伏后出道做风水师，逐步揭露九龙局真相。

**底层原理**：
- 命格非凡：天生异象（九龙入梦）
- 阴谋设局：九龙局移花接木
- 高人相救：三爷爷救主角并传相术
- 十年蛰伏：白天上学+晚上学相术
- 出道历练：以风水师身份行走江湖

**适用题材**：相师/玄学/悬疑/都市/风水

## 二、核心结构

### 2.1 开场设定（第1章）
```
九岁：九龙入梦
↓九条蛇钻进被窝
↓被勒得快死
↓三爷爷出现救主角
↓带走主角远离
```

### 2.2 九龙局背景
```
九龙局：
- 移花接木局
- 盗取精气
- 害主角的人要做
- 需要完成最后一步
```

### 2.3 十年蛰伏线
```
十年修炼：
- 三爷爷传授相术
- 观星/筹算/风水/起卦/符咒
- 天赋异禀（半年学会十几年内容）
- 禁止和家人联系
```

### 2.4 出道历练线
```
出道条件：
- 打出"天风姤"卦象
- 以风水师身份示人
- 不能用相天相人之术
- 隐藏实力
```

## 三、操作步骤

### Step 1：设计命格设定
```
命格非凡表现：
- 九龙入梦（九条蛇）
- 天生异象
- 身体虚弱（被吸取精气）
- 智力受损（被吸取精气）
```

### Step 2：设计阴谋设定
```
九龙局：
- 移花接木局
- 害主角的人设局
- 要把精气转给女主
- 十年后完成最后一步
```

### Step 3：设计救命恩人
```
三爷爷：
- 坐轮椅的老人
- 年轻时离家出走
- 相师身份
- 传授主角相术
```

### Step 4：设计十年修炼
```
修炼内容：
- 观星
- 筹算
- 风水
- 起卦
- 符咒
- 法诀

修炼成果：
- 天赋异禀（半年学完十几年内容）
- 白天上学+晚上学相术
```

### Step 5：设计出道历练
```
出道条件：
- 打出"天风姤"卦象才能接第一桩案子
- 派规限制：不能用相天/相人之术
- 隐藏实力+以风水师身份示人
- 留意特定人物（林青霜）
```

## 四、应用公式

```
九龙命格设定法 = 命格非凡（九龙入梦）
                + 阴谋设局（九龙局）
                + 高人相救（三爷爷）
                + 十年蛰伏（修炼相术）
                + 出道历练（风水师）
```

## 六、与短篇技法的区别

| 维度 | 长篇九龙命格法 | 短篇命格法 |
|------|----------------|------------|
| 篇幅 | 235万字 | 3000字 |

## 七、变体

1. **命格设定变体**：天生异象+被设局
2. **九龙局阴谋变体**：移花接木+盗取精气
3. **高人传授变体**：高人相救+传授技能
4. **十年蛰伏变体**：修炼+隐藏实力+逐步出道
5. **相术体系变体**：观星/风水/起卦/符咒完整体系

# T-024 外弱内强反击法

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（大喜日将军让我去殉葬，我却做了太子妃）
> 适用：古代虐文/都市爽文/身份反转

## 核心定义

主角表面看起来窝囊/懦弱/废物，实际暗藏实力（谋略/武功/身份），关键时刻反击打脸。

## 底层原理

反差是爽感来源。"废物"逆袭比"强者"胜利更爽，因为读者看到了"不可能"变成"可能"。

## 操作步骤

### Step 1：设计"弱"的表面

| 类型 | 表现 |
|------|------|
| 外表 | 瘦弱/普通/不起眼 |
| 处境 | 被欺负/被嘲讽/被抢 |
| 性格 | 沉默/忍耐/不反抗 |

**要点**：要让读者觉得"这也太窝囊了"

### Step 2：埋设"强"的暗线

| 类型 | 暗线 |
|------|------|
| 身份 | 隐藏身份（太子妃/皇族/大佬） |
| 能力 | 隐藏实力（武功/医术/谋略） |
| 关系 | 隐藏靠山（大佬朋友/神秘背景） |

**要点**：不能太早暴露，要埋伏笔

### Step 3：制造"欺负"场景

经典欺负场景：
- 婚礼当天被抢婚
- 庶妹顶替身份
- 被渣男嘲讽

### Step 4：关键时刻反击

反击时机：
- 被逼到绝路时
- 对方得意忘形时
- 关键时刻（如婚礼/宴会）

反击方式：
- 亮出身份
- 展现实力
- 打脸对方

## 应用公式

```
弱表面 + 强暗线 + 欺负场景 + 反击打脸 = 外弱内强
```

## 变体

| 变体 | 弱表面 | 强实质 | 爽点 |
|------|--------|--------|------|
| 窝囊废女主 | 被抢婚 | 太子妃身份 | 身份打脸 |
| 废材赘婿 | 被嘲讽 | 大佬身份 | 打脸嘲讽者 |
| 傻子少爷 | 被欺负 | 隐藏实力 | 扮猪吃虎 |
| 替身女主 | 被顶替 | 真千金身份 | 身份揭露 |

## 典型案例：将军让我去殉葬

**弱表面**：
- 被将军抢婚给庶妹
- 被迫殉葬
- 被嘲讽"装什么"

**强暗线**：
- 原本就是将军未婚妻
- 有谋略（为将军出谋划策立功）
- 太子妃身份（更大的靠山）

**反击场景**：
- 不反抗殉葬
- 太子突然认可
- 震惊将军和庶妹

## 伏笔技巧

### 早期伏笔
```
"我看着他自信的脸，想起那年我为他出谋划策的场景..."
（暗示主角有能力）
```

### 中期暗示
```
"你当初在军营的时候不也是说脱就脱？"
（将军的话暴露主角曾经参与）
```

### 后期揭露
```
"本宫是太子妃，谁敢动我？"
（身份揭露）
```

## 避坑指南

1. **弱要够弱**：要让读者觉得憋屈
2. **强要够强**：反击时要足够爽
3. **伏笔要合理**：不能太突兀

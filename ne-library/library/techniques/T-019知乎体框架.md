# T-019 知乎体框架

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（被系统绑架的我）
> 适用：知乎风/短故事/情绪文

## 核心定义

以知乎问答体为框架的短篇写作结构，天然具有代入感和信息密度优势。

## 底层原理

知乎体让读者扮演"提问者"角色，产生天然代入感。问答结构制造信息缺口，激发好奇心。

## 操作步骤

### Step 1：设计问答式开头

| 类型 | 示例 |
|------|------|
| 体验型 | "被系统绑架是什么体验？" |
| 选择型 | "放弃救命之恩是什么感受？" |
| 结果型 | "发现老公是双胞胎是什么体验？" |

### Step 2：数字分段叙事

每个数字段落 = 一个事件/情绪高潮点：
- 1：背景/起因
- 2：发展/矛盾
- 3：高潮/反转
- 4：结局/悬念

### Step 3：第一人称内心独白

知乎体的核心是"我"的视角：
- 内心戏要足
- 情绪要外化
- 吐槽要有梗

### Step 4：悬念结尾

留钩子，让读者想看后续：
- "评论区有人说..."（引导互动）
- "未完待续"（引导追更）
- 反问式结尾（制造争议）

## 应用公式

```
知乎问答开头 + 数字分段 + 第一人称 + 悬念结尾 = 知乎体框架
```

## 模板

```markdown
问：xxx是什么体验？

1
（事件描述...内心独白...）

2
（事件发展...矛盾升级...）

3
（高潮反转...情绪爆发...）

（未完待续/有什么想说的评论区见）
```

## 变体

| 变体 | 特点 | 适用场景 |
|------|------|----------|
| 知乎体 | 问答开头+数字分段 | 情感/复仇/悬疑 |
| 豆瓣体 | 帖子格式+时间线 | 婆媳/婚姻/家庭 |
| 论坛体 | 讨论帖+回复 | 八卦/撕逼/吃瓜 |
| 微博体 | 短句+话题标签 | 热梗/反转/情绪 |

## 避坑指南

1. **开头要抓人**：第一句就要制造冲突
2. **情绪要真实**：知乎体靠情绪共鸣
3. **反转要合理**：不能为了反转而反转

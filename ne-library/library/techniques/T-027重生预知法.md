# T-027 重生预知法

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（爱若季风过境）
> 适用：重生/复仇/渣男出轨

## 核心定义

主角带着前世记忆重生，预知未来发生的事，提前布局反击。

## 底层原理

信息差是最大的武器。主角知道未来会发生什么，对方却浑然不知，这种不对称制造巨大爽感。

## 操作步骤

### Step 1：前世记忆

开场揭示主角重生的背景：
- 前世被渣男和闺蜜背叛
- 知道他们未来会做什么
- 重生回到某个关键时间点

### Step 2：预知清单

列出主角知道的事情：
| 时间 | 前世发生的事 | 现在要做的事 |
|------|--------------|--------------|
| 未来1年 | 渣男出轨闺蜜 | 提前收集证据 |
| 未来3年 | 被逼到绝路 | 提前布局 |
| 未来5年 | 惨死家中 | 改变命运 |

### Step 3：淡定反击

主角不再歇斯底里，而是：
- 知道渣男会出轨 → 平静应对
- 知道闺蜜会背叛 → 提前疏远
- 知道证据在哪 → 提前收集

### Step 4：真相揭露

用预知的证据反击：
- 揭露渣男真面目
- 揭露闺蜜的背叛
- 众人震惊：她怎么知道的？

## 应用公式

```
前世悲剧 + 重生预知 + 提前布局 + 真相揭露 = 重生预知法
```

## 典型案例：爱若季风过境

**前世记忆**：
- 老公周羡临在除夕夜陪闺蜜看日出
- 自己在家里死了都没人发现
- 渣男选了最贵的墓地，哭着说"下辈子补偿"

**预知布局**：
- 知道老公有小号 → 直接问"你敢让我看吗？"
- 知道老公精神出轨 → 平静地说"不用解释"
- 知道闺蜜会背叛 → 直接宣布"我跟你不再是朋友"

**核心爽点**：
> "周羡临，你是不是有一个小号？你敢让我看看小号发的内容吗？"
> → 对方心虚：眼神闪躲
> → 真相揭露：全是闺蜜的照片

## 写作技巧

### 淡定语气
```
前女友（歇斯底里）："你是不是出轨了？！"
重生女主（淡定）："没关系，不用解释。"
```

### 证据收集
```
重生女主：默默拍照/截图/录音
渣男：还在得意自己藏得好
```

### 真相揭露
```
女主（平静）："我知道你们会在哪年哪月发生什么。"
渣男+闺蜜：震惊！她怎么知道的？
```

## 避坑指南

1. **预知要有证据**：不是靠猜，是靠记忆
2. **反击要淡定**：越淡定越爽
3. **信息要逐步揭露**：不要一次性全部说完

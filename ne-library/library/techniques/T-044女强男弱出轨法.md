# T-044 女强男弱出轨法

> L2 Strategy | 短篇技法
> 来源：Research层分析（爱意全家桶）
> 适用：女强/出轨/追妻火葬场

## 核心定义

女主是女强人/女老板，男主是普通丈夫，女主出轨男秘书，男主从隐忍到离开。

## 底层原理

"女强男弱"的设定打破了传统性别角色，女主的背叛对男主的伤害更深。

## 操作步骤

### Step 1：设计"女强男弱"背景

| 设定 | 女强男弱 |
|------|----------|
| 女主 | 女老板/女强人 |
| 男主 | 普通员工/家庭煮夫 |
| 关系 | 女强男弱 |

### Step 2：设计"出轨"场景

女主出轨对象：
- 男秘书
- 男助理
- 年轻下属

出轨证据：
- 朋友圈官宣
- 车内发现物品
- 别人告知

### Step 3：男主"隐忍"阶段

男主的选择：
- 不想离婚
- 以为她只是玩玩
- 为了面子/孩子

隐忍表现：
- 假装没看见
- 不吵不闹
- 继续付出

### Step 4：男主"觉醒/离开"

觉醒时刻：
- 发现更大的背叛
- 被伤到极限
- 看清真相

离开方式：
- 辞职
- 离开城市
- 不再回头

## 应用公式

```
女强男弱 + 出轨男秘书 + 隐忍 + 极限 + 离开 = 女强男弱出轨法
```

## 典型案例：爱烬成空

**女强男弱**：
- 女主季雨禾：强势女老板
- 男主许然：普通丈夫

**出轨场景**：
- 朋友圈官宣："蓄谋已久，得偿所愿"
- 车内发现男秘书的球鞋
- 男秘书住女主家

**隐忍**：
- 假装没看见手机
- 不吃醋/不追问
- 继续做饭/照顾

**觉醒/离开**：
- 被丢在医院
- 不再追问
- 彻底放弃

## 变体

| 变体 | 女强 | 出轨对象 |
|------|------|----------|
| 女老板型 | 企业老板 | 男秘书 |
| 女总裁型 | 公司总裁 | 男助理 |
| 女明星型 | 女明星 | 男经纪人 |

## 避坑指南

1. **女主要够强**：让反差更大
2. **男主要有底线**：隐忍要有底线
3. **离开要干脆**：不能再回头

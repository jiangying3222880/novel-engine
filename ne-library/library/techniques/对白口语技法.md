# T-013 对白口语技法

> 九层对白模型 · 口语硬规则9条 · 对白写作七步流程  
> 来源：中文写作对白口语方法总册（job-0019）

---

## 一、九层对白模型

每场对白逐层检查，从语境到钩子。

### 第一层：语境层

先判断这场话发生在什么环境里：

- **公开场 vs 私密场**（众目睽睽 vs 单独相处）
- **安全场 vs 危险场**（和平谈判 vs 被包围审问）
- **上位对下位 vs 平位试探**（命令 vs 商量）
- **第一次见面 vs 旧怨重逢**（试探 vs 爆发）

> 语境决定角色敢不敢说真话、说多少。

### 第二层：角色层

角色要先有"说话人格"。每个角色至少定这6项：

| 项目 | 问题 |
|------|------|
| 核心欲望 | 他想要什么？ |
| 核心恐惧 | 他最怕什么？ |
| 对外形象 | 他在别人面前装什么？ |
| 真正底色 | 他实际上是什么人？ |
| 常用句式 | 他说话是什么节奏？ |
| 不会说什么 | 什么话绝对从他嘴里出不来？ |

### 第三层：关系层

同一句话，因为关系不同，质地不同：

| 关系 | 语气倾向 |
|------|---------|
| 对上 | 更试探，更礼貌，更绕 |
| 对下 | 更指令，更直接 |
| 对爱人 | 更绕，更口是心非 |
| 对仇人 | 更扎，更不客气 |
| 对陌生人 | 更礼貌防御 |

### 第四层：冲突层

冲突不是单一的，至少有5种：

| 类型 | 例子 |
|------|------|
| 利益冲突 | 钱、权、资源分配 |
| 情感冲突 | 爱、恨、背叛、不信任 |
| 性格冲突 | 价值观/做事方式不同 |
| 观念冲突 | 对错/道德/立场对立 |
| 信息冲突 | 我知道的他不知道/他知道的我不知道 |

> 一场戏通常2-3种冲突叠加。

### 第五层：言语动作层

每句话背后必须能标出**动作**，不然就是废话：

**十二个常见言语动作**：压 / 顶 / 扎 / 逼 / 试 / 拖 / 躲 / 哄 / 骗 / 截 / 稳 / 收

> "我不是那个意思。"（躲）  
> "你只看见结果。"（顶）

### 第六层：句式层

高频有效句式：

| 句式 | 效果 | 示例 |
|------|------|------|
| 命令句 | 直接施压 | "坐下。" |
| 截断句 | 打断对方节奏 | "不用解释了。" |
| 追问句 | 逼对方补充 | "然后呢？" |
| 反问句 | 否定+施压 | "你觉得我会信？" |
| 悬空句 | 话留半截 | "其实我本来想……" |
| 回刺句 | 以攻代守 | "你有什么资格说我？" |

### 第七层：节奏层

对白节奏通常有4种：

| 节奏 | 特点 | 适用场景 |
|------|------|---------|
| 快攻快防 | 短句密集，像打乒乓球 | 争执/审问/争吵 |
| 慢压慢逼 | 长句为主，控制节奏 | 权谋/威胁/谈判 |
| 先松后炸 | 前半段缓和，后半段爆发 | 情感冲突/谈判反杀 |
| 先炸后冷 | 先炸场，再冷却 | 决裂/羞辱/翻脸 |

### 第八层：回响层

好对白不能说完就没了，必须产生**回响**：

- 改变关系
- 刺激情绪
- 推出动作
- 暴露弱点
- 引出下一个问题

### 第九层：钩子层

一场戏的尾句或尾动作，要给读者一个继续看的理由：

- 事实没说完
- 人还没翻盘
- 关系要变
- 危机要落下
- 伏笔要回头

## 二、口语硬规则9条

### 规则1：单句单义

一句话只做一件事。

> "别逞强，别硬撑。"（重复同一件事）  
> ✅ "别硬撑。"

### 规则2：先反应后信息

真人说话先给反应，再给信息。

> "你回来了。"（先给反应）  
> "你回来得有点早。"（先给反应+暗藏判断）

### 规则3：情绪越强句子越短

| 情绪 | 句子特征 |
|------|---------|
| 惊 | 一两个字 + 重复："你说什么？" |
| 怒 | 短句斩钉截铁："滚。" |
| 怕 | 句子短，颤抖："别过来。" |
| 恨 | 句子短，留阴影："我记住你了。" |

### 规则4：去同义重复

> "别逞强，别硬撑。" → ✅ "别硬撑。"  
> "你一定要小心，注意安全。" → ✅ "小心点。"

### 规则5：少解释多攻防

> ❌ "你误会了，我之所以这么做，是因为……"  
> ✅ "你只看见结果。"

### 规则6：用词要带身份

王公贵族不会满口网络口头语。将军说话不爱绕弯子。

### 规则7：口语允许不完整

> "我不是那个意思，我是说……算了。"  
> 真实对话天然有犹豫、断句、不说完。

### 规则8：一轮对话不要说死

好戏靠来我往，不靠一人讲完。

### 规则9：关键台词要可拆镜

写台词时要能直接对应：

- 谁说的
- 说时在做什么
- 对方什么反应
- 话落后局面怎么变

## 三、对白写作七步流程

### 第一步：写场景目标

这场戏**角色想达成什么**？想得到/想避免/想揭露/想改变？

### 第二步：写双方欲望和恐惧

- 我的核心欲望是什么？
- 我的核心恐惧是什么？
- 对方想要什么？
- 对方怕什么？

### 第三步：给出3-5个节拍

一场好对白有节奏，有起落：

| 节拍 | 内容 |
|------|------|
| 开场撞击 | 先给一个撞击/挑衅/意外 |
| 第一轮攻防 | 双方亮出基本立场 |
| 信息翻点 | 出现新信息/意外/反转 |
| 情绪升级 | 冲突加剧 |
| 尾句钩子 | 给读者一个继续看的理由 |

### 第四步：先写动作，再写对白

先写**这场戏里人物在做什么**（动作/表情/姿势），再让对白跟上动作。

> 动作决定对白的质地：打斗中说不了情话。

### 第五步：给每句台词打标签

每句台词标出言语动作（压/顶/扎/逼/试/拖/躲/哄/骗/截/稳/收）。

### 第六步：压缩

- 解释句 → 结论句
- 复述句删掉
- 能用动作表达的不用台词

### 第七步：回收检查

对照十八条自检表（T-015）逐条过。

## 四、与anti-ai四大转换的互补关系

| anti-ai原则 | 层级 | T-013补充 |
|------------|------|----------|
| 原则一：心理→动作 | 表层形式 | 第五层言语动作 |
| 原则二：独白→互动 | 互动结构 | 第八层回响层 |
| 原则三：对称→不对称 | 节奏差异 | 第七层节奏层 |
| 原则四：静态→动态 | 动态变化 | 第九层钩子层 |

> anti-ai四大转换解决"形式问题"；T-013解决"内容深度问题"。

# T-043 无限次背叛法

> L2 Strategy | 短篇技法
> 来源：Research层分析（多次出轨后悔流）
> 适用：渣男/出轨/追妻火葬场

## 核心定义

渣男无限次背叛，主角一次次原谅，最终彻底离开。

## 底层原理

"原谅"是有极限的。当背叛超过某个阈值，任何原谅都无意义。

## 操作步骤

### Step 1：设计"背叛循环"

| 循环 | 表现 |
|------|------|
| 背叛 | 出轨/伤害 |
| 求原谅 | 甜言蜜语 |
| 原谅 | 心软 |
| 再背叛 | 再次伤害 |

### Step 2：设计"原谅理由"

主角每次原谅的原因：
- 还爱他
- 为了孩子
- 相信他会改
- 没有退路

### Step 3：设计"极限时刻"

| 极限类型 | 表现 |
|----------|------|
| 身体极限 | 被打/受伤 |
| 心理极限 | 心死了 |
| 尊严极限 | 被踩在脚下 |
| 信任极限 | 再也不信 |

### Step 4：彻底离开

离开后的状态：
- 不再回头
- 开始新生活
- 渣男后悔

## 应用公式

```
背叛 → 求原谅 → 原谅 → 再背叛 → 极限 → 彻底离开 = 无限次背叛法
```

## 典型案例：多次出轨后悔流

**背叛循环**：
- 多次出轨
- 每次求原谅
- 主角每次原谅
- 直到极限

**极限时刻**：
- 心彻底死了
- 不再相信
- 彻底离开

## 避坑指南

1. **背叛要有升级**：每次要比上次更过分
2. **原谅要有理由**：让读者理解为什么原谅
3. **离开要有力量**：不是崩溃，是清醒

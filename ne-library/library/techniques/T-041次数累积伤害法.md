# T-041 次数累积伤害法

> L2 Strategy | 短篇技法
> 来源：Research层分析（结婚三年取消领证18次）
> 适用：渣男/出轨/追妻

## 核心定义

通过次数的累积展现伤害，从第一次到最后一次，每一次都是伤害的叠加。

## 底层原理

数字的累积有强大冲击力。"第18次"比"很多次"更有震撼力。

## 操作步骤

### Step 1：设计"次数"

| 次数类型 | 设计 |
|------|------|
| 取消领证 | N次 |
| 出轨 | N次 |
| 放鸽子 | N次 |
| 受伤 | N次 |

### Step 2：每次都有"理由"

渣男每次都有借口：
- "她是我徒弟"
- "她需要我"
- "下次一定"
- "特殊情况"

### Step 3：数字累积

从1到N，逐渐累积：
- 第1次：原谅
- 第10次：麻木
- 第N次：离开

### Step 4：离开时刻

离开的瞬间：
- 不再追问
- 平静接受
- 头也不回

## 应用公式

```
第1次（原谅） + 第10次（麻木） + 第N次（离开） = 次数累积伤害法
```

## 典型案例：结婚三年取消领证18次

**次数累积**：
- 婚礼三年，领证18次没成功
- 每次都有理由（徒弟/沈灵溪）
- 第18次依然放鸽子

**离开时刻**：
> "不用了纪尘，我已经辞职，马上飞往巴黎"
> 关机，登机

## 数字的力量

| 数字 | 效果 |
|------|------|
| 第1次 | 可以原谅 |
| 第10次 | 开始麻木 |
| 第18次 | 彻底死心 |
| N次 | 离开 |

## 避坑指南

1. **次数要有代表性**：18次比3次更有冲击力
2. **每次要有具体场景**：不能只是数字
3. **最后一次要有标志性**：离开的瞬间要震撼

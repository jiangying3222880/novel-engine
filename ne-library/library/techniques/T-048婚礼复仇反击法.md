# T-048 婚礼复仇反击法

> L2 Strategy | 短篇技法
> 来源：Research层分析（反派强人设世情）
> 适用：婚礼/闺蜜背叛/复仇

## 核心定义

婚礼上被闺蜜/反派当众爆料，主角冷静应对，等对方说完再反击。

## 底层原理

"你说的越多，漏洞越多"。让对方先把所有脏水泼完，再一一反击，让对方自食恶果。

## 操作步骤

### Step 1：设计"爆料"场景

| 爆料类型 | 内容 |
|----------|------|
| 假爆料 | 完全是编造的 |
| 半真半假 | 有真有假 |
| 选择性爆料 | 只说对自己有利的 |

### Step 2：主角"冷静"应对

冷静的方式：
- 不解释
- 不反驳
- 不哭闹
- 只是看着

### Step 3：等对方"说完"

让对方说够：
- 等待对方把所有爆料说完
- 记录每一句话
- 收集所有漏洞

### Step 4：一一"反击"

反击方式：
- 用证据打脸
- 揭露对方真相
- 让对方自食恶果

## 应用公式

```
爆料场景 + 冷静等待 + 对方说完 + 反击成功 = 婚礼复仇反击法
```

## 典型案例：反派强人设世情

**爆料场景**：
- 闺蜜林笑在婚礼上爆料
- "苏晚大学在夜总会坐台"
- "还得过那种病"

**冷静应对**：
> "你继续。"
> 一言不发
> 只是看着

**反击时刻**：
- 收集所有爆料
- 等对方说完
- 证据打脸

## 关键台词

| 场景 | 台词 |
|------|------|
| 冷静 | "你继续。" |
| 等够 | "我不急，你慢慢说。" |
| 反击 | "你说的每一句话，我都有证据。" |

## 避坑指南

1. **冷静要彻底**：不能中途爆发
2. **等待要有耐心**：让对方说够
3. **反击要精准**：针对每一个漏洞

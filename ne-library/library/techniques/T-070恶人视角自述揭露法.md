# T-070 恶人视角自述揭露法
> L2 Strategy | 短篇技法
> 来源：Research层分析（恶人视角/我不肯拿退休金给妻子用）
> 适用：恶人视角/第一人称/揭露

## 核心机制
以"恶人"的第一人称视角叙述，让读者亲眼看到他的自私和无情，揭露真相。

## 适用场景
- 恶人视角
- 第一人称
- 婚姻矛盾

## 设计要素
1. **恶人自述**：以恶人的角度叙述，不美化
2. **内心独白**：恶人觉得自己没错
3. **读者共情**：读者能看到恶人的自私
4. **对比效果**：恶人的叙述vs事实真相

## 核心创意
让恶人自己揭露自己——读者不需要别人来告诉谁是坏人

## 与T-032恶人视角揭露法的区别
- T-032：通过恶人之口（杀人犯）说出别人的真相
- T-070：通过恶人自述揭露自己的恶

# 期待感技法

> 来源：龙空论坛写作培训 · 期待感（job-0038）
> 定位：L2 Strategy 层 · 支撑 C-004（冲突是引擎）
> 上游：高潮突转技法库（T-010） / 爽点设计方法论（T-005）

---

## 核心原理

> **期待感 = 读者追读的核心驱动力**
>
> "引人入胜"的核心：
> - **胜** = 小说的高潮（小结局 / 大结局）
> - **引** = 引起读者的好奇感、期待感、追看欲望
> - 读者没有追看欲望 → 小说没有继续写下去的意义

---

## "引"字四法

| # | 技法 | 操作要点 | 案例 |
|---|-----|---------|------|
| 1 | **伏笔提醒** | 埋下伏笔后要不断提醒读者进展 | 主角被灭门后，定期提醒"他正在修炼，日后可报仇" |
| 2 | **连环伏笔** | 场景结束前预埋下一场景伏笔，一环扣一环 | 网游副本：打完当前BOSS → 出现下一个 → 更大BOSS |
| 3 | **误导诱导** | 让读者产生错误判断，结局相反却顺理成章 | 作者暗示A是坏蛋，最后A是好人，B才是真凶 |
| 4 | **预给好处** | 先给一块糖，告诉读者还有更多 | 得到宝物后继续探险，读者期待更多收获 |

## 技法一：伏笔提醒（吊驴草手法）

> 核心比喻：**吊在驴面前的草**——驴想吃草但吃不到，会一直往前走。
>
> 读者就像那头驴，作者不断告诉他们"就快吃到草了"，他们就一直追读。

### 高手 vs 新手的唯一区别

| | 高手 | 新手 |
|---|---|---|
| 埋伏笔后 | 定期提醒读者，主角快成功了 | 丢一边不管，直等最后揭开 |
| 伏笔激活频率 | 每1-2个场景提醒一次 | 从头到尾零提醒 |
| 效果 | 读者持续追看，期待感强 | 读者忘记伏笔，期待感弱 |

### 操作规则

1. **埋下伏笔时**：明确告诉读者"这个伏笔有多重要"（主角的仇恨/任务/目标）
2. **情节推进时**：每1-2个场景，定期提醒读者伏笔进展（"主角离复仇更近了一步"）
3. **高潮前**：最后一次强化提醒，让读者"憋不住"想知道结果

## 技法二：连环伏笔（副本结构）

> 来自网游副本 + 连环任务的叙事化应用。

### 公式

```
场景A（高潮伏笔）→ 场景B（伏笔A兑现 + 场景C伏笔埋设）→ 场景C（伏笔B兑现 + …）
```

### 操作要点

1. **每个场景结束时**：埋设下一个场景的伏笔（不能凭空跳场景）
2. **当前场景高潮**：读者因为有之前伏笔的铺垫，期待值更高
3. **副本升级**：每个场景的挑战/收获都要比前一个更大

### 案例

> 配角生病 → 需要找医生（伏笔A）→ 需要药物一（伏笔B）+ 药物二（伏笔C）
> → 主角找药物一（小爽）→ 途中得到药物二线索 → 找药物二（中爽）→ 见到医生（大爽）

## 技法三：误导诱导（情理之中意料之外）

> 核心：让读者"以为"某件事会发生，当相反的事发生时，冲击力更强。

### 操作步骤

1. **建立预期**：在高潮前，让读者相信"A是坏人/ B事件会发生"
2. **维持预期**：通过叙述不断强化这个错误预期
3. **揭晓真相**：真相与预期相反，但逻辑自洽

### 效果

> 读者参与了"推理"，当推理被证明错误但又合情合理时 → **参与感 + 意外感 = 更强的突转冲击**

---

## 技法四：预给好处（先给糖手法）

> 公式：**已满足的期待 + 新的更大期待 = 持续追读**

### 操作步骤

1. 设定一个重要目标（宝物/技能/地位）
2. 让主角提前获得一部分（让读者满足）
3. **同时告知**：还有更多在等着（让读者期待）
4. 主角继续努力 → 更大的收获

### 效果

> 给读者一块糖 = 建立信任（作者说话算数）
> 告诉还有更多 = 强化期待（读者愿意继续等）

## 期待感自检表

- [ ] 我埋设的伏笔，多久之后提醒读者一次？（建议每1-2个场景提醒一次）
- [ ] 读者是否记得主角的目标/仇恨/任务？（不记得 = 伏笔失效）
- [ ] 每个场景结尾是否预埋下一个场景的伏笔？（不能凭空跳场景）
- [ ] 有没有在读者预期满足后，再给一个更大的惊喜？
- [ ] 有没有利用误导诱导让读者参与预判？（增强了突转的冲击力）
- [ ] 主角是否在"吊驴草"效应下持续推进？（读者知道"快吃到草了"）

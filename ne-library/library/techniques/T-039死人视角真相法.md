# T-039 死人视角真相法

> L2 Strategy | 短篇技法
> 来源：Research层分析（真相大白死人文学）
> 适用：死人文学/悬疑/真相揭露

## 核心定义

主角死后以旁观者视角看到真相，真相比生前更清晰。

## 底层原理

死后视角让主角看清生前看不清的真相，比活着时更清醒。

## 操作步骤

### Step 1：设计"死因"

| 死因 | 类型 |
|------|------|
| 被杀 | 他杀/意外 |
| 自杀 | 被逼无奈 |
| 病死 | 绝症/被害 |

### Step 2：死后视角

主角以灵魂/旁观者视角：
- 看到身边人的反应
- 看到真相
- 看到阴谋

### Step 3：真相揭露

| 真相 | 内容 |
|------|------|
| 凶手 | 谁是真凶 |
| 动机 | 为什么杀我 |
| 阴谋 | 完整的真相 |

### Step 4：结局处理

| 结局 | 类型 |
|------|------|
| 复仇 | 死后复仇成功 |
| 真相大白 | 世人知道真相 |
| 释然 | 看清一切，放下 |

## 应用公式

```
死因 + 死后视角 + 真相揭露 + 结局 = 死人视角真相法
```

## 典型案例：真相大白死人文学

**死后视角**：
- 以灵魂视角旁观
- 看到活着时看不清的真相
- 看到身边人的真实嘴脸

**真相揭露**：
- 谁是凶手
- 动机是什么
- 背后的阴谋

## 避坑指南

1. **死因要合理**：不是无故死亡
2. **真相要震撼**：比想象的更黑暗
3. **结局要有力**：真相大白是爽点

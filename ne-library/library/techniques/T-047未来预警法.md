# T-047 未来预警法

> L2 Strategy | 短篇技法
> 来源：Research层分析（跨越时空/十年后邮件）
> 适用：预警/预知/复仇

## 核心定义

收到来自未来的信息/警告，提前预知悲剧发生，有机会改变命运。

## 底层原理

"如果能提前知道未来"。信息差是最大的武器，当你知道未来会发生什么，就能提前布局。

## 操作步骤

### Step 1：设计"预警"来源

| 来源类型 | 设定 |
|----------|------|
| 未来邮件 | 十年后的自己发来 |
| 系统提示 | 收到未来的信息 |
| 预言 | 预知能力 |
| 遗书 | 临死前的警告 |

### Step 2：设计"预警"内容

预警的内容：
- 他会出轨
- 她会害你
- 你会死
- 所有人都在骗你

### Step 3：设计"验证"过程

验证预警真假：
- 观察对方行为
- 收集证据
- 确认预言

### Step 4：设计"改变"行动

改变命运的方式：
- 提前布局
- 将计就计
- 主动出击

## 应用公式

```
预警来源 + 预警内容 + 验证过程 + 改变行动 = 未来预警法
```

## 典型案例：跨越时空

**预警来源**：
- 十年后的自己发来邮件
- 来自未来的警告

**预警内容**：
> "按你那边的时间线，裴澈出轨沈雨棠已经一年了"
> "所有人包括母亲都知道"
> "婚后他每月给我一千块，给她转十万"

**验证过程**：
- 发现订婚钻戒是假的
- 发现母亲在帮忙
- 发现所有人都在骗自己

**改变行动**：
- 联系父亲
- 准备离开
- 改变命运

## 预警工具箱

| 工具 | 适用场景 |
|------|----------|
| 邮件 | 跨越时空的警告 |
| 系统 | 重生/系统文 |
| 预言 | 玄幻/仙侠 |
| 遗书 | 死后复仇 |

## 避坑指南

1. **预警要具体**：不能只是模糊的警告
2. **验证要有证据**：让读者相信
3. **改变要有力量**：改变命运是爽点

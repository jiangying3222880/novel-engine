# T-115 神仙下凡营业法 > L2 Strategy | 长篇技法 > 来源：Research层分析（被迫营业后团宠大神爆红娱乐圈） > 适用：娱乐圈/沙雕/团宠/神仙下凡 > 版本：v1.0（2024年提炼）

## 一、技法概述

**核心定义**：神仙下凡追回被偷商品，被迫营业当明星，沙雕爆笑风格，怼天怼地怼空气，把求生综艺玩成吃吃喝喝。

**底层原理**：
- 神仙下凡：混沌灵气化身的神
- 追商品：魔灵偷走商品卖给了不该卖的人
- 被迫营业：神魂投胎当明星
- 沙雕风格：怼人怼到底
- 团宠属性：被各方团宠

**适用题材**：娱乐圈/沙雕/团宠/神仙下凡

## 二、核心结构

### 2.1 开场设定（第1章）
```
伏锦是混沌灵气化身的神
↓开店什么都卖
↓商品被魔灵偷走
↓被迫下凡追商品
↓神魂投胎成宓锦
```

### 2.2 娱乐圈线
```
娱乐圈线：
- 宓锦隐瞒身份当明星
- 三年没追回商品
- 惹下一堆烂摊子
↓神仙亲自出马
↓被迫营业
```

### 2.3 沙雕反击线
```
沙雕反击：
- 把求生综艺玩成吃吃喝喝
- 把穷游综艺玩成富游
- 怼天怼地怼空气
- 各方团宠
```

## 三、操作步骤

### Step 1：设计神仙设定
```
神仙设定：
- 混沌灵气化身
- 开店什么都卖
- 捉弄其他神仙
- 被迫下凡
```

### Step 2：设计追商品任务
```
任务设定：
- 商品被魔灵偷走
- 卖给了素质不过关的人
- 需要退货或换货念头
- 抽出神魂下凡追
```

### Step 3：设计被迫营业
```
营业设定：
- 神魂投胎成宓锦
- 隐瞒身份当明星
- 三年没追回商品
- 神仙亲自出马
```

### Step 4：设计沙雕风格
```
沙雕风格：
- 把求生综艺玩成吃吃喝喝
- 把穷游综艺玩成嘉宾富游导演穷游
- 怼天怼地怼空气
- 各种神操作
```

## 四、应用公式

```
神仙下凡营业法 = 神仙下凡（混沌灵气化身）
                + 追商品任务（魔灵偷走商品）
                + 被迫营业（当明星追商品）
                + 沙雕风格（怼天怼地）
                + 团宠属性（各方团宠）
```

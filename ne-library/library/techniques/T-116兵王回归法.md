# T-116 兵王回归法 > L2 Strategy | 长篇技法 > 来源：Research层分析（超级兵王） > 适用：兵王/特种兵/都市/雇佣兵 > 版本：v1.0（2024年提炼）

## 一、技法概述

**核心定义**：雇佣兵世界的王者回归都市，刀削脸庞+浅浅疤痕+痞帅气质，从飞机劫机事件开始，逐步揭露身份。

**底层原理**：
- 兵王人设：狼牙雇佣军首领
- 八年回归：十七岁离开→八年回归
- 痞帅气质：痞痞的可爱
- 身份反差：外表土气实则王者
- 打脸模式：扮猪吃虎

**适用题材**：兵王/特种兵/都市/雇佣兵

## 二、核心结构

### 2.1 开场设定（第1章）
```
叶谦坐飞机回国
↓八年离开
↓穿着土气（洗白T恤+迷彩裤）
↓被西装中年人鄙视
↓劫机事件
```

### 2.2 身份揭露线
```
叶谦身份：
- 狼牙雇佣军首领
- 狼王
- 八年兵王生涯
- 各国元首头疼的兵王
```

### 2.3 打脸模式
```
打脸模式：
- 中年人鄙视→被匪徒打
- 叶谦藏匕首→出手解决劫机
- 不留名→低调离开
```

```

```
兵王回归法 = 兵王人设（狼牙首领）

# T-107 赘婿归来法

> L2 Strategy | 长篇技法
> 来源：Research层分析（女神的超级赘婿）
> 适用：都市/豪门/长篇（50万字+）

## 核心定义

主角以"废物赘婿"身份隐忍三年，三年期满/母亲遗言到期后，展露真实身份和能力。

## 底层原理

"憋压释放"的极致形式：
- **三年隐忍**：观众和角色都知道主角在装
- **到期爆发**：身份揭露有明确时间节点
- **身份落差**：废物赘婿 → 至高存在

## 操作步骤

### Step 1：设计隐忍原因

| 隐忍原因 | 说服力 |
|----------|----------|
| 母亲遗言 | 亲情羁绊，最常用 |
| 家族打压 | 不得不藏拙 |
| 妻子保护 | 爱情羁绊 |
| 高人指点 | 师门规矩 |

### Step 2：设计废物人设

| 废物表现 | 观众期待 |
|----------|----------|
| 被岳父岳母骂 | "等我摊牌" |
| 被小舅子欺负 | "让你们后悔" |
| 被妻子冷落 | "她会后悔的" |
| 被丈人嫌弃 | "狗眼看人低" |

### Step 3：设计真实身份

| 真实身份 | 爽感强度 |
|----------|----------|
| 顶级家族少爷 | 强（家族对决） |
| 绝世神医 | 中（专业碾压） |
| 战神归来 | 强（武力碾压） |
| 隐形富豪 | 中（财富碾压） |

### Step 4：设计触发事件

| 触发事件 | 爽感来源 |
|----------|----------|
| 三年之期到了 | 明确时间节点 |
| 母亲遗言曝光 | 情感爆发 |
| 妻子家族遇难 | 英雄救美 |
| 前女友出现 | 打脸时刻 |

## 典型结构

```
第1章：三年之期已到，祭拜母亲
第2-5章：废物人设日常，被欺负
第6-10章：触发事件，身份即将揭露
第11-20章：妻子家族遇难，主角出手
第20-50章：赘婿身份反转，打脸所有人
50章+：真实身份上线，家族对决
```

## 变体分类

| 变体 | 特点 | 爽感来源 |
|------|------|----------|
| 战神赘婿 | 武力最强 | 拳头说话 |
| 神医赘婿 | 医术无敌 | 救命碾压 |
| 豪门赘婿 | 家族回归 | 权力碾压 |
| 隐世赘婿 | 隐藏身份 | 神秘碾压 |

## 核心爽点

1. **"三年之期"宣言**："我，不想再当废物了！"
2. **废物期憋屈**："让你们欺负我"
3. **身份揭露**："他竟然是..."
4. **打脸连续剧**："跪下！"

## 避坑指南

1. **废物人设要真实**：不能太假，要让读者觉得"忍不了"
2. **憋屈要适度**：不能太憋，否则读者弃书
3. **揭露要震撼**：身份反差要够大
4. **打脸要连贯**：连续打脸更爽

## 与T-016身份反差开场法的区别

| 技法 | 核心 | 时间线 |
|------|------|--------|
| T-016身份反差 | 表面vs实际身份 | 开场即反差 |
| T-107赘婿归来 | 废物→暴露 | 有憋压期 |

## 配套技法

- T-002开篇钩子："三年之期"震撼开场
- T-003憋压三段式：憋→压→放情绪节奏
- T-005爽点设计：打脸高潮设计

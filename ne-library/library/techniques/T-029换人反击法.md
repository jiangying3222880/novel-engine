# T-029 换人反击法

> L2 Strategy | 短篇技法
> 来源：Research层分析（换亲私生子后，未婚夫悔疯了）
> 适用：悔婚/追妻/打脸

## 核心定义

当男主渣时，女主不哭不闹，直接选择另一个男人（通常是男主最讨厌的人），让男主悔疯。

## 底层原理

"得不到的永远在骚动"。当女主选择离开/选择别人，男主才发现她有多重要。

## 操作步骤

### Step 1：渣男作死

男主渣到极致：
- 七次逃婚
- "她哪儿值这么多钱？"
- 陪小青梅看电影，放女主鸽子

### Step 2：女主不哭不闹

女主的选择：
- "这个婚，我不结了。"
- 不是求他回来
- 不是大吵大闹

### Step 3：换人反击

选择男主最讨厌的人：
- 私生子弟弟
- 竞争对手
- 一直被她忽视的人

### Step 4：男主悔疯

渣男发现女主真的不要他了：
- "你确定选他？"
- "你确定？"
- 疯狂求复合

## 应用公式

```
渣男作死 + 女主离开 + 选择别人 + 渣男悔疯 = 换人反击法
```

## 典型案例：换亲私生子后，未婚夫悔疯了

**渣男作死**：
> "她哪儿值这么多钱？"
> "你信不信，我路边随便捡块石头都能把她哄得服服帖帖。"

**女主反击**：
> "我嫁谁，谁就是慕家的继承人。这话还算数吗？"

**换人选择**：
- 不选渣男慕斯年
- 选择：慕景（渣男最厌恶的私生子弟弟）

**渣男悔疯**：
- 七次逃婚的女神被弟弟娶走
- 继承人位置也丢了
- 彻底慌了

## 换人选择类型

| 换人类型 | 效果 |
|----------|------|
| 换私生子 | 打脸渣男身份歧视 |
| 换情敌的人 | 直接报复 |
| 换渣男敌人 | 强强联合 |
| 换更好的人 | 直接超越 |

## 写作技巧

### 淡定宣言
```
渣男（得意）：你等我哄好卿卿就回来~
女主（平静）：我不需要你回来了。
渣男（愣住）：你说什么？
女主：我说，这个婚，我不结了。
```

### 换人场景
```
女主看向人群中那个男人："我嫁谁，谁就是继承人。"
渣男（震惊）：你选他？！他是我最讨厌的人！
女主（微笑）：正好。
```

## 避坑指南

1. **渣男要够渣**：七次逃婚才够爽
2. **新选择要够好**：不能是随便找人凑数
3. **渣男要悔得彻底**：不是简单道歉，要彻底后悔

- T-028心死型觉醒：换人需要心死做基础
- T-024外弱内强反击法：新选择可能是隐藏实力
- T-005爽点设计：渣男悔疯是核心爽点

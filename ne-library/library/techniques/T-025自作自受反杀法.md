# T-025 自作自受反杀法

> L2 Strategy | 短篇专用技法
> 来源：Research层分析（00后打假公司福利制度）
> 适用：职场/打脸/爽文

## 核心定义

主角让对方自己作死，最终自食恶果，反杀于无形。

## 底层原理

"搬起石头砸自己脚"是最爽的反杀方式——不需要主角动手，对方自己害自己。

## 操作步骤

### Step 1：设计"作死"场景

对方自信满满地做某件事：
- 集体辞职威胁老板
- 散布谣言陷害主角
- 以为主角好欺负

### Step 2：设置"反弹"机制

主角不是直接反击，而是设置条件让对方自食恶果：
- "好，批准你们的离职"
- "走法律程序"
- "你说的每一句话都成了证据"

### Step 3：等待"砸脚"时刻

让对方一步步走进自己挖的坑：
- 离职申请已批准
- 账算清楚了
- 该走的人是谁？

### Step 4：爽点爆发

对方发现是自己坑了自己：
- 后悔
- 求饶
- 主角淡定看戏

## 应用公式

```
对方作死 + 主角设置条件 + 反弹机制 = 自食恶果
```

## 典型案例：00后打假公司福利制度

**作死场景**：
- 员工集体要求加薪
- 威胁：不加薪就离职
- 帖子上热搜，老板被骂

**反弹机制**：
- 老板："好，批准离职"
- "趁天色还早，把东西收拾走吧"

**砸脚时刻**：
- 员工傻眼：真的要批准？
- 老板淡定：算清账再走

**核心爽点**：
> "我们打工人也是有脾气的！"
> "你不会以为还有人愿意来你公司上班吧？"
> → 结果：没人来的是你们自己

## 避坑指南

1. **反弹要合理**：不能让主角显得太腹黑
2. **节奏要快**：不要拖太长
3. **爽点要集中**：最后一击要够狠

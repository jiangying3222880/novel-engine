# 平台风格卡 · 起点

> 本卡描述的是**风格口味**，回答"写成什么味道最像这里的东西"。

## 一句话味道

世界观可信 + 成长可期——读者追的是体系与升级的**确定性**。

## 风格指纹

| 维度 | 这里的口味 |
|---|---|
| 叙事节奏 | 允许铺垫，但铺垫必须是"有用的信息"（力量体系、世界规则、悬念），纯氛围铺垫照样扑 |
| 语言质地 | 能承载长句与设定说明，逻辑自洽优先于爽。对话可以有机锋、有潜台词 |
| 情绪曲线 | 中频中幅。靠"期待感"支撑长期追读：伏笔、升级路线、目标渐近 |
| 视角与人称 | 主角限知为主，配角 POV 用于扩世界观（但不是每章换人） |
| 人物审美 | 成长弧清晰可验证；配角有独立动机；反派要能被理解（有逻辑的对手才有压迫感） |
| 留白与信息 | 长线伏笔是被鼓励的，甚至可以跨卷；设定发布要稳，不能前后打架 |

## 读者在为什么停留

想看主角怎么一步步变强、世界真相怎么一层层揭开。他们愿意为"长期回报"付耐心，但不接受空头支票。

## 什么稿子在这里对味

- 力量体系/规则清晰且被严格遵守
- 主角的每一次提升都有代价与过程，不是空降
- 世界有纵深，读者能感到"冰山下面还有东西"

## 什么稿子在这里不对味

- 无逻辑的机械爽（读者会挑刺，评论区很毒）
- 设定前后矛盾、战力崩坏
- 主角纯靠运气和贵人
- 爽点密到没有喘息（那是番茄的活）

## 适配气质

玄幻 / 修仙 / 科幻 / 历史 / 游戏 / 克系 / 诸天。共同点：**世界需要被认真搭建**。

## 派生节奏参数

- 章节体量：2000-3000 字
- 兑现密度：每 1-3 章一次推进，大兑现按卷计
- 篇幅量级：百万字起步

# 平台风格卡 · 番茄长篇

> 本卡描述的是**风格口味**，回答"写成什么味道最像这里的东西"。
> 平台规约（红线/审核/字数下限）见 `./_README.md`；本卡末尾的节奏参数是**风格的外显结果**，不是风格本体。

## 一句话味道

即时反馈型爽感——读者用"下一个爽点什么时候来"丈量全文。

## 风格指纹

| 维度 | 这里的口味 |
|---|---|
| 叙事节奏 | 事件驱动，几乎不留静场。每段要么"有事发生"，要么"信息兑现"。氛围铺垫被视为成本，不是资产 |
| 语言质地 | 短句、动词先行、对话驱动。心理描写压缩成外部动作；形容词和环境铺陈越少越好 |
| 情绪曲线 | 高频小幅波动。压抑极短（几段到半章），兑现要快。长期憋屈是致命伤 |
| 视角与人称 | 紧贴主角的第三人称限知，读者知道的和主角一样多。几乎不用全知俯瞰 |
| 人物审美 | 主角目标明确、主动出击、手握金手指或信息优势。配角功能化：送资源、送脸、送冲突 |
| 留白与信息 | 不留白。伏笔要短（三章内兑现），世界观按需给、给一口吃一口 |

## 读者在为什么停留

等下一次兑现——打脸、升级、揭身份、反转。他们不是来"读一个故事"的，是来**收下一次反馈**的。

## 什么稿子在这里对味

- 开篇第一页就有具体冲突，主角在第一章就"动了"
- 主角的每一次得手都可被读者立刻感知（有旁观者反应更好）
- 每章收尾挂一个未兑现的钩

## 什么稿子在这里不对味

- 慢热的世界观铺陈（读者在前三章就走了）
- 群像、多线并行、文艺独白
- 主角长期被动、被压制超过半卷
- 悲剧或开放式结尾

## 适配气质

系统 / 重生 / 都市逆袭 / 战神赘婿 / 脑洞 / 神医相师。共同点：**主角手里有一张别人没有的牌**。

## 派生节奏参数

- 章节体量：2000-2500 字
- 兑现密度：每章至少一个小兑现，3-5 章一个中兑现
- 篇幅量级：百万字起步

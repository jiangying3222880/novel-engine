# 平台风格卡 · 书旗

> 本卡描述的是**风格口味**，回答"写成什么味道最像这里的东西"。

## 一句话味道

通俗的中间地带——比番茄从容，比起点直接。

## 风格指纹

| 维度 | 这里的口味 |
|---|---|
| 叙事节奏 | 偏快，能接受少量铺垫，但铺垫要短 |
| 语言质地 | 通俗白话，允许一点点文采，但不能文艺 |
| 情绪曲线 | 爽为主，允许虐但必须短；不追求极端的情绪浓度 |
| 视角与人称 | 主角限知 |
| 人物审美 | 主角有成长线，但不要求搭建完整体系；配角可以有基本动机 |
| 留白与信息 | 中等。可以有伏笔，但兑现不能拖太久 |

## 读者在为什么停留

稳定的消遣供给——每天有得看、看得懂、看着不累。

## 什么稿子在这里对味

- 类型清晰、不混搭
- 节奏稳定，不忽快忽慢
- 主角目标明确，读者始终知道他在干嘛

## 什么稿子在这里不对味

- 过于硬核的设定体系（那是起点的读者）
- 过于文艺的表达
- 极端快节奏且毫无铺垫（那是番茄的读者）
- 题材摇摆、类型不清晰

## 适配气质

都市 / 玄幻 / 甜宠 / 通俗悬疑。共同点：**一句话能说清是什么类型**。

## 派生节奏参数

- 章节体量：2000 字左右
- 兑现密度：每章一次推进
- 篇幅量级：百万字起步

# 平台风格卡 · 七猫

> 本卡描述的是**风格口味**，回答"写成什么味道最像这里的东西"。

## 一句话味道

直给的市井爽感——比番茄更糙、更直、更不绕弯。

## 风格指纹

| 维度 | 这里的口味 |
|---|---|
| 叙事节奏 | 快，冲突直白。不打机锋、不埋长线，看不起谁就直接打谁的脸 |
| 语言质地 | 大白话到底。句式短、对白多、书面语越少越好。文采是减分项 |
| 情绪曲线 | 简单二元：被看不起 → 打脸。不追求情绪层次，追求命中率 |
| 视角与人称 | 主角限知，几乎不离开主角的得失 |
| 人物审美 | 身份反差型主角：战神、霸总、神医、赘婿。配角是"震惊的背景板" |
| 留白与信息 | 不留白。身份、底牌早亮早爽，藏着是浪费 |

## 读者在为什么停留

等身份揭晓那一刻的爽——"你根本不知道你在跟谁说话"。

## 什么稿子在这里对味

- 主角开局就被踩，且踩得具体（谁、当着谁、说了什么）
- 打脸场面有围观者、有细节、有对方的表情变化
- 节奏不停，一章一件事

## 什么稿子在这里不对味

- 文学性表达、复杂叙事结构
- 慢热铺垫
- 苦情、悲剧、主角长期吃亏
- 需要动脑的多线阴谋

## 适配气质

都市战神 / 霸总 / 赘婿 / 现言逆袭 / 神医相师。共同点：**身份差是唯一的发动机**。

## 派生节奏参数

- 章节体量：2000 字左右
- 兑现密度：每章一打脸
- 篇幅量级：百万字起步

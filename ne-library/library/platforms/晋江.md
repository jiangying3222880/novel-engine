# 平台风格卡 · 晋江

> 本卡描述的是**风格口味**，回答"写成什么味道最像这里的东西"。

## 一句话味道

人物关系与情感张力的质地——读者追的是"他们之间到底怎么回事"。

## 风格指纹

| 维度 | 这里的口味 |
|---|---|
| 叙事节奏 | 情感节奏 > 事件节奏。一场对话可以撑一整章，只要**关系张力在推进** |
| 语言质地 | 细腻，心理与感官描写是主体。句式可长，讲究氛围感与措辞质感 |
| 情绪曲线 | 低频高幅——起伏慢但深。虐与甜都要给足过程，快进是犯罪 |
| 视角与人称 | 主角限知（女主/主受），重视内心活动；双视角很常见，用于制造错位张力 |
| 人物审美 | 人物先于剧情。CP 感和人设一致性是硬通货，**OOC 是死罪** |
| 留白与信息 | 允许留白和含蓄，读者享受"自己读懂"。信息交代要为情绪服务，不能打断情绪 |

## 读者在为什么停留

追人物关系进展与情感兑现。他们会反复重读某几场戏，为一句台词截图。

## 什么稿子在这里对味

- 人物有稳定的内在逻辑，行为可预测但选择出人意料
- 感情推进有阻力、有过程、有阶段性兑现
- 配角也有自己的欲望，不是工具

## 什么稿子在这里不对味

- 人物工具化（为推动剧情让角色做不符合人设的事）
- 感情线快进、跳阶段
- 为爽牺牲人设
- 大段与人物无关的设定说明

## 适配气质

言情 / 古言 / 耽美 / 悬疑言情 / 群像情感 / 现言。共同点：**核心看点是"人"**。

## 派生节奏参数

- 章节体量：3000-5000 字
- 兑现密度：情感小兑现每章一次，关系大兑现按卷计
- 篇幅量级：几十万字

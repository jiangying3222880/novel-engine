# 平台风格卡 · 飞卢

> 本卡描述的是**风格口味**，回答"写成什么味道最像这里的东西"。

## 一句话味道

脑洞本身的快感——这里"点子"比"文笔"值钱。

## 风格指纹

| 维度 | 这里的口味 |
|---|---|
| 叙事节奏 | 极快。几乎每段都有新信息或新爽点，停顿即流失 |
| 语言质地 | 功能性文字，不追求质感，模板化程度高。读者不来看文笔 |
| 情绪曲线 | 纯爽。负面情绪短到以"段"计，几乎不存在压抑期 |
| 视角与人称 | 主角限知 + 系统面板/数据化呈现（数值、进度条、提示音） |
| 人物审美 | 主角是爽点发生器；配角多为"反应者"（震惊、跪舔、后悔） |
| 留白与信息 | 信息全给，且以可视化方式给（面板、排行榜、播报） |

## 读者在为什么停留

想看下一个脑洞怎么展开、下一个谁被打脸。**更新量本身也是产品的一部分**。

## 什么稿子在这里对味

- 设定一句话能说清且足够新（"我绑定了XXX系统"式）
- 爽点可视化：有数值、有排名、有围观反应
- 日更量大，不断更

## 什么稿子在这里不对味

- 慢热、虐主、悲剧
- 文学性表达
- 长线伏笔（读者追的是即时反馈，不是解谜）
- 更新不稳

## 适配气质

同人 / 系统 / 诸天 / 脑洞 / 爽文 / 聊天群。共同点：**一个可立刻展示效果的外挂**。

## 派生节奏参数

- 章节体量：1500-2000 字
- 兑现密度：每段级
- 篇幅量级：百万字，日更万字是常态

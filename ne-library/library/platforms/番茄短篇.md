# 平台风格卡 · 番茄短篇

> 本卡描述的是**风格口味**，回答"写成什么味道最像这里的东西"。

## 一句话味道

一句话钩住 → 情绪拉满 → 反转揭底。整个篇幅只服务一次情绪冲击。

## 风格指纹

| 维度 | 这里的口味 |
|---|---|
| 叙事节奏 | 第一句就要制造"这不对劲"的疑问。中段只做一件事：把情绪往上拧。尾段揭底/反转 |
| 语言质地 | 口语化、短段落、大量单句成段（竖屏阅读）。不追求文采，追求"一口气读完" |
| 情绪曲线 | 单一情绪主线拉满——虐到底或爽到底。中途换调=翻车 |
| 视角与人称 | 第一人称"我"占绝对多数，强倾诉感、强代入 |
| 人物审美 | 人物极少（1-3 个），关系本身就是冲突。不需要人物弧光，需要人物处境 |
| 留白与信息 | 全程压制关键信息的释放，只在结尾一次放出 |

## 读者在为什么停留

想知道"到底怎么回事"，以及要一次情绪宣泄——哭出来或爽出来。

## 什么稿子在这里对味

- 开篇即异常陈述（"我丈夫死后第七天，他回来了"式）
- 全文只有一个问题，所有段落都在回答它或延迟回答它
- 结尾有明确的反转或揭底，不留开放式余味

## 什么稿子在这里不对味

- 多线、群像、支线
- 慢热、氛围先行
- 留白式结尾（读者会觉得被骗）
- 需要设定表才能读懂的题材

## 适配气质

悬疑 / 复仇 / 情感虐恋 / 家庭伦理反转 / 志怪。共同点：**一个可以被一句话说清的反常处境**。

## 派生节奏参数

- 章节体量：不分章或极短章
- 兑现密度：全文一次大兑现（结尾），中段靠小疑问续命
- 篇幅量级：1-3 万字

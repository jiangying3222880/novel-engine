# platforms/ — 平台风格卡

> **本目录只管一件事：风格口味。** 回答"这本书写成什么味道，最像这个平台的东西"。

## 风格 != 规约（重要区分）

| | 是什么 | 放哪 | 会不会变 |
|---|---|---|---|
| **平台风格** | 这个平台的读者爱什么味道：节奏审美、语言质地、情绪曲线、人物审美 | 本目录下 8 张卡 | 慢变（数年） |
| **平台规约** | 字数要求、审核红线、签约政策、AI 治理尺度 | 本文件 §红线禁忌 | 快变（按年甚至按月） |

**本技能的默认立场：平台维度取"风格"，不取"规约"。**
原因是规约会过期、且各平台差异不大（涉黄涉政全平台都禁），对**文风生成**帮助有限；
真正改变输出的是"这里的人爱什么味道"。

> 例外：规约中少数与文风直接相关者（如 AI 粗制滥造治理）已在 §红线禁忌 标注，
> 影响的是写法而非口味，按"写作前必读"处理。

## 跨平台通用法则

1. **黄金三章**：所有平台都看重前三章，只是"好看"的定义不同（番茄要爽点，起点要设定钩子，晋江要人物张力）
2. **断章技巧**：章尾留钩子通用，但钩子类型不同——番茄留"未兑现的爽"，起点留"未揭开的设定"，晋江留"未说出口的话"
3. **爽点密度**：免费端（番茄/七猫/飞卢）要密，付费端（起点/晋江）可缓
4. **人设鲜明**：所有平台都吃人设，只是人设类型不同
5. **更新稳定**：不断更比偶尔爆发更重要

## 红线禁忌（全平台通用 · 规约层）

- ❌ 涉政、涉黄、涉暴
- ❌ 抄袭、洗稿、融梗
- ❌ 三观不正（美化犯罪、教唆自杀等）
- ❌ 未成年人性描写
- ❌ 敏感时期发敏感内容

> **AI 治理（写法层，2026 起各平台普遍收紧）**：番茄等平台明确拒签"AI 粗制滥造 / 空洞水文 /
> 重复堆砌 / 机械扩写"，第三方补充的识别特征为**词频平、句构单一、情感无波动**。
> 这些不是"平台风格"，是"写得太差会被判为机器"的下限——对应到本技能，靠的是
> 执笔态声音样本（见 `../../identities/作者.md` §五）与 S3 去 AI 味检验
> （见 `../../../ne-review/SKILL.md`），不是靠平台卡。

## 新人避坑

1. **不要同时发太多平台**：选 1-2 个主力深耕
2. **不要拿 A 平台的写法去 B 平台发**：番茄爽文发晋江大概率扑
3. **不要写完一本才发现投错了平台**：立项时就该定（见 `../../../ne-setup/references/题材与平台自动确认.md`）
4. **不要盲目跟风**：热门题材竞争也大，适合自己的才最好
5. **不要只看稿费**：还要看读者反馈、成长空间、平台政策

# 平台风格卡 · 知乎盐选

> 本卡描述的是**风格口味**，回答"写成什么味道最像这里的东西"。

## 一句话味道

可信的真实感 + 冷静的第一人称 + 层层剥开的反转。

## 风格指纹

| 维度 | 这里的口味 |
|---|---|
| 叙事节奏 | 开头即抛"异常陈述/反常事件"制造疑问；中段层层剥；结尾揭底或反转，留一点余味 |
| 语言质地 | 冷静克制，书面但不文艺。**细节的真实**（职业流程、数字、行话）是可信度的来源 |
| 情绪曲线 | 克制中积累不安/愤怒/悲悯，最后一次性释放。中途情绪泛滥=破功 |
| 视角与人称 | 第一人称"亲历者/从业者"口吻为主，强调"我为什么会知道这些" |
| 人物审美 | 普通人卷入异常；专业身份（警察、医生、律师、记者）天然带可信度 |
| 留白与信息 | 信息要"公平"：线索给足让读者能自己推，但不能明显到一眼看穿 |

## 读者在为什么停留

想知道真相到底是什么，且享受**智力参与**（自己跟着推）。他们会把推理错的当成奖励。

## 什么稿子在这里对味

- 开篇第一句就是一个反常事实
- 每个疑点都有后续回应，没有废笔
- 真相揭晓后回头看，所有伏笔都成立

## 什么稿子在这里不对味

- 玄幻设定、系统、金手指（破坏"这可能发生"的契约）
- 无脑爽、夸张巧合
- 情绪泛滥、煽情过猛
- 结尾不揭底（读者会投诉）

## 适配气质

悬疑 / 刑侦 / 职场暗战 / 家庭伦理 / 真实事件改编 / 志怪。共同点：**"这事真的发生过"的错觉**。

## 派生节奏参数

- 章节体量：不分章或短章
- 兑现密度：每 2-3 段一个小疑点，结尾一次大揭底
- 篇幅量级：1-5 万字

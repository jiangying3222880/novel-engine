> 定位：L3 Profile 层 · 悬疑推理题材专属指南
> 上游：高潮突转技法库（T-010） / 期待感技法（T-013） / 爽点设计（T-005）

## 悬疑题材核心定位

> **悬疑小说的核心：情节驱动 + 突发式悬念 > 期望式悬念。**
>
> 悬疑读者追求的是"想知道接下来发生了什么"，不是代入角色成长。

---

## 悬疑四小类

| 类型 | 核心特征 | 代表作 |
|------|---------|--------|
| **恐怖悬疑** | 把恐怖进行到底 | 读者追求惊险刺激、汗毛直竖的快感 |
| **侦探推理** | 智力超群的人破解各种案件 | 《名侦探柯南》《神探狄仁杰》 |
| **灵异怪谈** | 灵异传说为主题 | 聊斋类、现代鬼故事 |
| **探险揭秘** | 探秘冒险+破解未解之谜 | 《盗墓笔记》《卫斯理》 |

---

## 悬疑核心技法

### 悬念设置

| 类型 | 机制 | 适用场景 |
|------|------|---------|
| **突发式悬念** | 读者不知道会发生，突然逆转 | 情节驱动类悬疑 |
| **期望式悬念** | 读者有预感/知道会发生，等待发生 | 性格描写类悬疑 |

> 悬疑题材偏向突发式悬念，每一章都要有让读者意外的元素。

### 节奏控制

> **悬疑小说的节奏：比任何题材都快。**
>
> 核心原则：每一章结尾必须是新的问题或意外，不能是答案。

| 章节位置 | 目标 |
|---------|------|
| 开头 | 抛出问题/异常/谜团 |
| 中段 | 逐层深入，信息递增 |
| 结尾 | 揭示部分真相，同时抛出更大谜团 |

### 信息释放节奏

> **悬疑小说的信息不是一次性给出，而是逐层释放。**

- **第一层**：表面现象（读者看到的是什么）
- **第二层**：矛盾点（表面之下的不合理）
- **第三层**：深层原因（为什么）
- **第四层**：更大背景（这只是冰山一角）

## 悬疑小说写作要点

### 主角定位

> 悬疑小说的主角不一定是智者，但必须是有执行力的人。

| 类型 | 主角特征 |
|------|---------|
| **侦探型** | 智力超群，观察细致，逻辑严密 |
| **行动型** | 普通人在危机中成长，边行动边推理 |
| **复合型** | 智力和行动力兼备 |

### 悬疑小说的代入感

> 悬疑的代入感不来自角色成长，而来自**与主角一起解谜的快感**。

| 代入方式 | 操作 |
|---------|------|
| **信息同步** | 让读者和主角同时获得线索，同时推理 |
| **误导参与** | 让读者建立错误判断，然后在反转中修正 |
| **紧迫感传递** | 通过时间限制/生命威胁制造紧迫感 |

### 悬疑小说的人物塑造

| 技巧 | 说明 |
|------|------|
| **配角立体** | 每个配角都有秘密，配角池要足够深 |
| **反派不可预测** | 反派的动机要合理但出人意料 |
| **真凶不唯一** | 误导读者的嫌疑人要有合理的犯罪动机 |

## 悬疑题材与都市神话的区别

| | 悬疑推理 | 都市神话（斩神式） |
|---|---|---|
| **核心驱动力** | 谜团 + 信息释放 | 热血 + 守护责任 |
| **主角定位** | 普通人/智者 | 普通人+特殊能力+创伤 |
| **群像** | 配角提供线索/干扰 | 队友提供战力/情感支撑 |
| **节奏来源** | 信息逐层释放 | 高燃战斗+牺牲 |
| **悬念类型** | 突发式 > 期望式 | 期望式为主 |

---

## 悬疑题材写作禁区

- **不要突然出现超自然元素**（如果是现实悬疑）
- **不要让读者觉得主角是傻子**（线索就在眼前但不发现）
- **不要给出无解的谜团**（读者需要最终答案）
- **不要通篇解密**（解密之间要有新的谜团）

---

## 悬疑题材自检表

- [ ] 每章结尾是否抛出新问题/意外？（不是答案）
- [ ] 线索是否逐层释放？（不是一次性全给）
- [ ] 读者能否参与推理？（信息同步）
- [ ] 突发式悬念是否足够？（不是所有都是期望式）
- [ ] 反派动机是否合理但出人意料？
- [ ] 主角是否在推动情节？（不是旁观者）
- [ ] 全文是否有一条清晰的主线谜团？
- [ ] 结局是否有足够的回收？（不是挖坑不填）

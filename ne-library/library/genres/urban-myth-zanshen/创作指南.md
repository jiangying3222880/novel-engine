# 都市神话题材创作指南

> 来源：斩神式文风技能（job-0028/0030）+ 基线测试分析
> 定位：L3 Profile 层 · 都市神话题材专属指南
> 上游：爽点设计（T-005） / 群像文写作法（T-011）

---

## 题材定位

> 现代都市 + 神话降临 + 守护组织 + 群像小队 + 高燃牺牲 + 章节钩子

**核心口味：**
- 现代生活开场，异常从日常裂缝里钻出来
- 主角外表冷静、内在背负巨大秘密；能力与创伤、责任、代价绑定
- 神话不是背景板，而是现实秩序的压力源
- 群像不是装饰，每个队友都有标签、缺口、成长线、牺牲可能和高光场
- 燃点来自"普通人也要守住人间"，而不是单纯战力碾压

---

## 都市神话四要素

| # | 要素 | 说明 |
|---|-----|------|
| 1 | **都市日常** | 读者熟悉的世界，降低代入门槛 |
| 2 | **神话降临** | 异常从日常裂缝里钻出，形成反差 |
| 3 | **守护组织** | 主角所在团队，提供群像基础 |
| 4 | **高燃牺牲** | 普通人守护人间的使命感 |

---

## 文风特征

> 正文风格：**"清楚、短促、有画面、可滑屏"**。

| 特征 | 说明 |
|------|------|
| **短句节奏** | 一句一段，短促有力 |
| **动作先行** | 先动作后描写，减少"XX的YY"结构 |
| **对话精炼** | 对话不超过3轮，每轮不超过2句 |
| **情绪克制** | 悲伤/愤怒用行动表达，不直接描写 |
| **章节钩子** | 每章结尾抛出悬念或情感冲击点 |

---

## 群像小队设计

> 核心：每个队友都是独立的人，有自己的故事线。

| 角色类型 | 定位 | 高光时刻 |
|---------|------|---------|
| **主角** | 冷静背负秘密，执行者 | 关键时刻的决策 |
| **辅助** | 提供信息/资源支持 | 技术破解 |
| **热血** | 冲动但可靠 | 第一个冲上去 |
| **反差** | 外表冷漠内心火热 | 关键时刻的牺牲 |
| **对照组** | 与主角形成镜像 | 对比强化主题 |

## 都市神话写作要点

### 开篇结构

1. 日常生活建立代入
2. 异常事件打破日常
3. 主角介入（被迫或主动）
4. 神话元素登场
5. 建立第一个悬念/目标

### 章节发动机

每章需要一个发动机：
- **信息差发动机**：主角知道，读者不知道
- **情感发动机**：情绪冲击点（牺牲/羁绊/回忆）
- **悬念发动机**：抛出新问题
- **战斗发动机**：高燃战斗场景

### 爽点设计

> 都市神话的爽点不是战力碾压，而是**"以凡人之躯比肩神明"**。

| 爽点类型 | 操作 |
|---------|------|
| **守护爽** | 普通人挡住神明攻击 |
| **羁绊爽** | 队友牺牲或羁绊加深 |
| **认知爽** | 用智慧破解神明设定 |
| **成长爽** | 从普通人到守护者的蜕变 |

## 都市神话 vs 纯都市 vs 纯玄幻

| | 都市神话 | 纯都市 | 纯玄幻 |
|---|---|---|---|
| 力量来源 | 神话+都市 | 现实能力 | 虚构修炼体系 |
| 主角 | 普通人+特殊能力 | 普通人 | 修炼者 |
| 爽点 | 守护/牺牲/羁绊 | 逆袭/权力/金钱 | 升级/神器 |
| 情感深度 | 高（牺牲/羁绊） | 中 | 低 |
| 群像要求 | 高（小队必须有特色） | 低 | 低 |

---

## 都市神话自检表

- [ ] 开篇是否从日常生活切入？（不是直接神话降临）
- [ ] 神话元素是否制造足够反差？（日常裂缝里钻出异常）
- [ ] 主角是否有创伤/秘密？（不是纯爽型主角）
- [ ] 每个队友是否有独立故事线？
- [ ] 每章是否有发动机（悬念/情感/战斗）？
- [ ] 情感是否用行动表达而非直接描写？
- [ ] 章节结尾是否有钩子？

---

## 都市题材核心定位

> **都市小说的核心优势：代入感永远是第一位。**
>
> 都市背景是读者最熟悉的世界，读者不需要跨越认知门槛就能直接代入。

---

## 都市读者画像

| 读者群体 | 心理特征 | 期待内容 |
|---------|---------|---------|
| **热血青春** | 刚步入社会，对事业有渴望 | 逆袭、职场成长 |
| **校园风云** | 升学压力、青春躁动 | 暧昧、热血、友情 |
| **都市重生** | 后悔过去，渴望弥补 | 重来一次、改写命运 |
| **都市异能** | 渴望超脱平凡 | 超能力改变人生 |
| **都市激战（黑道）** | 热血叛逆，想发泄 | 打拼、热血、兄弟情 |
| **商业大亨** | 追求财富和权力 | 财富帝国、商场博弈 |
| **官场风云** | 权力欲望 | 从基层到顶峰的权力之路 |
| **娱乐明星** | 向往光环 | 成为万人迷 |
| **乡土乡村** | 怀旧、接地气 | 田园生活、乡村逆袭 |

## 都市题材核心卖点

| # | 卖点 | 说明 |
|---|-----|------|
| 1 | **真实感** | 都市背景真实，读者有切身感受 |
| 2 | **代入感** | 读者能在主角身上看到自己（后悔/梦想/被欺压） |
| 3 | **爽点明确** | 美女/金钱/地位/复仇都是读者熟悉且渴望的东西 |
| 4 | **分类多样** | 12小类，覆盖不同读者群体需求 |

---

## 都市题材常见模式

| 模式 | 核心爽点 | 代表类型 |
|------|---------|---------|
| **逆袭模式** | 从弱到强，打脸所有人 | 都市重生/异能 |
| **权力模式** | 从底层到顶峰的晋升之路 | 官场/职场/商业 |
| **热血模式** | 兄弟情+热血战斗 | 都市激战（黑道） |
| **暧昧模式** | 收集美女/感情纠葛 | 都市生活/娱乐 |
| **复仇模式** | 报仇雪恨 | 都市重生 |

## 都市题材写作要点

### 代入门道

> **增加代入感的经典桥段**：
> - 难以忘怀的童年场景
> - 后悔当年事的弥补
> - 艰辛生活的描绘
> - 平凡人生的飞扬
> - 被欺压的报复心理满足

### "看+变"创作法

> **核心：看足够多的书 → 发现套路雷同 → 变通**

| 常规写法 | 变化写法 |
|---------|---------|
| 重生回十年前 | 重生回半个月前，只多15天记忆 |
| 当清官 | 被枪毙的贪官重生到双规前一天 |
| 武力型黑道 | 无武力书生被逼入黑道 |

### 都市vs仙侠/玄幻

| | 都市 | 仙侠/玄幻 |
|---|---|---------|
| 背景 | 读者熟悉的世界 | 需要构建陌生世界观 |
| 代入门槛 | 低 | 高 |
| 力量体系 | 现实体系（金钱/权力/地位） | 虚构体系（等级/法宝/丹药） |
| 爽点来源 | 现实欲望（金钱/权力/美女） | 虚构幻想（升级/神器） |

## 都市题材写作禁区

- **别写大学**（写烂了）
- **别混在夜总会**（都市仙侠败笔）
- **别写主角窝囊**（主角可以平凡但不能窝囊）
- **别写配角比主角更耀眼**（代入感断裂）

---

## 都市题材自检表

- [ ] 都市背景是否真实可信？（读者能否相信这个世界的逻辑？）
- [ ] 主角目标是否符合读者期待？（权力/金钱/复仇/感情）
- [ ] 爽点是否明确且符合都市读者的欲望？
- [ ] 有没有利用读者"后悔"的心理（重生文核心）？
- [ ] 分类定位是否清晰？（不是大杂烩）
- [ ] 开头三章是否让读者立刻产生代入感？

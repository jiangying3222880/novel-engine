## 仙侠 vs 玄幻：核心区别

> **仙侠**：核心是"仙"，追求长生不老、仗义行侠，读者期待主角对"道"的探索
> **东方玄幻**：RPG网游化，读者期待副本/收集/推boss

| | 仙侠 | 东方玄幻 |
|---|---|---------|
| **核心追求** | 长生不老，仗义行侠（求道） | RPG网游化 |
| **读者期待** | 主角对"道"的探索与追求 | 暧昧/杀人夺宝/探险/学艺/做任务 |
| **升级系统** | 必须清晰 | 略宽松 |
| **背景纯度** | 纯正东方，不能写大杂脍 | 可兼容多种元素 |
| **作者常犯** | 写到经历探险忘了求道主线 | 升级路线模糊 |

## 仙侠四大核心元素

| # | 元素 | 说明 |
|---|-----|------|
| 1 | **能力等级设定** | 升级类仙侠小说的主线之一 |
| 2 | **丹药法宝系统** | 炼器、炼丹、布阵、画符 |
| 3 | **恩怨情仇** | 爱情、友情、争霸、阴谋、宫斗、传承 |
| 4 | **获得与失去** | 获得宝物/失去宝物 = 一次桥段 |

### 仙侠元素清单（14个）

救美 / 采药 / 夺宝 / 炼丹 / 反抢 / 踩人 / 装逼 / 体悟 / 副本 / 升级 / 反杀 / 奇遇 / 传承 / 天劫

### 元素组合拼接法

> **核心：用元素拼骨架，用骨架编情节。**

**操作步骤**：
1. 列出本书要用的核心元素（从14个中选）
2. 设计元素之间的因果链（A→B→C）
3. 给每个元素配上爽点（装逼/收获/反杀）

**案例**（元素组合）：
> 美女患绝症 → 需要副本药物 → 需要某人宝物 → 主角得到 → 坏人杀原主人 → 主角反杀 → 进入副本 → 遇竞争者 → 抢药物+获好处（伏笔）

## 仙侠四流派

| 流派 | 说明 | 代表作 |
|------|------|--------|
| **洪荒封神流** | 以洪荒时代为背景，封神榜体系 | 《佛本是道》 |
| **星际寻宝流** | 星际背景寻宝探险 | 《飘渺之旅》 |
| **都市仙侠流** | 现代都市背景修真（避免大学/夜总会） | 多部 |
| **历史仙侠** | 以历史人物（李白/吕洞宾）为背景 | 较少见 |
| **回炉仙侠** | 修仙失败，回到过去重新修炼 | 较多 |

### 都市仙侠写作禁区

- 别写大学（写烂了）
- 别混在夜总会（败笔）
- 尽量添加新意

## 仙侠四卖点

| # | 卖点 | 操作要点 |
|---|-----|---------|
| 1 | **纯正东方背景** | 不掺杂西方吸血鬼/魔法师，读者会感觉怪异 |
| 2 | **制造** | 主角亲手制作（比直接获得神器更让读者喜欢） |
| 3 | **升级** | 长期目标（长生）+ 短期目标（每级收获），满足收集癖 |
| 4 | **执着** | 主角不能散漫，修炼艰辛才有爽感 |

### 长期目标 + 短期目标公式

> 主角的最终目标是长生/求道（长期目标），但作者要经常提醒读者这个目标（不要让读者忘记）。
>
> 同时，安排短期目标（升级/收获宝物/打败敌人）满足读者的"收集癖"。

---

## 东方玄幻关键词：随心所欲

> 读者读玄幻 = 追求"随心所欲"的幻境来放松心灵

**网游让玩家沉迷的要素 = 玄幻让读者沉迷的要素**：
- 装备越来越炫（收获感）
- PK推boss很爽（战斗爽点）
- 妹妹可以勾搭（后宫）
- 宝物一个比一个牛（升级感）
- 每次推boss都有战利品（收集癖）

## 仙侠写作自检表

- [ ] 仙侠：主角是否在追求"道"？有没有在探险中忘了求道主线？
- [ ] 玄幻：升级路线是否清晰？（读者需要长期追看目标）
- [ ] 有没有掺杂西方背景？（仙侠读者会感觉怪异）
- [ ] 等级系统是否清晰？（散仙→地仙→天仙→大罗金仙等）
- [ ] 长期目标（长生）是否经常提醒读者？
- [ ] 短期目标（升级/宝物）是否满足读者收集癖？
- [ ] 元素是否组合成完整情节？（不是堆砌，是因果链）
- [ ] 主角获得宝物是否靠亲手制造？（比直接捡到更让读者喜欢）
- [ ] 主角是否执着？（散漫主角 = 唬烂感）
